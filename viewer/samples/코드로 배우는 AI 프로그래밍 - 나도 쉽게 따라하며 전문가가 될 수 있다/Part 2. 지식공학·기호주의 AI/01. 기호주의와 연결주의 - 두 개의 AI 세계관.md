# 01. 기호주의와 연결주의 - 두 개의 AI 세계관

> AI는 크게 두 방식으로 발전해 왔습니다. 하나는 사람이 규칙을 직접 넣는 방식이고, 다른 하나는 데이터에서 규칙을 학습하는 방식입니다. 이 챕터에서는 이 큰 구도를 먼저 잡고, 이후 Part 2에서 기호주의를, Part 4 이후에서 연결주의를 본격적으로 살펴봅니다.

## 1. AI를 만드는 두 갈래 길

AI를 구현하는 접근은 역사적으로 크게 두 계열로 갈라져 왔습니다.

- **기호주의 (Symbolic AI, 지식공학)**: 사람이 알고 있는 지식·규칙을 기호와 규칙 형태로 **명시적으로 코드에 심는** 접근. 1950~1980년대 전문가 시스템이 대표적입니다.
- **연결주의 (Connectionist AI, 데이터공학)**: 대량의 데이터를 학습 알고리즘에 흘려 넣어 **규칙이 가중치 형태로 저절로 떠오르게** 하는 접근. 퍼셉트론, 신경망, 그리고 현대의 딥러닝이 이 계열입니다.

둘은 지능을 바라보는 출발점부터 다릅니다. 기호주의는 지능을 규칙과 추론의 문제로 보고, 연결주의는 많은 예시를 학습해 패턴을 익히는 문제로 봅니다. 그래서 개발 방식·필요 자원·해석 가능성도 크게 달라집니다.

| 축 | 기호주의 | 연결주의 |
|---|---|---|
| 지식 주입 방식 | 사람이 규칙을 직접 작성 | 데이터에서 학습 |
| 필요한 것 | 전문가 지식, 명시적 규칙 | 대량의 라벨링된 데이터 |
| 강점 | **설명 가능**, 소량 도메인에 강함 | 복잡한 패턴, 이미지·음성·자연어에 강함 |
| 약점 | 규칙 폭발, 새로운 상황에 취약 | 해석 어려움(블랙박스), 데이터 품질 의존 |
| 대표 사례 | 전문가 시스템, 규칙 기반 챗봇 | 신경망, 딥러닝, 현대 ML |

## 2. 기호주의 - 지식을 코드로 심는 길

기호주의의 발상은 단순합니다. "사람이 의사결정을 어떻게 하는지 알면, 그 규칙을 그대로 프로그램으로 옮기면 된다."

```python
def classify_grade(score: int) -> str:
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    else:
        return "F"
```

위 학점 분류기는 **규칙이 코드에 노출**되어 있습니다. 누가 왜 어떤 등급을 받았는지 설명할 수 있고, 규칙 하나를 바꾸고 싶으면 해당 if 문만 고치면 됩니다. 이 특성이 기호주의의 최대 강점입니다.

하지만 한계도 분명합니다. 예를 들어 이메일 스팸 분류를 규칙만으로 풀려면 표현, 이미지, 발신자, 시간대 같은 요소를 모두 규칙으로 적어야 합니다. 그러다 보면 규칙이 빠르게 늘어나고, 서로 충돌하는 경우도 생깁니다. 새로운 스팸 기법이 나올 때마다 사람이 규칙을 다시 손봐야 한다는 점도 부담입니다. 현실 문제가 고차원 패턴을 다룰수록 이런 유지 비용은 감당하기 어려워집니다.

### 2.1 지식 표현 - 시멘틱 네트워크와 Knowledge Graph

기호주의의 또 한 축은 **지식 표현(Knowledge Representation)** 입니다. 사람이 가진 지식을 기호와 관계의 그래프로 형식화해, 컴퓨터가 탐색·추론을 수행할 수 있게 하는 접근입니다.

대표적인 방식으로는 **시멘틱 네트워크(Semantic Network)**, **온톨로지(Ontology)**, **지식 그래프(Knowledge Graph)**가 있습니다. 일단 여기서는 지식 그래프를 대표 예시로 이해해도 충분합니다. 예컨대 "카나리아는 새다", "새는 날 수 있다" 같은 사실을 노드(개체)와 엣지(관계)로 연결해 저장해 두면, "카나리아는 날 수 있는가?" 같은 질문에 그래프 탐색으로 답할 수 있습니다. 현대 검색 엔진의 Google Knowledge Graph, 공개 데이터 프로젝트 Wikidata, 지식공학 연구의 Cyc 같은 시스템이 이 전통을 계승하고 있습니다.

지식 그래프는 단독으로 쓰이기도 하지만, 최근에는 연결주의 모델(대규모 언어 모델 등)의 답변을 검증·보강하는 외부 지식원으로도 자주 결합됩니다. 기호주의와 연결주의가 실무에서 서로를 보완하는 대표적 지점입니다.

Part 2의 나머지 챕터에서는 기호주의의 또 다른 구체 기법인 **규칙 기반 전문가 시스템**·**탐색 기반 AI**·**유전 알고리즘**을 짧게 짚어 보겠습니다.

## 3. 연결주의 - 데이터에서 지식을 뽑는 길

연결주의는 반대로 접근합니다. "규칙을 직접 쓰지 말고, 예시(데이터)를 충분히 보여 주면 모델이 규칙에 해당하는 파라미터를 스스로 맞춰 갈 것이다."

> [!note] `X`는 왜 대문자이고 `y`는 왜 소문자인가
> 학교에서 보던 `y = f(x)`처럼, `x`는 입력이고 `y`는 그 입력에 대한 결과라는 뜻입니다.
>
> 머신러닝에서는 입력이 한 값이 아니라 여러 샘플과 여러 Feature로 이루어진 표이므로 입력 전체를 행렬 `X`로 쓰고, 각 샘플의 정답은 한 줄짜리 벡터 `y`로 씁니다. 그래서 선형대수 표기 관례까지 겹쳐 `X`는 대문자, `y`는 소문자로 남았습니다.

아직 데이터를 학습용과 평가용으로 나누기 전에는 보통 `X`, `y`를 쓰고, `train_test_split` 같은 단계로 분할한 뒤에는 `X_train`, `X_test`, `y_train`, `y_test`처럼 이름이 바뀝니다. 아래 의사 코드도 이 기본 표기를 따릅니다.

![[p2-x-y-train-test-split.svg|560]]

*그림 1. 분할 전의 `X`, `y`가 학습용 `X_train`, `y_train`과 테스트용 `X_test`, `y_test`로 나뉘는 구조*

```python
# 의사 코드 (실제 모델 학습은 Part 4 이후에서 구체화)
model = SomeClassifier()
model.fit(X, y)                    # 데이터로부터 학습
model.predict(X_new)               # 새 입력 분류
```

모델 내부에는 사람이 명시한 if/else가 없습니다. 대신 수많은 가중치가 학습 과정에서 조정되어 결과적으로 분류 경계를 구성합니다. 개발자조차 "이 입력이 왜 A로 분류됐는지"를 가중치만 보고 직접 읽기는 어렵습니다. 이것이 연결주의의 **블랙박스** 특성입니다.

약점은 있지만 결정적 강점도 있습니다. 이미지·음성·자연어처럼 규칙을 손으로 쓰기가 사실상 불가능한 데이터에서 기호주의가 도달하지 못한 성능을 보여 왔고, 2010년대 중반 이후 딥러닝의 부상으로 실무 AI의 주류 접근으로 자리 잡았습니다.

### 3.1 연결주의의 간단한 연대기

큰 분기점만 네 개 짚어 두겠습니다. 세부 수식은 Part 4에서 본격적으로 풀어냅니다.

- **1957년 퍼셉트론 (Frank Rosenblatt)**: 단층 신경망의 원형. 선형 분리 가능한 문제는 풀지만 XOR 같은 비선형에는 무력했습니다.
- **1969년 XOR 한계 지적 (Minsky & Papert)**: "Perceptrons" 책으로 첫 AI 겨울의 방아쇠가 됩니다.
- **1986년 역전파 알고리즘 (Rumelhart, Hinton, Williams)**: 다층 신경망 학습의 길을 엽니다.
- **2012년 AlexNet의 ImageNet 우승**: 딥러닝이 실무 성능 기준선을 한 차례 뛰어넘으며 현 주류 패러다임으로 들어섭니다.

## 4. 붓꽃(Iris) 분류로 보는 두 세계관

두 패러다임의 차이를 가장 선명하게 보여 주는 예가 **붓꽃 분류**입니다. 붓꽃은 꽃잎·꽃받침의 길이·너비 네 가지 수치만으로 세 품종(Setosa·Versicolor·Virginica) 중 하나를 맞추는 데이터셋으로, 1936년 Ronald Fisher가 판별분석 논문에서 처음 사용한 이래 머신러닝 입문의 단골 예제로 쓰입니다.

Feature는 네 개, Label은 품종 한 컬럼입니다. 앞서 Part 1 Ch 04에서 타이타닉 데이터로 만난 "Feature + Label" 포맷과 동일합니다.

| 꽃잎 길이 | 꽃잎 너비 | 꽃받침 길이 | 꽃받침 너비 | 품종 |
|---|---|---|---|---|
| 5.1 | 3.5 | 1.4 | 0.2 | Setosa |
| 7.0 | 3.2 | 4.7 | 1.4 | Versicolor |
| 6.3 | 3.3 | 6.0 | 2.5 | Virginica |

### 4.1 기호주의로 풀기

도메인 전문가가 직접 규칙을 심을 수 있습니다.

```python
def classify_iris(petal_len: float, petal_width: float) -> str:
    if petal_len < 2.5:
        return "Setosa"
    elif petal_width < 1.7:
        return "Versicolor"
    else:
        return "Virginica"
```

코드가 바로 "판단 기준" 이라 읽히고, 규칙을 바꾸면 결과도 예측 가능하게 변합니다. 하지만 이 임계값은 사람이 데이터를 열어 보고 **직접 관찰해 정해야** 합니다. Feature 수가 늘고 경계가 복잡해지면 금방 한계가 옵니다.

### 4.2 연결주의로 풀기

같은 문제를 데이터와 학습 알고리즘만 제공해 푸는 방식입니다. 실제 모델 구현은 Part 4 이후의 신경망 챕터에서 구체화하고, 여기서는 흐름만 의사 코드로 보입니다.

```python
# 의사 코드. 실제 신경망 학습은 Part 4 Ch 02에서 구체화합니다
model = NeuralNetwork(hidden_units=16)
model.fit(X, y)                 # 데이터로부터 가중치가 학습됨
model.predict(X_new)
```

`if/else`나 임계값이 코드에 노출되지 않습니다. 모델 내부에는 수많은 가중치가 있고, 학습이 끝나면 그 가중치의 조합이 분류 경계를 구성합니다. 개발자조차 "왜 이 꽃을 Versicolor로 분류했는지"를 가중치만 보고 직접 읽어 내기는 어렵습니다. 이것이 연결주의의 **블랙박스** 특성이며, Part 5 Ch 07의 설명가능 AI는 바로 이 블랙박스를 역으로 해석하려는 시도입니다.

한편 Part 3에서 다룰 Decision Tree·SVM·k-NN 같은 전통 머신러닝 알고리즘은 두 세계관의 중간 지점에 놓인 경우가 많습니다. 데이터로부터 학습한다는 점에서는 연결주의에 가깝지만, 결과를 비교적 해석하기 쉬운 모델도 많기 때문입니다. 이 챕터에서는 큰 구도만 먼저 잡고, 알고리즘별 위치는 해당 챕터에서 다시 짚겠습니다.

## 5. 모라벡의 역설과 연결주의의 부상

두 세계관이 왜 이렇게 분화되었는지에 대한 직관적 설명 중 하나가 **모라벡의 역설**입니다. 1980년대 Hans Moravec이 제시한 관찰로 요약하면 이렇습니다.

> "인간에게 쉬운 일이 기계에게 어렵고, 인간에게 어려운 일이 기계에게 쉽다."

- 컴퓨터는 수십 자리 수의 곱셈이나 체스 탐색은 너무나 잘 합니다. 이것들은 규칙이 명확해서 기호주의로도 잘 풀립니다.
- 그런데 "사진 속 고양이를 알아보는 일" 이나 "대화 속 맥락을 이해하는 일" 은 인간 아기도 하는데 컴퓨터에게는 엄청나게 어렵습니다. 이 영역은 규칙을 말로 풀어 쓰기 어렵기 때문에 기호주의의 방식이 통하지 않습니다.

연결주의는 바로 이 "말로 설명할 수 없는 지식" 을 데이터의 양으로 우회합니다. 사진 수십만 장에 고양이·개 라벨을 붙여 학습시키면 모델이 경계를 스스로 맞추며, 결과적으로 사람이 규칙을 적지 못했던 문제가 풀립니다. 이미지·음성·자연어가 연결주의의 주무대가 된 이유이기도 합니다.

## 6. 하이브리드와 XAI의 등장

실제 실무에서는 두 세계관을 대립으로 두기보다 **상황에 맞게 섞어 쓰는** 경우가 훨씬 많습니다. 추천 시스템은 협업 필터링(연결주의적) 결과를 비즈니스 규칙(기호주의적)으로 한 번 더 걸러 내보내고, 금융 사기 탐지는 규칙 기반 필터 위에 딥러닝 점수를 덧씌우는 식으로 조합됩니다.

연결주의의 블랙박스 성향을 완화하려는 흐름으로 **설명가능 AI (XAI, eXplainable AI)**도 자리를 잡았습니다. 쉽게 말해, 모델이 왜 그런 판단을 했는지 나중에라도 해석해 보려는 시도입니다. 미국 DARPA가 2016년에 XAI 프로그램을 공식화하면서 이 흐름이 널리 알려졌고, 이후 Feature Importance·GradCAM·SHAP 같은 해석 기법이 실무에 들어왔습니다. 자세한 내용은 Part 5 Ch 07에서 다룹니다.

또 한 갈래는 Andrew Ng이 강조한 **Data-centric AI** 흐름입니다. "모델을 더 크게 만드는 것보다 데이터를 더 깨끗하게 만드는 것이 성능에 큰 기여를 할 때가 많다"는 주장이며, 이는 연결주의의 약점인 데이터 품질 문제를 정면으로 다룹니다.

## 7. 이 책에서 두 세계관은 어디서 만나는가

이 챕터의 구도를 그대로 이 책의 뒷부분에 대응시키면 다음과 같습니다.

- **Part 2 (이 Part)**: 기호주의 계열. 규칙 기반·전문가 시스템·탐색·유전 알고리즘을 짧게 짚습니다.
- **Part 3**: 전통 머신러닝. 두 세계관의 경계선에 있는 알고리즘(Decision Tree·SVM·Linear Regression 등)이 중심이며, 기호주의의 해석 가능성과 연결주의의 데이터 기반 학습이 가장 공존하는 영역입니다.
- **Part 4~6**: 연결주의 계열. 신경망·CNN·RNN·NLP·CV까지, 현대 딥러닝의 주 흐름입니다.
- **Part 5 Ch 07**: XAI. 블랙박스를 해석하려는 역방향 시도입니다.

따라서 이 챕터의 두 세계관 구도는 뒤에서 단순한 "역사 이야기"가 아니라, 각 Part가 **어떤 철학적 전제를 기반으로 문제를 푸는지**를 읽는 틀로 활용됩니다.

## 마무리

두 세계관은 서로를 완전히 대체하지 않습니다. 규칙으로 푸는 게 더 싸고 명확한 문제가 여전히 많고, 반대로 규칙으로는 영원히 못 쫓아갈 고차원 패턴도 있습니다. 좋은 AI 엔지니어는 문제를 먼저 보고 "이건 어느 쪽의 무기로 푸는 게 맞는가" 를 판단합니다.

다음 챕터에서는 기호주의의 가장 오래된 구체 기법인 **규칙 기반 전문가 시스템과 퍼지 추론**을 살펴봅니다.

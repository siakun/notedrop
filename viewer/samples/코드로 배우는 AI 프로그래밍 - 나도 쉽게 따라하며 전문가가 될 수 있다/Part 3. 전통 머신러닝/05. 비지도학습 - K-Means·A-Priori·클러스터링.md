# 05. 비지도학습 - K-Means·A-Priori·클러스터링

> 지금까지는 "정답 라벨이 있는 데이터"로 학습하는 지도학습을 다뤘습니다. 현실에는 라벨을 확보하기 어려운 데이터가 훨씬 많습니다. 이 챕터에서는 라벨 없이 데이터 자체의 구조를 찾는 **비지도학습**의 대표 기법을 정리합니다.

## 1. 비지도학습이란

지도학습에는 `X`와 `y`가 쌍으로 있었습니다. 비지도학습에는 `y`가 없고 `X`만 있습니다. 목표는 "이 데이터가 어떻게 생겼는가, 비슷한 것끼리 어떻게 묶이는가"를 찾아내는 일입니다.

대표 네 갈래가 있습니다.

- **클러스터링(Clustering)**: 비슷한 데이터를 군집으로 묶기 (K-Means, GMM, DBSCAN)
- **차원 축소(Dimensionality Reduction)**: 고차원 데이터를 의미를 보존한 저차원으로 압축 (PCA, t-SNE, UMAP)
- **연관 규칙(Association Rules)**: 함께 자주 나타나는 항목 조합 찾기 (A-Priori, FP-Growth)
- **이상 탐지(Anomaly Detection)**: 대다수와 크게 다른 샘플 찾기 (Isolation Forest, One-Class SVM)

공통 난점은 **평가** 입니다. 정답이 없으니 accuracy 같은 지표가 통하지 않습니다. K-Means 평가를 다루는 뒤 절과 이 장의 평가 섹션에서 그 대안을 살펴봅니다.

## 2. K-Means - 거리 기반 군집화

가장 널리 쓰이는 클러스터링 알고리즘입니다. 아이디어 자체는 단순합니다.

1. 군집 개수 `k`를 정합니다
2. 랜덤으로 `k` 개의 중심점(centroid)을 초기화합니다
3. 각 데이터를 가장 가까운 중심점에 할당합니다
4. 각 군집에 속한 점들의 평균을 새 중심점으로 업데이트합니다
5. 할당이 더 이상 변하지 않을 때까지 3-4를 반복합니다

### 2.1 기본 사용

```python
from sklearn.cluster import KMeans
from sklearn.datasets import load_iris
import numpy as np

iris = load_iris()
X = iris.data

# n_init은 초기 중심점 샘플링을 몇 번 시도할지입니다. sklearn 버전에
# 따라 기본값이 바뀌므로 재현성 확보를 위해 명시 지정해 둡니다.
kmeans = KMeans(n_clusters=3, n_init=10, random_state=42)
kmeans.fit(X)

labels = kmeans.labels_           # 각 샘플이 속한 군집 번호 (0, 1, 2)
centers = kmeans.cluster_centers_ # 군집 중심 좌표
```

`labels_`는 분류 라벨과 모양이 같지만 의미가 다릅니다. "이 샘플이 어떤 군집에 묶였는가" 일 뿐, 실제 품종 라벨과 1:1 대응이 되는 것은 아닙니다. 군집 번호 0·1·2는 실행할 때마다 바뀔 수 있습니다.

### 2.2 스케일링과 K-Means

K-Means는 유클리드 거리에 의존하기 때문에 **피처 스케일이 결과에 결정적** 입니다. 한 피처가 다른 피처보다 100배 큰 단위를 가지면 그 하나의 피처가 거리 계산을 지배합니다. 학습 전에 Ch 04의 `StandardScaler`를 걸어 두는 것을 루틴으로 삼는 편이 안전합니다.

### 2.3 k를 어떻게 정할까 - 엘보우와 실루엣

K-Means의 약점은 사람이 `k`를 미리 정해야 한다는 점입니다. 두 가지 관점이 있습니다.

**엘보우 방법**: `k`를 늘려 가면서 군집 내 분산 합(inertia)을 그리면, 어느 `k` 이후부터 감소 폭이 눈에 띄게 꺾이는 지점이 나타납니다. 팔꿈치(elbow)가 바로 적정 `k`의 직관적 후보입니다.

```python
inertias = []
for k in range(1, 11):
    km = KMeans(n_clusters=k, n_init=10, random_state=42).fit(X)
    inertias.append(km.inertia_)
```

**실루엣 계수(Silhouette Coefficient)**: 각 샘플이 자기 군집과 얼마나 가까운지(`a`), 다른 군집과는 얼마나 먼지(`b`)를 종합해 `-1 ~ 1` 값으로 요약합니다. `1`에 가까울수록 깔끔한 군집, `0` 근방이면 경계에 놓인 샘플, 음수면 다른 군집에 더 가까운 잘못 배치된 샘플입니다.

```python
from sklearn.metrics import silhouette_score

score = silhouette_score(X, labels)
# 전체 평균 실루엣
```

여러 `k`에 대해 실루엣을 뽑아 비교하면 "가장 높은 실루엣을 내는 `k`"가 우선 후보가 됩니다. 엘보우와 실루엣이 같은 `k`를 가리키면 비교적 자신 있게 고를 수 있습니다.

다만 지표가 가리키는 값이 항상 최종 답은 아닙니다. 엘보우와 실루엣이 서로 다른 `k`를 가리키면 도메인 지식으로 다시 판단해야 합니다. 예컨대 붓꽃 데이터에서는 실루엣상 `k=2`가 가장 높게 나오지만 실제 품종은 3종이라 `k=3`을 채택하는 식입니다.

### 2.4 이미지 색상 클러스터링 예시

K-Means의 입력이 꼭 "정형 데이터" 일 필요는 없습니다. 사진 한 장을 `(H, W, 3)` RGB 배열에서 `(H*W, 3)`으로 reshape 하면, 각 행이 하나의 "픽셀 색" 벡터가 되어 그대로 K-Means 입력이 됩니다. `k=3`으로 군집화하면 사진이 대표색 3개로 양자화되고, 센트로이드를 다시 이미지 형태로 그리면 **색상 팔레트**가 자연스럽게 떨어집니다.

```python
from sklearn.cluster import KMeans

# img : 사전에 불러둔 (H, W, 3) 모양의 uint8 배열이라고 가정
h, w, _ = img.shape
pixels = img.reshape(-1, 3)           # (H*W, 3)

km = KMeans(n_clusters=3, n_init=10, random_state=42).fit(pixels)
palette = km.cluster_centers_.astype("uint8")
quantized = palette[km.labels_].reshape(h, w, 3)
```

"샘플 하나 = 벡터 하나"로 데이터를 표현하기만 하면 K-Means는 입력 형식을 가리지 않는다는 것을 보여주는 대표 데모입니다.

## 3. 차원 축소 - PCA

피처가 수십~수백 차원이 되면 시각화도 어렵고, 거리 기반 알고리즘에서 "차원의 저주"가 나타나기 시작합니다. **PCA(Principal Component Analysis)**는 데이터의 분산을 가장 크게 만드는 방향 몇 개를 찾아 그 방향들로 데이터를 투영하는 방법입니다. 결과적으로 고차원 데이터를 **정보 손실을 최소화하며** 저차원으로 압축합니다.

```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

X_scaled = StandardScaler().fit_transform(X)

pca = PCA(n_components=2)
X_2d = pca.fit_transform(X_scaled)    # (N, 4) -> (N, 2)

pca.explained_variance_ratio_         # 각 주성분이 설명하는 분산 비율
pca.explained_variance_ratio_.sum()   # 2차원으로 보존된 전체 분산 비율
```

PCA의 가장 흔한 두 가지 용도입니다.

- **시각화**: 4차원 붓꽃을 2차원으로 내려 산점도로 그리면 품종이 어떻게 분리되는지 육안으로 확인 가능
- **전처리**: 너무 많은 피처를 일부 주성분만으로 줄여 학습 속도·과적합을 완화

PCA는 선형 변환이므로 비선형 구조를 잘 잡지 못합니다. 복잡한 구조를 시각화하고 싶으면 **t-SNE** 나 **UMAP** 같은 비선형 기법이 대안입니다.

## 4. Gaussian Mixture - 확률적 클러스터링

K-Means는 각 샘플을 하나의 군집에 **하드하게** 할당합니다. 경계에 애매하게 걸린 샘플도 강제로 한쪽에 붙여 버립니다. **Gaussian Mixture Model (GMM)**은 각 군집을 가우시안 분포로 보고, 샘플마다 "각 군집에 속할 확률"을 돌려줍니다.

```python
from sklearn.mixture import GaussianMixture

gmm = GaussianMixture(n_components=3, random_state=42)
gmm.fit(X)

labels = gmm.predict(X)          # 가장 확률 높은 군집으로 할당
proba  = gmm.predict_proba(X)    # 각 군집에 대한 확률 분포
```

GMM은 K-Means보다 유연해서 군집이 원형이 아니거나 크기가 제각각일 때 특히 잘 맞습니다. 반면 파라미터(평균·공분산)가 많아져 데이터가 적으면 과적합 위험이 있습니다. 평가에는 K-Means와 마찬가지로 실루엣 점수를 함께 활용할 수 있습니다.

## 5. A-Priori - 연관 규칙과 장바구니 분석

장바구니(거래) 데이터에서 "빵을 산 사람이 우유도 같이 사더라" 같은 **연관 규칙(Association Rule)**을 찾는 고전 알고리즘입니다. 클러스터링과는 다른 계열의 비지도학습으로, 1994년 Agrawal과 Srikant가 제안했습니다.

핵심 개념은 세 가지입니다.

- **지지도(Support)** = `P(A ∩ B)`. 두 항목이 **함께 나타날** 전체 확률
- **신뢰도(Confidence)** = `P(B | A)`. A를 산 사람 중 B도 산 비율
- **향상도(Lift)** = `Confidence / P(B)`. B가 "우연히 함께 나타날 확률" 대비 얼마나 함께 더 자주 나오는가. `1`보다 크면 양의 연관

sklearn은 A-Priori를 기본 제공하지 않지만, 커뮤니티 패키지 `mlxtend`가 표준처럼 쓰입니다. 간단한 4건 거래 예시로 흐름을 따라가 보겠습니다.

```python
# pip install mlxtend가 선행되어야 합니다
from mlxtend.preprocessing import TransactionEncoder
from mlxtend.frequent_patterns import apriori, association_rules

# 4건의 거래 (각 거래에 구매한 상품 리스트)
dataset = [
    ["A", "C", "D"],
    ["B", "C", "E"],
    ["A", "B", "C", "E"],
    ["B", "E"],
]

# one-hot 인코딩된 DataFrame으로 변환 (행=거래, 열=상품)
te = TransactionEncoder()
transactions = pd.DataFrame(
    te.fit(dataset).transform(dataset),
    columns=te.columns_,
)

frequent_items = apriori(transactions, min_support=0.5, use_colnames=True)
rules = association_rules(frequent_items, metric="lift", min_threshold=1.0)
rules.sort_values("lift", ascending=False).head()
```

`min_support=0.5`는 전체 거래의 50% 이상에서 함께 등장하는 항목 조합만 남긴다는 뜻입니다. 실 데이터에서는 `0.01~0.05` 수준의 낮은 값을 기본으로 두고, 규모에 맞춰 조정합니다.

추천 시스템의 가장 단순한 형태이자, 유통·마케팅 도메인에서 여전히 쓰이는 기법입니다.

## 6. 비지도학습의 평가

지도학습의 accuracy·RMSE 처럼 깔끔한 평가 지표가 없다는 점이 비지도학습의 가장 큰 실무적 어려움입니다. 정답이 없기 때문에, 먼저 어떤 축에서 성능을 볼지 정해야 합니다. 그래서 몇 가지 대안이 함께 쓰입니다.

- **내부 지표(Internal)**: 데이터만으로 계산합니다
    - 실루엣 계수: `-1~1`, 클수록 좋음
    - Calinski-Harabasz: 군집 간 분산 / 군집 내 분산 비, 클수록 좋음
    - Davies-Bouldin: 군집 간 분리도 기반, **작을수록** 좋음
- **외부 지표(External)**: 참값 라벨이 일부 있을 때 비교합니다
    - Adjusted Rand Index(ARI): 라벨 쌍 일치 비율을 무작위 기대치로 보정
    - Normalized Mutual Information(NMI): 두 라벨링 사이 상호 정보량 정규화
- **다운스트림 평가**: 비지도 결과를 다음 단계의 입력으로 넣어 "이 군집화가 후속 분류 성능을 올려 주었는가"를 봅니다. 실무에서 가장 믿음이 가는 접근입니다

"최고의 군집화"는 수학적으로 정의되지 않습니다. 쓰는 목적(세그멘테이션·이상 탐지·시각화)에 맞게 평가 축을 먼저 정하고 지표를 고르는 것이 실무 순서입니다.

## 7. 이상 탐지

비지도학습의 또 다른 큰 용도가 **이상 탐지(Anomaly Detection)** 입니다. 정상 패턴을 학습하고 거기에서 크게 벗어나는 샘플을 찾아냅니다. 금융 사기·설비 고장·네트워크 침입 같은 도메인이 대표적입니다.

```python
from sklearn.ensemble import IsolationForest

iso = IsolationForest(contamination=0.05, random_state=42)
iso.fit(X)

scores = iso.decision_function(X)     # 클수록 정상
preds  = iso.predict(X)                # 1=정상, -1=이상
```

`contamination`은 이상치 비율의 사전 추정치입니다. 정확한 값이 없어도 대략의 감으로 지정하며, 모델은 이 비율을 타깃으로 결정 경계를 조정합니다. 앞의 Ch 01에서 본 IQR 기준이 한 피처 단위 이상치에 강하다면, Isolation Forest는 여러 피처의 조합으로 만들어지는 고차원 이상치까지 잡아냅니다.

# 01. 데이터 탐색과 전처리 - Pandas 심화·결손 데이터·피처 엔지니어링

> 실무에서 머신러닝 프로젝트에 들이는 시간 중 대부분은 모델이 아니라 **데이터 준비**에 들어갑니다. 잘못된 전처리는 아무리 좋은 모델로도 복구되지 않습니다. 이 챕터는 Part 3의 분류·회귀·클러스터링 실습이 시작되기 전, 데이터를 훑고 다듬는 최소 도구 세트를 정리합니다.

## 1. 데이터의 두 세계 - 정형과 비정형

실무에서 만나는 데이터는 크게 두 갈래로 나뉩니다.

- **정형(Structured) 데이터**: 행과 열로 표현되는 표 형식. CSV·관계형 DB·엑셀이 대표. 타이타닉·포켓몬·Boston Housing 같은 전통 머신러닝 데이터가 모두 여기 속합니다
- **비정형(Unstructured) 데이터**: 표로 나누기 어려운 데이터. 이미지(픽셀 행렬)·텍스트(토큰 시퀀스)·음성(파형)·시계열이 대표. Part 4 이후의 딥러닝이 주로 다루는 영역

Part 3은 정형 데이터의 세계를 다룹니다. 정형 데이터는 컬럼마다 의미가 분명해서 사람이 직접 특성을 설계하기가 쉽고, 결과를 해석하기도 상대적으로 쉽습니다.

이 챕터는 이전 챕터에서 써 온 **타이타닉 데이터**를 그대로 사용합니다.

```python
import pandas as pd

titanic_df = pd.read_csv("titanic_train.csv")
titanic_df.shape       # (891, 12)
```

## 2. Pandas 심화 - 조회·정렬·집계·그룹

전처리 작업 대부분은 "어떤 조건을 만족하는 행을 골라 요약한다"의 반복입니다. 네 가지 도구만 몸에 익히면 됩니다.

### 2.1 불린 인덱싱

조건식이 `True/False`의 `Series`를 만들고, 이 시리즈로 원본을 필터링합니다. `ndarray`와 정확히 같은 발상입니다.

```python
# 여성 승객
titanic_df[titanic_df["Sex"] == "female"].head()

# 1등석 + 생존
mask = (titanic_df["Pclass"] == 1) & (titanic_df["Survived"] == 1)
titanic_df[mask].shape
```

복수 조건은 `&`·`|`·`~`로 결합하며, **각 조건을 괄호로 감싸는 것이 중요** 합니다. 괄호를 빼먹으면 연산자 우선순위 때문에 엉뚱한 결과가 나옵니다.

### 2.2 정렬 - sort_values

```python
titanic_df.sort_values("Age").head(3)                          # 나이 오름차순
titanic_df.sort_values("Fare", ascending=False).head(3)        # 운임 내림차순

# 여러 컬럼 기준
titanic_df.sort_values(["Pclass", "Fare"],
                       ascending=[True, False]).head()
```

### 2.3 집계 함수

전체 합·평균 등은 DataFrame에 바로 적용되고, 특정 컬럼만 추려 쓸 수도 있습니다.

```python
titanic_df["Age"].mean()        # 평균 나이
titanic_df["Fare"].max()        # 최고 운임
titanic_df[["Age", "Fare"]].agg(["mean", "std", "max"])
```

### 2.4 그룹바이 - 컬럼 단위 집계의 왕도

"성별에 따라 생존율은 얼마나 달랐을까" 같은 질문은 `groupby`가 가장 직접적으로 답합니다.

```python
titanic_df.groupby("Sex")["Survived"].mean()
# Sex
# female    0.742
# male      0.189

titanic_df.groupby(["Pclass", "Sex"])["Survived"].mean()
# 1등석 여성 97%, 3등석 남성 14% 등 등급·성별 교차 생존율
```

`groupby` 결과는 그 자체가 작은 DataFrame·Series 이므로, 이후 시각화·모델링의 입력으로 그대로 넘어갈 수 있습니다.

## 3. 결손 데이터 처리

### 3.1 결측 확인

```python
titanic_df.isna().sum()
# Age       177
# Cabin     687
# Embarked    2
# ...
```

컬럼별 결측 개수를 한눈에 봅니다. 비율을 쓰면 전체 규모 대비 감각이 더 잘 잡힙니다.

```python
titanic_df.isna().mean().sort_values(ascending=False)
# Cabin     0.771
# Age       0.199
# ...
```

### 3.2 전략 선택

결측 처리에 정답은 없고 세 가지 중 선택입니다.

- **컬럼 제거**: 결측 비율이 과도하게 높으면(예: `Cabin` 87%) 컬럼 자체를 버림
- **행 제거**: 행이 충분히 많고 결측 행을 뺀 나머지만으로 학습이 가능할 때
- **대체(Imputation)**: 평균·중앙값·최빈값으로 채우거나, 주변 컬럼으로부터 예측해 채움

```python
# 전략 예시
titanic_df["Age"] = titanic_df["Age"].fillna(titanic_df["Age"].median())
titanic_df["Embarked"] = titanic_df["Embarked"].fillna("S")   # 최빈값
titanic_df = titanic_df.drop(columns=["Cabin"])               # 컬럼 제거
```

어떤 전략을 택하든, **학습에서 정한 규칙을 검증과 테스트에도 그대로 적용해야 합니다**. 예를 들어 검증 데이터의 결측값을 채울 때도 학습 데이터에서 구한 중앙값을 재사용해야 합니다. 검증 데이터 자체의 중앙값으로 다시 채우면 **데이터 누수(data leakage)**가 생깁니다.

## 4. 이상치 탐지 - IQR 방법

"비정상적으로 크거나 작은 값"은 모델을 쉽게 망가뜨립니다. 가장 흔히 쓰는 단순 기준이 **IQR(사분위수 범위)** 입니다.

```python
q1 = titanic_df["Fare"].quantile(0.25)
q3 = titanic_df["Fare"].quantile(0.75)
iqr = q3 - q1
lower, upper = q1 - 1.5 * iqr, q3 + 1.5 * iqr

outliers = titanic_df[(titanic_df["Fare"] < lower) |
                      (titanic_df["Fare"] > upper)]
outliers.shape
```

`Q1 - 1.5·IQR`과 `Q3 + 1.5·IQR` 바깥을 이상치로 보는 규칙입니다. 박스플롯의 "수염(whisker)"과 같은 기준이며, 직관적이면서도 분포 형태에 크게 의존하지 않습니다. 이상치를 발견했다고 무조건 삭제하지는 않습니다. 운임이 비정상적으로 높은 승객이 실제 1등석의 고급 객실 이용자일 수 있으므로, **도메인 해석**이 반드시 동반되어야 합니다.

## 5. 인코딩 - 문자열을 숫자로

머신러닝 알고리즘 대부분은 수치 입력만 받습니다. `Sex`·`Embarked` 같은 범주형 컬럼을 숫자로 바꿔야 합니다.

### 5.1 Label Encoding

각 범주에 정수 하나를 부여합니다. 범주 사이에 **순서**가 있다는 인상을 주므로, 의미상 순서가 있는 값(등급·학점)에 적합합니다.

```python
from sklearn.preprocessing import LabelEncoder

le = LabelEncoder()
titanic_df["Sex_label"] = le.fit_transform(titanic_df["Sex"])
# female -> 0, male -> 1  (알파벳 순)
```

피처(X)의 순서형 인코딩에는 보통 `OrdinalEncoder`가 더 잘 맞습니다. scikit-learn 공식 문서도 `LabelEncoder`는 원래 라벨(y) 전용 도구로 안내합니다. 다만 실무에서는 두 도구가 섞여 쓰이는 경우도 있으니, 용도 차이를 알고 선택하는 편이 좋습니다.

### 5.2 One-hot Encoding

범주마다 별도 0/1 컬럼을 만들어 순서 오해를 없앱니다. 범주 수가 많지 않을 때 표준 선택입니다.

```python
pd.get_dummies(titanic_df["Embarked"], prefix="Embarked").head()
#    Embarked_C  Embarked_Q  Embarked_S
# 0           0           0           1
# 1           1           0           0
# ...
```

sklearn의 `OneHotEncoder`를 쓰면 학습 시 보지 못한 범주를 테스트에서 어떻게 다룰지 같은 세부 옵션을 더 정교하게 설정할 수 있습니다.

## 6. 피처 엔지니어링 - 새 컬럼을 만들어 정보를 더하기

"원본 컬럼만으로는 부족하다. 조합해서 새 컬럼을 만들어야 한다"는 관점이 **피처 엔지니어링** 입니다. 전통 머신러닝에서 모델 선택보다 훨씬 큰 성능 차이를 만들어 내는 부분으로, "응용 머신러닝은 결국 피처 엔지니어링이다"는 말이 실무에서 자주 회자되곤 합니다.

대표적인 변환 패턴 몇 가지입니다.

```python
# 1) 파생 컬럼 - 가족 수 합산
titanic_df["FamilySize"] = titanic_df["SibSp"] + titanic_df["Parch"] + 1

# 2) 구간화(binning) - 연속값을 범주로
# pd.cut은 기본이 '오른쪽 경계 포함, 왼쪽 경계 제외' 입니다.
# include_lowest=True를 주면 bins의 좌측 하한(0)도 포함시켜 경계값 누락을 막습니다.
titanic_df["AgeBucket"] = pd.cut(
    titanic_df["Age"],
    bins=[0, 12, 20, 40, 60, 120],
    labels=["child", "teen", "young", "middle", "senior"],
    include_lowest=True,
)

# 3) 로그 변환 - 왜도가 큰 분포 완화
import numpy as np
titanic_df["FareLog"] = np.log1p(titanic_df["Fare"])

# 4) 원본 조합 지표
titanic_df["FarePerPerson"] = titanic_df["Fare"] / titanic_df["FamilySize"]
```

새 피처를 만들 때마다 "이 피처가 정답을 예측하는 데 도움이 되는가"를 `groupby`와 시각화로 확인하는 습관이 중요합니다.

## 7. EDA - 시각화로 먼저 본다

탐색적 데이터 분석(Exploratory Data Analysis, EDA)은 모델링 전에 데이터의 분포·관계·패턴을 눈으로 확인하는 단계입니다. Matplotlib와 seaborn이 기본 도구입니다.

```python
import matplotlib.pyplot as plt
import seaborn as sns

# 범주별 카운트
sns.countplot(data=titanic_df, x="Pclass", hue="Survived")
plt.show()

# 수치 분포
sns.histplot(titanic_df["Age"].dropna(), bins=20)
plt.show()

# 상관관계 히트맵
num_cols = ["Survived", "Pclass", "Age", "SibSp", "Parch", "Fare"]
corr = titanic_df[num_cols].corr()
sns.heatmap(corr, annot=True, cmap="coolwarm")
plt.show()
```

상관관계 히트맵은 변수 쌍마다 피어슨 상관계수를 색으로 보여 줍니다. `1`에 가까우면 같이 증가, `-1`에 가까우면 반대 방향, `0` 근방이면 선형 관계가 약한 상태입니다. "어떤 피처가 `Survived`와 가장 강하게 얽혀 있는가"를 한눈에 파악할 수 있습니다.

## 8. 피처 선택 - 쓸 피처만 남기기

피처 수가 많을수록 모델이 과적합되기 쉽고 학습도 느려집니다. **피처 선택(Feature Selection)**은 "정답을 잘 설명하는 피처만 골라 쓰는" 작업입니다. 대표적인 기법 두 가지를 소개합니다.

```python
from sklearn.feature_selection import SelectKBest, f_classif, RFE
from sklearn.tree import DecisionTreeClassifier

X = titanic_df[["Pclass", "Sex_label", "Age", "SibSp", "Parch", "Fare"]]
y = titanic_df["Survived"]

# (1) 통계적 검정 기반 - F-통계량 상위 k개
selector = SelectKBest(score_func=f_classif, k=4)
X_sel = selector.fit_transform(X, y)

# (2) 모델 기반 순환 제거 - RFE
rfe = RFE(estimator=DecisionTreeClassifier(), n_features_to_select=4)
X_rfe = rfe.fit_transform(X, y)
```

- **SelectKBest**: 각 피처와 라벨 사이의 통계적 연관성(예: ANOVA F-value)을 계산해 점수 상위 k 개만 남김
- **RFE (Recursive Feature Elimination)**: 모델을 학습시키고 중요도가 낮은 피처를 하나씩 제거하는 과정을 반복

피처 중요도는 Part 5 Ch 07의 **설명가능 AI** 에서도 다시 등장하는 핵심 개념이므로 여기서 감만 잡아 둡니다.

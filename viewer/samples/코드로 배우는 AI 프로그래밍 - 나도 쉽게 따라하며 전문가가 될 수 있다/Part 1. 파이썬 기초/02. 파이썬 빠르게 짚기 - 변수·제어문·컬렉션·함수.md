# 02. 파이썬 빠르게 짚기 - 변수·제어문·컬렉션·함수

> 파이썬을 처음 접하신다면 이 챕터 하나로 입문하기보다는 공식 튜토리얼과 병행하시길 권합니다. 건너뛰어도 되는지 판단하는 기준은 바로 아래 1번 항목에 있습니다.

## 1. 이 챕터를 건너뛰어도 되는지 빠른 체크

아래 코드가 한눈에 읽힌다면 이 챕터는 건너뛰어도 괜찮습니다.

```python
nums = [x ** 2 for x in range(5) if x % 2 == 0]
names = {"alice": 90, "bob": 78}
for name, score in names.items():
    tag = "pass" if score >= 80 else "fail"
    print(f"{name}: {score} ({tag})")
```

낯선 문법이 있다면 해당 섹션만 골라 읽어도 됩니다. AI 실습에서 자주 등장하는 패턴 중심으로 정리했으므로, 파이썬 전반을 깊게 다루지는 않습니다.

## 2. 변수와 기본 자료형

파이썬은 변수 선언 시 자료형을 명시하지 않습니다. 대입하는 값에 따라 자료형이 자동으로 결정됩니다.

```python
x = 10          # int
y = 3.14        # float
name = "Alice"  # str
ok = True       # bool
nothing = None  # NoneType
```

자료형 확인은 `type()`, 변환은 `int()`·`float()`·`str()`·`bool()` 같은 내장 함수로 합니다.

```python
type(x)        # <class 'int'>
str(x)         # '10'
int("42")      # 42
float("3.14")  # 3.14
```

## 3. 연산자

산술·비교·논리 연산자는 대부분의 언어와 비슷합니다. 파이썬 고유의 특징만 짚어 두면 충분합니다.

```python
7 / 2    # 3.5   (실수 나눗셈)
7 // 2   # 3     (정수 나눗셈)
7 % 2    # 1     (나머지)
2 ** 10  # 1024  (거듭제곱)

a, b = 3, 5
a == b       # False
a != b       # True
(a < b) and (b < 10)  # True
not (a == b)          # True
```

문자열도 `+`로 연결하고 `*`로 반복할 수 있습니다.

```python
"hello" + " " + "world"  # 'hello world'
"ab" * 3                  # 'ababab'
```

문자열 포맷은 **f-string**이 가장 간결합니다.

```python
name, score = "Bob", 88
f"{name} 님의 점수는 {score}점"  # 'Bob 님의 점수는 88점'
f"{3.14159:.2f}"                   # '3.14'
```

## 4. 입출력과 내장 함수·모듈

콘솔 입출력은 `print()`, `input()`으로 처리합니다. `input()`은 항상 문자열을 반환하므로 숫자가 필요하면 형변환을 거칩니다.

```python
print("값:", 42)

age = int(input("나이를 입력: "))
```

자주 쓰이는 내장 함수는 다음과 같습니다.

```python
len([1, 2, 3])          # 3
sum([1, 2, 3])          # 6
max([1, 9, 5])          # 9
min([1, 9, 5])          # 1
sorted([3, 1, 2])       # [1, 2, 3]
range(5)                # range(0, 5)  (순회 시 0,1,2,3,4 를 차례로 생성)
abs(-7)                 # 7
round(3.14159, 2)       # 3.14
```

모듈은 `import`로 불러옵니다. 표준 라이브러리만으로도 수학·난수·파일 처리 등 상당한 작업이 가능합니다.

```python
import math
import random

math.sqrt(16)          # 4.0
math.pi                # 3.141592653589793

random.randint(1, 6)   # 1~6 사이 정수
random.choice(["a", "b", "c"])  # 요소 중 하나
```

## 5. 제어문

### 5.1 if / elif / else

들여쓰기로 블록을 구분합니다. 중괄호가 없으므로 동일 들여쓰기가 같은 블록입니다.

```python
score = 82

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"
```

간단한 조건은 삼항식으로 한 줄에 씁니다.

```python
tag = "pass" if score >= 60 else "fail"
```

### 5.2 for

`for`는 "반복 가능한 것"을 순회합니다. `range()`·리스트·문자열·딕셔너리 모두 동일하게 다뤄집니다.

```python
for i in range(3):       # 0, 1, 2
    print(i)

for ch in "abc":         # 'a', 'b', 'c'
    print(ch)

scores = [90, 75, 82]
for s in scores:
    print(s)
```

인덱스와 값을 같이 쓰고 싶다면 `enumerate`, 두 리스트를 나란히 순회하려면 `zip`이 편리합니다.

```python
for i, name in enumerate(["a", "b", "c"]):
    print(i, name)           # 0 a / 1 b / 2 c

names = ["alice", "bob"]
ages  = [30, 25]
for name, age in zip(names, ages):
    print(name, age)
```

### 5.3 while

종료 조건이 분명하지 않은 반복에 쓰입니다. `break`로 루프를 즉시 탈출하고, `continue`로 이번 반복만 건너뛸 수 있습니다.

```python
# break: 조건을 만나면 루프 탈출
n = 0
while True:
    if n == 3:
        break
    print(n)
    n += 1
# 0, 1, 2 출력

# continue: 이번 반복만 건너뛰고 다음으로
n = 0
while n < 5:
    n += 1
    if n == 3:
        continue
    print(n)
# 1, 2, 4, 5 출력
```

## 6. 컬렉션

AI 실습에서 가장 자주 다루는 자료구조입니다. 네 가지 모두 최소 사용법 위주로만 정리합니다.

### 6.1 리스트 (list)

순서가 있고 중복을 허용하며 수정이 가능합니다. 대괄호로 씁니다.

```python
nums = [3, 1, 4, 1, 5]
nums[0]          # 3
nums[-1]         # 5  (뒤에서 첫 번째)
nums[1:3]        # [1, 4]  (슬라이스)

nums.append(9)   # 뒤에 추가
nums.sort()      # 제자리 정렬
len(nums)        # 길이
```

2차원 리스트는 "리스트의 리스트" 형태로 표현합니다. 수치 연산이 본격적으로 필요해지면 NumPy의 `ndarray`로 넘어가며, 이는 다음 챕터에서 다룹니다.

```python
grid = [
    [1, 2, 3],
    [4, 5, 6],
]
grid[1][2]       # 6
```

### 6.2 리스트 컴프리헨션

반복·필터·변환을 한 줄로 표현합니다. AI 실습에서 데이터 전처리 시 자주 등장합니다.

```python
squares = [x ** 2 for x in range(5)]
# [0, 1, 4, 9, 16]

evens = [x for x in range(10) if x % 2 == 0]
# [0, 2, 4, 6, 8]

# 변환과 필터를 함께
even_squares = [x ** 2 for x in range(5) if x % 2 == 0]
# [0, 4, 16]
```

### 6.3 튜플 (tuple)

한 번 만들면 수정할 수 없습니다. 소괄호로 쓰거나 괄호 없이 쉼표로 구분해도 됩니다. 여러 값을 한꺼번에 반환하거나 분해할 때 유용합니다.

```python
point = (3, 5)
x, y = point     # 언패킹: x=3, y=5

def min_max(xs):
    return min(xs), max(xs)

lo, hi = min_max([4, 2, 7])  # lo=2, hi=7
```

### 6.4 세트 (set)

중복이 없고 순서가 없는 집합입니다. 중복 제거와 집합 연산에 강합니다.

```python
a = {1, 2, 3, 2, 1}   # {1, 2, 3}
b = {3, 4, 5}

a & b   # {3}         교집합
a | b   # {1,2,3,4,5} 합집합
a - b   # {1, 2}      차집합
```

### 6.5 딕셔너리 (dict)

키-값 쌍으로 값에 접근합니다. AI 실습에서 설정·레이블·빈도 계산 등에 폭넓게 쓰입니다.

```python
scores = {"alice": 90, "bob": 78, "carol": 85}
scores["alice"]          # 90
scores["dave"] = 72      # 추가

for name, score in scores.items():
    print(name, score)

"alice" in scores         # True
scores.get("eve", 0)      # 키가 없으면 기본값 0 반환
```

### 6.6 네 컬렉션 비교 요약

| 자료형 | 순서 | 중복 | 수정 | 대표 용도 |
|---|---|---|---|---|
| list | 있음 | 허용 | 가능 | 순차 데이터, 샘플 목록 |
| tuple | 있음 | 허용 | 불가 | 고정된 값 묶음, 함수 다중 반환 |
| set | 없음 | 불허 | 가능 | 중복 제거, 집합 연산 |
| dict | 있음(삽입 순) | 키 중복 불허 | 가능 | 키로 조회, 매핑 |

## 7. 함수

`def`로 정의하고 `return`으로 값을 돌려줍니다. 여러 값을 돌려줄 때는 튜플이 자동으로 쓰입니다.

```python
def add(a, b):
    return a + b

def stats(xs):
    return min(xs), max(xs), sum(xs) / len(xs)

lo, hi, mean = stats([1, 2, 3, 4, 5])
```

기본값·키워드 인자·가변 인자를 조합하면 유연하게 쓸 수 있습니다.

```python
def greet(name, greeting="안녕", emphasis=1):
    return f"{greeting}, {name}" + "!" * emphasis

greet("Alice")                          # '안녕, Alice!'
greet("Bob", emphasis=3)                 # '안녕, Bob!!!'
greet("Carol", greeting="Hi")            # 'Hi, Carol!'
```

간단한 함수는 `lambda`로 이름 없이 한 줄에 정의할 수 있습니다. `sorted`의 `key`, pandas의 `apply` 같이 "콜백" 형태로 함수를 전달해야 할 때 자주 보입니다.

```python
square = lambda x: x ** 2
square(5)  # 25

pairs = [(1, "b"), (3, "a"), (2, "c")]
sorted(pairs, key=lambda p: p[1])
# [(3, 'a'), (1, 'b'), (2, 'c')]
```

## 8. 파이썬스러운 표현 몇 가지

AI 실습 코드에서 자주 마주치지만 초심자가 멈칫하기 쉬운 표현들을 모아 둡니다.

```python
# 여러 변수 동시 대입
a, b, c = 1, 2, 3

# 두 값 교환 (임시 변수 없이)
a, b = b, a

# 언더스코어로 값 무시
_, remainder = divmod(17, 5)   # remainder=2

# in 연산자로 포함 여부 검사
"py" in "python"       # True
3 in [1, 2, 3]          # True

# any / all
all([True, True, False])   # False
any([False, False, True])  # True

# zip + dict로 두 리스트를 매핑으로 변환
keys = ["a", "b", "c"]
vals = [1, 2, 3]
mapping = dict(zip(keys, vals))   # {'a': 1, 'b': 2, 'c': 3}
```

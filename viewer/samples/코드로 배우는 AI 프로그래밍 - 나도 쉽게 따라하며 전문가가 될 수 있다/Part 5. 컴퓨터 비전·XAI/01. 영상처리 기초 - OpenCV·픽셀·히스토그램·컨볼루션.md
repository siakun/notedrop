# 01. 영상처리 기초 - OpenCV·픽셀·히스토그램·컨볼루션

> 컴퓨터 비전의 현대 실무는 대부분 CNN 기반이지만, 그 전·후단에는 여전히 전통 영상처리 도구가 깔려 있습니다. 이 챕터에서는 OpenCV로 영상을 읽고, 픽셀·히스토그램·컨볼루션을 다루는 최소 감각을 익힙니다. 이 도구들은 뒤의 전처리 파이프라인·전통 CV 실전·전이학습 챕터에서도 반복 등장합니다.

## 1. 컴퓨터 비전이란

**컴퓨터 비전(Computer Vision, CV)**은 "이미지·영상에서 의미 있는 정보를 뽑아내는" 분야입니다. 분류(고양이/강아지)·검출(얼굴 위치)·분할(픽셀 단위 객체 마스크)·생성(새 이미지) 등 세부 영역이 많지만, 공통적으로 "픽셀 배열을 다룬다"는 점에서 묶입니다.

실무에서 CV 파이프라인은 대개이 순서로 흘러갑니다.

```text
원본 이미지
  -> 전처리 (크기 조정·색공간 변환·노이즈 제거)
  -> 피처 추출 (컨볼루션·엣지·CNN 임베딩 등)
  -> 판단 (분류·검출·분할)
  -> 후처리·시각화
```

앞서 Part 4 Ch 03에서 본 CNN이 피처 추출·판단 단계를 통합해 처리한다면, 전처리와 후처리는 OpenCV 같은 라이브러리가 맡는 경우가 많습니다. 두 도구는 경쟁이 아니라 보완 관계입니다.

## 2. OpenCV 설치와 첫 이미지 로드

Python 에서는 `opencv-python` 패키지가 표준입니다.

```bash
pip install opencv-python
```

설치 뒤에는 `cv2`라는 이름으로 불러옵니다.

```python
import cv2
import numpy as np

img = cv2.imread("sample.jpg")      # 이미지 로드
img.shape                             # (H, W, 3)  - 높이, 너비, 채널 수
img.dtype                             # dtype('uint8') - 0~255
```

중요한 특이점 한 가지: OpenCV는 이미지를 **BGR 순서**로 읽습니다. Matplotlib 나 Pillow는 RGB 이므로, 같은 이미지를 두 라이브러리로 다루면 빨강·파랑이 뒤바뀌어 보입니다. 변환은 `cvtColor`로 간단합니다.

```python
import matplotlib.pyplot as plt

img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
plt.imshow(img_rgb); plt.axis("off"); plt.show()
```

## 3. 디지털 영상의 구조

연속된 빛의 세기를 격자 단위로 잘라 각 칸의 값을 대표 숫자로 정한 결과가 디지털 이미지입니다. 격자를 나누는 단계를 **샘플링(sampling)**, 각 칸의 값을 유한한 단계로 반올림하는 단계를 **양자화(quantization)**라 부릅니다. 8 비트 이미지는 양자화 단계가 `L = 256` 이어서 픽셀 값이 0 ~ 255 사이의 정수로 들어옵니다.

한 장의 이미지는 결국 **3 차원 NumPy 배열** 입니다. `(H, W, 3)`에서 세 번째 축이 색 채널입니다. 흑백 이미지는 `(H, W)`의 2 차원 배열로 읽힙니다.

```python
# 픽셀 하나에 접근
img[100, 200]           # [B, G, R] = [우측 200, 아래 100 위치의 픽셀]

# 한 채널만 추출
blue  = img[:, :, 0]
green = img[:, :, 1]
red   = img[:, :, 2]

# 특정 영역 잘라내기 (Region of Interest)
roi = img[50:150, 80:180]     # 100x100 patch
```

`uint8` 타입이 기본입니다. 픽셀 값은 0 ~ 255 범위이고, 산술 연산 시 범위를 넘으면 오버플로우가 발생할 수 있으므로 주의해야 합니다. 이 성질은 바로 아래 4.2 절에서 다시 설명합니다.

## 4. 점 연산 - 픽셀 하나씩 독립 변환

**점 연산(point operation)**은 한 픽셀의 값을 그 픽셀만의 함수로 바꾸는 연산입니다. 주변 픽셀을 참조하지 않아 구현이 단순하고 빠릅니다.

### 4.1 이미지 반전 (Negative)

모든 픽셀 값을 255에서 빼면 필름 네거티브 효과가 납니다.

```python
neg = 255 - img
```

`img`가 `uint8` 이고 `255 - img`의 결과는 항상 `0 ~ 255` 사이라 이 연산은 오버플로우 걱정 없이 그대로 써도 안전합니다.

### 4.2 밝기 조정과 오버플로우

상수를 더하거나 빼면 전체 밝기가 조정됩니다. 단, NumPy의 `uint8` 덧셈은 255를 넘으면 **250 + 10 = 4** 처럼 한 바퀴 돌아 들어옵니다. 이를 **wrap-around**라 부르고, 반대로 255에 고정시키는 방식을 **saturation**이라 합니다. `cv2.add`가 saturation 방식이며, 또는 int로 타입을 올려 `np.clip` 한 뒤 다시 `uint8`로 내리는 방법을 쓸 수 있습니다.

```python
# 위험한 방법 (오버플로우 발생 가능)
bright_bad = img + 50

# 안전한 방법 1: cv2.add는 자동 saturation
bright = cv2.add(img, 50)

# 안전한 방법 2: 타입 확장 후 clip
bright2 = np.clip(img.astype(np.int32) + 50, 0, 255).astype(np.uint8)
```

### 4.3 흑백 변환

가중 평균으로 채널을 섞어 1 채널 영상으로 바꿉니다. OpenCV가 표준 계수를 이미 구현해 두었습니다.

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)   # (H, W) 2D 배열
gray.shape
```

### 4.4 감마 보정

감마 값 `γ`를 이용해 어두운 부분·밝은 부분의 비선형 톤 매핑을 수행합니다. 전처리로 조명 편차를 줄이거나 디스플레이 감마 보정에 자주 쓰입니다. 아래 코드에서는 관례적으로 `γ < 1` 일 때 "어둡게", `γ > 1` 일 때 "밝게" 되도록 지수에 `1/γ`를 쓰므로 수식으로 적으면 다음과 같습니다.

```text
out = 255 * (in / 255) ^ (1 / γ)
```

```python
def gamma_correct(img, gamma=0.5):
    inv = 1.0 / gamma
    table = np.array([((i / 255.0) ** inv) * 255
                      for i in range(256)]).astype(np.uint8)
    return cv2.LUT(img, table)

dark = gamma_correct(img, gamma=0.5)    # 어둡게
light = gamma_correct(img, gamma=2.0)   # 밝게
```

`cv2.LUT` (Look-Up Table)은 점 연산을 한 번에 빠르게 적용하는 유틸입니다. 이 장의 구현은 `1 / gamma`를 지수로 쓰는 정의를 사용합니다. 그래서 `gamma < 1` 이면 어두워지고, `gamma > 1` 이면 밝아집니다.

### 4.5 두 영상 블렌딩 (Scene Dissolve)

두 영상을 `α : (1 - α)` 비율로 섞으면 장면 전환 효과가 나옵니다.

```python
img1 = cv2.imread("scene1.jpg")
img2 = cv2.imread("scene2.jpg")
# 두 이미지 크기가 같다고 가정

for alpha in np.linspace(0, 1, 20):
    blended = cv2.addWeighted(img1, 1 - alpha, img2, alpha, 0)
    # blended를 저장하거나 표시
```

## 5. 히스토그램

**히스토그램(histogram)**은 "각 밝기(0~255)가 이미지에 몇 픽셀 등장하는가"를 막대그래프로 나타낸 것입니다. 이미지의 노출·대비·분포를 한눈에 파악할 수 있어 전처리 판단의 첫걸음입니다.

```python
hist = cv2.calcHist([gray], [0], None, [256], [0, 256])
# hist.shape == (256, 1)

plt.plot(hist); plt.xlim([0, 256]); plt.show()
```

### 5.1 히스토그램 평활화 (Equalization)

히스토그램이 특정 구간에 몰려 있으면 영상이 뿌옇거나 어둡게 보입니다. **평활화**는 누적 분포를 이용해 밝기 분포를 전 구간으로 펼치는 연산입니다. 대비가 낮은 의료 영상·야간 사진에서 특히 효과가 큽니다.

```python
eq = cv2.equalizeHist(gray)
```

컬러 이미지에 적용하려면 채널을 모두 평활화하지 않고, 색공간을 `YCrCb`로 바꿔 **밝기 채널만** 평활화하는 것이 일반적입니다.

```python
ycrcb = cv2.cvtColor(img, cv2.COLOR_BGR2YCrCb)
y, cr, cb = cv2.split(ycrcb)
y_eq = cv2.equalizeHist(y)
result = cv2.cvtColor(cv2.merge([y_eq, cr, cb]), cv2.COLOR_YCrCb2BGR)
```

## 6. 컨볼루션 기초

**컨볼루션(convolution)**은 이미지 위에서 작은 커널을 슬라이딩하며 각 위치에서 가중합을 계산하는 연산입니다. CNN의 `Conv2D`가 학습된 커널을 쓰는 것과 달리, 영상처리에서는 **사람이 설계한 커널**을 씁니다.

### 6.1 박스 마스크 - 평균 블러

가장 단순한 스무딩 커널입니다. 주변 픽셀의 평균값으로 노이즈를 줄입니다.

```python
k = np.ones((5, 5), np.float32) / 25.0     # 5x5 평균 커널
smooth = cv2.filter2D(img, -1, k)

# OpenCV 편의 함수
smooth2 = cv2.blur(img, (5, 5))
```

### 6.2 엣지 검출 마스크

수평·수직 방향 변화량을 포착하는 커널입니다. 픽셀이 급격히 바뀌는 경계에서 큰 값을 냅니다.

```python
# 수평 방향 변화
kernel_h = np.array([[-1, 0, 1],
                     [-2, 0, 2],
                     [-1, 0, 1]], np.float32)
edge_h = cv2.filter2D(gray, -1, kernel_h)

# 수직 방향 변화
kernel_v = np.array([[-1, -2, -1],
                     [ 0,  0,  0],
                     [ 1,  2,  1]], np.float32)
edge_v = cv2.filter2D(gray, -1, kernel_v)
```

위 두 커널이 **Sobel 연산자** 이고, OpenCV는 `cv2.Sobel`로 동일한 결과를 편리하게 제공합니다.

### 6.3 가우시안 필터

박스 평균은 모든 픽셀을 동등하게 섞지만, 실제로는 "가까운 픽셀이 더 비슷하다"는 가정이 자연스럽습니다. 중심 근처에 가중치가 더 큰 **가우시안 커널**이 그 가정을 반영합니다. 박스 블러보다 부드럽고, 경계의 계단 효과가 덜합니다.

```python
gauss = cv2.GaussianBlur(img, (5, 5), sigmaX=1.0)
```

가우시안 필터는 실무 전처리에서 가장 자주 쓰이는 스무딩 방법이자, 다음 챕터(색공간 변환·이진화·엣지 검출)의 흔한 선행 단계입니다.

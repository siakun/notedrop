# 02. 영상 전처리 파이프라인 - 색공간·노이즈·에지·모폴로지

> 앞 챕터가 "영상을 숫자로 다루는 기본 도구" 였다면, 이 챕터는 "관심 있는 픽셀만 남기는 방법"을 다룹니다. 색공간 변경, 이진화, 노이즈 제거, 경계 강화 같은 전처리 도구를 차례로 살펴봅니다. 이 도구들은 Part 5 뒤의 실전 파이프라인에서 반복적으로 조합됩니다.

## 1. 색공간 - BGR·HSV·YCrCb

색은 여러 방식으로 표현할 수 있고, 각 표현마다 다루기 쉬운 정보가 다릅니다.

- **BGR (= RGB)**: OpenCV 기본 순서. 디스플레이·저장에는 자연스럽지만 "이 색이 얼마나 붉은가" 같은 질문에 바로 답하기 어려움
- **HSV**: Hue(색조)·Saturation(채도)·Value(명도)로 분리. 조명 변화에 가장 민감한 Value를 분리해 두어, **"색 자체" 만으로 영역을 분할** 하기 좋음
- **YCrCb**: 밝기(Y)와 색차(Cr, Cb) 분리. JPEG·동영상 압축에서 표준적으로 쓰이는 표현. 얼굴 검출이나 피부색 검출에 유리

```python
import cv2

img = cv2.imread("sample.jpg")
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
ycrcb = cv2.cvtColor(img, cv2.COLOR_BGR2YCrCb)
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
```

HSV에서 "빨간색 영역만"을 뽑으려면 Hue 채널에 구간 마스크를 씌웁니다.

```python
import numpy as np

h, s, v = cv2.split(hsv)
# OpenCV HSV는 H=0~179, S=0~255, V=0~255
red_mask = ((h < 10) | (h > 170)) & (s > 80) & (v > 80)
red_only = cv2.bitwise_and(img, img, mask=red_mask.astype(np.uint8) * 255)
```

HS 두 채널만 가지고 **2D 히스토그램**을 그리면, 피부색·하늘색처럼 "어떤 색이 어디에 얼마나 있는지"가 한눈에 보입니다.

```python
# H·S 각각을 32 단계로 양자화한 2D 히스토그램
hist_hs = cv2.calcHist(
    [hsv], channels=[0, 1], mask=None,
    histSize=[32, 32], ranges=[0, 180, 0, 256])
hist_hs = hist_hs / hist_hs.max()   # 0 ~ 1로 정규화
# hist_hs[h_bin, s_bin]에 해당 색 빈도가 누적돼 있음
```

`histSize`로 양자화 단계 수를 조절합니다. 단계가 많을수록 색 구분이 세밀해지지만 빈도가 흩어져 히스토그램이 듬성듬성해지므로, 보통 16 ~ 64 사이에서 목적에 맞게 고릅니다. 이 히스토그램을 "참조 샘플"로 삼아 새 이미지의 각 픽셀이 얼마나 비슷한 색인지 채점하는 **역투영(Back Projection)**은 이후 얼굴 검출(Part 5 Ch 03)의 핵심 아이디어입니다.

## 2. 이진화 - 전경과 배경 분리

**이진화(binarization)**는 흑백 이미지의 각 픽셀을 임계값 기준으로 0 / 255 둘 중 하나로 바꾸는 연산입니다. 윤곽선 추출·문자 인식·객체 분리의 흔한 첫 단계입니다.

### 2.1 고정 임계값

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
```

127은 중간값 기준의 단순 설정입니다. 조명이 균일하지 않으면 성능이 크게 떨어집니다.

### 2.2 Otsu 알고리즘 - 자동 임계값

**Otsu 방법**은 히스토그램을 보고 "전경과 배경 분산의 합이 최소가 되는" 임계값을 자동으로 찾아 줍니다. 이미지마다 임계값이 달라 수동 조정 없이도 잘 작동하는 경우가 많습니다.

```python
_, binary = cv2.threshold(gray, 0, 255,
                          cv2.THRESH_BINARY + cv2.THRESH_OTSU)
```

조명이 한 장 안에서도 크게 변하는 이미지에는 지역 기반 **적응형 임계값** 인 `cv2.adaptiveThreshold`가 한 단계 위의 옵션입니다.

## 3. 노이즈와 필터

### 3.1 Salt & Pepper 노이즈

CCD 센서의 불량 화소나 전송 오류 때문에 검은·흰 점이 무작위로 찍히는 현상을 **Salt & Pepper 노이즈**라 합니다. 직접 만들어 실험해 볼 수 있습니다.

```python
def add_salt_pepper(img, amount=0.02):
    out = img.copy()
    n = int(amount * img.size)
    for _ in range(n // 2):
        y, x = np.random.randint(0, img.shape[0]), np.random.randint(0, img.shape[1])
        out[y, x] = 255
    for _ in range(n // 2):
        y, x = np.random.randint(0, img.shape[0]), np.random.randint(0, img.shape[1])
        out[y, x] = 0
    return out

noisy = add_salt_pepper(gray, amount=0.02)
```

### 3.2 Median Filter

S&P 같은 **극단값 노이즈** 에는 앞 챕터의 Gaussian 블러보다 **Median Filter**가 훨씬 효과적입니다. 커널 안의 값을 정렬해 중간값을 대표값으로 쓰므로, 극단값이 결과에 영향을 거의 못 줍니다.

```python
clean3 = cv2.medianBlur(noisy, 3)
clean5 = cv2.medianBlur(noisy, 5)
```

일반적인 가우시안 노이즈에는 여전히 Gaussian 블러가 낫습니다. "노이즈 종류에 맞는 필터를 고르는" 감각이 중요합니다.

## 4. 모폴로지 - 이진 영상 다듬기

이진화 결과에는 작은 구멍이나 외곽 노이즈가 남기 마련입니다. **모폴로지(morphology)**는 이를 정리하는 집합 기반 연산입니다. 구조 요소(Structuring Element, SE)라는 작은 모양을 이미지 위에서 이동시키며 처리합니다.

| 연산 | 정의 | 효과 |
|---|---|---|
| **침식(Erosion)** | SE 전체가 전경 안에 들어가는 지점만 전경으로 | 얇은 가지·노이즈 제거, 전경 축소 |
| **팽창(Dilation)** | SE 일부라도 전경에 닿는 지점을 전경으로 | 구멍·틈 메우기, 전경 확장 |
| **Opening** | Erosion -> Dilation | **노이즈 제거** (작은 전경 제거, 크기 유지) |
| **Closing** | Dilation -> Erosion | **구멍 메우기** (큰 전경 유지, 작은 구멍 닫기) |

```python
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))

eroded  = cv2.erode(binary, kernel, iterations=1)
dilated = cv2.dilate(binary, kernel, iterations=1)
opened  = cv2.morphologyEx(binary, cv2.MORPH_OPEN,  kernel)
closed  = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)
```

실무에서는 이진화 직후 `Opening`으로 작은 잡음을 털고, 이어서 `Closing`으로 큰 객체 안의 구멍을 메우는 2 단계 조합이 가장 흔합니다.

명암(grayscale) 이미지에도 같은 개념이 적용되는 **명암 모폴로지**가 있습니다. 3x3 이웃의 **최댓값**을 취하면 Dilation, **최솟값**을 취하면 Erosion이 됩니다.

OpenCV `cv2.dilate`·`cv2.erode`는 이진·명암 모두 같은 API로 처리하므로 호출 방식 변경 없이 쓸 수 있습니다. 문자 인식 전 배경 보정, 질감 분석, 조명 불균일 보정 등에 활용됩니다.

## 5. 에지 검출

**에지(edge)**는 픽셀 값이 급격히 변하는 지점입니다. 경계를 찾는 이 단계는 객체 분리·윤곽 추출의 출발점입니다.

### 5.1 Sobel - 1차 미분

앞 챕터에서 짚었듯, Sobel 커널은 수평·수직 방향 기울기를 계산해 방향별 에지를 추출합니다. 두 방향을 합쳐 강도 맵을 얻는 것이 표준입니다.

```python
gx = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
gy = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)
mag = cv2.magnitude(gx, gy)           # sqrt(gx^2 + gy^2)
mag = np.uint8(np.clip(mag, 0, 255))
```

`cv2.CV_64F`를 쓰는 이유는 음수 값을 보존하기 위함입니다. 마지막에 `uint8`로 내리기 전에 절댓값 또는 magnitude로 양수화합니다.

그래디언트의 크기뿐 아니라 **방향**도 중요한 정보입니다. `θ = arctan(gy / gx)`로 계산하고, 에지는 이 그래디언트에 수직 방향으로 뻗어 있습니다. 후속 알고리즘(특히 Canny NMS)은 이 θ 값을 `0°·45°·90°·135°` 네 방향으로 양자화해 "비교할 이웃 두 픽셀"을 결정합니다.

### 5.2 LoG - 2차 미분 기반

**Laplacian of Gaussian (LoG)**는 Gaussian 블러 뒤에 Laplacian을 적용한 필터입니다. 2차 미분의 부호가 바뀌는 지점(**zero-crossing**)을 에지로 잡아, 1차 미분보다 경계가 얇고 일관되게 떨어집니다.

```python
blurred = cv2.GaussianBlur(gray, (5, 5), sigmaX=1.0)
log = cv2.Laplacian(blurred, cv2.CV_64F, ksize=3)
```

영교차 판정은 단순히 부호가 바뀐 픽셀을 모두 고르면 노이즈까지 따라 들어오므로, 실무 구현은 두 조건을 함께 봅니다.

1. 중심 픽셀의 **상하·좌우·두 대각선 4 쌍** 중 **2 쌍 이상**에서 부호가 바뀔 것
2. 부호가 바뀐 쌍의 값 차이(절댓값)가 임계값을 넘을 것

이 두 조건을 같이 걸면 약한 떨림은 걸러지고 실제 경계만 살아남습니다.

### 5.3 Canny - 실무 표준

**Canny** (John Canny, 1986)는 현재도 가장 널리 쓰이는 에지 검출기입니다. 네 단계로 동작합니다.

1. **Gaussian 블러**로 노이즈 제거
2. **Sobel 기반 기울기 크기·방향** 계산
3. **Non-maximum Suppression**: 기울기 방향으로 가장 강한 픽셀만 남김 (얇은 에지)
4. **Hysteresis Thresholding**: 높은 임계값으로 강한 에지를 정하고, 낮은 임계값의 픽셀은 이 강한 에지에 연결돼 있을 때만 유지 (연속성 확보)

```python
edges = cv2.Canny(gray, threshold1=50, threshold2=150)
```

두 임계값 비율은 대략 `1:2 ~ 1:3`이 관례이며, 이미지마다 조정합니다. Canny는 깔끔한 이진 에지맵을 돌려주므로, 다음 단계의 윤곽선 추출·Hough 변환 입력으로 바로 쓰기에 좋습니다.

내부적으로 Hysteresis 단계는 **BFS 씨앗 확장**과 비슷하게 동작합니다. 높은 임계값을 넘은 픽셀을 "씨앗"으로 시작해, 그와 연결된 약한 에지까지 살려 내기 때문에 끊어진 경계를 더 연속적으로 이어 붙일 수 있습니다.

## 6. 기하 연산 - 회전과 보간

물체가 회전해 있거나 크기가 다른 경우가 흔합니다. **기하 변환(geometric transform)**은 픽셀의 위치를 옮기는 연산입니다. 구현 방식은 크게 두 가지입니다. 원본의 각 `(x, y)`를 목표 위치로 보내는 **순방향 매핑**은 반올림 때문에 결과에 구멍(hole)이 생기기 쉽고, 반대로 **역방향 매핑**은 타깃의 각 `(x', y')`에 대해 "어느 원본 픽셀을 가져올지"를 계산해 빈틈이 생기지 않습니다. OpenCV의 `warpAffine`은 내부적으로 역방향 매핑과 보간을 묶어 수행합니다.

```python
h, w = img.shape[:2]
M = cv2.getRotationMatrix2D((w // 2, h // 2), angle=30, scale=1.0)
rotated = cv2.warpAffine(img, M, (w, h),
                          flags=cv2.INTER_LINEAR)
```

회전·확대·축소에서는 "원본에 없는 위치의 값"을 만들어야 하므로 **보간법(interpolation)**이 필요합니다.

- **Nearest (cv2.INTER_NEAREST)**: 가장 가까운 픽셀 값. 속도 최고, 계단 현상
- **Bilinear (cv2.INTER_LINEAR, 기본값)**: 주변 4 픽셀의 가중 평균. 부드러움·속도 균형
- **Bicubic (cv2.INTER_CUBIC)**: 주변 16 픽셀 사용, 더 부드러움
- **Lanczos (cv2.INTER_LANCZOS4)**: 품질 우선, 연산량 가장 큼

실무에서는 기본 Bilinear로 시작해, 축소·확대 품질이 필요해지면 위 순서로 올려 씁니다.

## 7. 다해상도 처리 - 이미지 피라미드

이미지를 반씩 줄여 쌓은 것을 **이미지 피라미드**라 부릅니다. 객체 탐지에서 "같은 커널로 다른 크기의 객체를 검출" 하거나, 처리 속도를 내고 싶을 때 저해상도에서 먼저 계산해 실마리를 잡는 식으로 활용됩니다.

```python
down1 = cv2.pyrDown(img)          # 1/2로 축소
down2 = cv2.pyrDown(down1)        # 1/4로 축소
up    = cv2.pyrUp(down2)          # 다시 2 배 확대
```

단순히 2 배 축소를 하면 홀수 열·행의 픽셀이 통째로 버려져 고주파 성분이 에일리어싱으로 되돌아옵니다. `pyrDown`은 먼저 5x5 Gaussian 커널로 가중합을 구해 **주변 픽셀 전체가 결과에 기여** 하게 만든 뒤 다운샘플링하므로, 원본 색이 고루 녹아들고 에일리어싱이 눈에 띄게 줄어듭니다. 단순 `cv2.resize`보다 안전한 축소 방법이며, 이미지 피라미드 외에도 멀티스케일 매칭·고속 객체 탐지에서 전처리로 자주 쓰입니다.

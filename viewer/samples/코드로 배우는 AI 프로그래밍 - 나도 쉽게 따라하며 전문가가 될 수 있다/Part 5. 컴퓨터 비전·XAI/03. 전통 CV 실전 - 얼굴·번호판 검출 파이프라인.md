# 03. 전통 CV 실전 - 얼굴·번호판 검출 파이프라인

> 앞 두 챕터에서 쌓은 부품을 엮어 실제 문제 두 개를 풀어 봅니다. 얼굴 영역 검출은 색 기반 접근, 번호판 검출은 에지·윤곽선 기반 접근을 대표합니다. 이 장은 딥러닝 이전의 CV 엔지니어링 감각을 짧게 체험하는 챕터이기도 합니다. 이후 Part 5 Ch 05의 객체 탐지 모델이 어떤 한계를 해결하려 등장했는지도 자연스럽게 이어집니다.

## 1. 전통 CV 파이프라인의 구조

전통 CV 접근은 문제마다 다르지만 뼈대는 비슷합니다.

```text
원본 이미지
  -> 색공간 변환 (조명·색 분리)
  -> 블러·노이즈 제거
  -> 이진화 (전경·배경)
  -> 모폴로지 (잡음 정리·구멍 메우기)
  -> 연결 성분 분석 / 윤곽선 / 영역 제안
  -> 후보 필터링 (크기·비율·위치)
  -> 필요 시 회전·정렬
  -> 결과: 관심 영역의 좌표 박스
```

이 뼈대에 문제마다 특화된 조건(색 범위·에지 방향·비율 조건)을 덧붙입니다. 공통 감각은 "관심 픽셀을 가능한 한 이진 마스크로 추려낸 뒤, 구조 정보(위치·크기·비율)로 후보를 걸러낸다" 입니다.

## 2. 얼굴 영역 검출 파이프라인

사람 얼굴은 "색 분포"로 구분하기 좋은 객체입니다. 피부색이 HSV 공간에서 비교적 좁은 영역에 몰려 있기 때문입니다.

### 2.1 전략

1. 얼굴 샘플 이미지에서 **HS 2D 히스토그램**을 만들어 "피부색 분포"를 학습
2. 대상 이미지에 **역투영(Back Projection)**을 적용해 각 픽셀이 피부색에 얼마나 가까운지 스코어링
3. **이진화 + 모폴로지**로 스코어 맵을 깔끔한 마스크로 정리
4. **레이블링(연결 성분 분석)**으로 후보 영역 분리
5. **크기·비율 필터**로 비얼굴 후보 제거

### 2.2 역투영

역투영은 "참조 히스토그램에 등장한 색이면 높은 값, 아니면 낮은 값"을 픽셀 단위로 할당합니다.

```python
import cv2
import numpy as np

# 학습 단계: 얼굴 패치에서 HS 히스토그램 생성
face_patch = cv2.imread("face_sample.jpg")
face_hsv   = cv2.cvtColor(face_patch, cv2.COLOR_BGR2HSV)

model_hist = cv2.calcHist(
    [face_hsv], channels=[0, 1], mask=None,
    histSize=[16, 16], ranges=[0, 180, 0, 256])
cv2.normalize(model_hist, model_hist, 0, 255, cv2.NORM_MINMAX)

# 추론 단계: 대상 이미지에 역투영
target = cv2.imread("group_photo.jpg")
target_hsv = cv2.cvtColor(target, cv2.COLOR_BGR2HSV)

score = cv2.calcBackProject(
    [target_hsv], channels=[0, 1], hist=model_hist,
    ranges=[0, 180, 0, 256], scale=1)
# 역투영 결과를 0~255로 재스케일해 시각화·이진화에 편리하게 만듭니다.
cv2.normalize(score, score, 0, 255, cv2.NORM_MINMAX)
```

양자화 단계 수(`histSize`)는 검출 품질에 꽤 영향을 줍니다. 단계가 너무 많으면(예: 64 단계) 빈도가 흩어져 얼굴 내부도 듬성듬성한 스코어가 나오고, 너무 적으면(예: 8 단계) 배경까지 같이 잡힙니다. 피부색처럼 좁고 진한 색 영역을 찾는 경우에는 `8 ~ 32` 사이에서 조정하는 것이 실전 감각이며, 이 책은 16을 기본값으로 씁니다.

`score`는 같은 크기의 흑백 이미지이며, 피부색에 가까울수록 밝게 표시됩니다.

### 2.3 이진화와 모폴로지로 마스크 정리

```python
# 가우시안 블러로 점 단위 스파이크 제거
score = cv2.GaussianBlur(score, (5, 5), 0)

# Otsu로 자동 이진화
_, mask = cv2.threshold(score, 0, 255,
                        cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# 작은 잡음 제거 + 구멍 메우기
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN,  kernel)
mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel, iterations=2)
```

순서가 중요합니다. `Opening`으로 점 노이즈를 먼저 털고 `Closing`으로 얼굴 내부의 작은 구멍을 메워야 깔끔한 영역이 남습니다. Otsu는 역투영 스코어 맵의 밝기 분포에 맞춰 임계값을 자동으로 결정합니다.

### 2.4 레이블링 - 연결 성분 분리

마스크에 남은 **연결된 흰색 덩어리 각각을 하나의 영역으로 식별** 하는 작업이 레이블링입니다. OpenCV는 `connectedComponentsWithStats` 한 줄로 제공합니다.

```python
n_labels, labels, stats, centroids = cv2.connectedComponentsWithStats(
    mask, connectivity=8)

# stats: (n_labels, 5) - [left, top, width, height, area]
#   - 인덱스 0 번 행은 이미지 전체 배경을 뜻하므로 크기·비율 필터 시 제외
# labels[y, x] = 해당 픽셀이 속한 덩어리 번호 (0 = 배경)
```

결과 시각화를 위해 덩어리마다 서로 다른 색을 지정할 때, `np.random.seed`로 시드를 고정하면 실행할 때마다 같은 색이 나와 디버깅이 수월합니다.

```python
np.random.seed(42)
colors = np.random.randint(0, 255, size=(n_labels, 3), dtype=np.uint8)
colors[0] = 0                                 # 배경은 검정
viz = colors[labels]                          # 고급 인덱싱으로 전체 컬러화
```

### 2.5 후보 필터링

모든 덩어리가 얼굴은 아닙니다. 크기·가로세로 비율로 비얼굴 후보를 걸러냅니다.

```python
faces = []
for i in range(1, n_labels):                  # 0은 배경
    x, y, w, h, area = stats[i]
    aspect = w / h
    if area < 500:           continue         # 너무 작음
    if not (0.5 < aspect < 1.5): continue     # 얼굴은 대체로 정사각형 근처
    faces.append((x, y, w, h))

# 원본에 박스 그리기
for (x, y, w, h) in faces:
    cv2.rectangle(target, (x, y), (x + w, y + h), (0, 255, 0), 2)
```

이 단순 색 기반 접근은 조명·인종·배경 색에 민감합니다. 같은 조건에서도 조명이 바뀌면 재학습이 필요하고, 손·팔 같은 다른 피부 영역도 같이 잡히는 약점이 있습니다. 이 한계를 Part 5 Ch 05의 CNN 기반 객체 탐지 모델이 해결합니다.

## 3. 번호판 검출 파이프라인

차량 번호판은 "사각형에 일정한 비율의 문자가 배치" 되어 있는 구조를 가집니다. 색보다는 **형태와 문자 배치**로 잡는 것이 효과적입니다.

### 3.1 전략

1. 회색조 변환 + 블러
2. **Canny** 또는 **Adaptive Threshold**로 에지·이진화
3. `findContours`로 윤곽선 추출
4. 각 윤곽의 **Bounding Rect**를 얻어 크기·비율 필터
5. 필터 통과한 박스들 중 **문자 그룹** (수평 배치·비슷한 크기)을 찾기
6. 그룹이 이룬 영역을 **회전 보정** 후 크롭

### 3.2 에지 기반 전처리

```python
img = cv2.imread("car.jpg")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# 1) 대비 증폭: TopHat·BlackHat으로 밝은 문자·어두운 문자 양쪽 강조
kernel_big = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
tophat = cv2.morphologyEx(gray, cv2.MORPH_TOPHAT,   kernel_big)
blackhat = cv2.morphologyEx(gray, cv2.MORPH_BLACKHAT, kernel_big)
enhanced = cv2.add(cv2.add(gray, tophat), -blackhat)

# 2) 블러 + Adaptive Threshold
blur = cv2.GaussianBlur(enhanced, (5, 5), 0)

edges = cv2.adaptiveThreshold(
    blur, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY_INV,
    blockSize=19, C=9,
)
```

TopHat은 배경보다 밝은 영역만 남기고(밝은 번호판 위 어두운 문자 반대 상황), BlackHat은 배경보다 어두운 영역만 남깁니다. 둘을 함께 더하고 빼면 "문자 경계의 대비"만 증폭되어 뒷단계 Adaptive Threshold가 깔끔한 문자 덩어리를 뽑아냅니다. 번호판 주변은 명암이 강하고 문자 경계도 선명하기 때문에이 전처리 체인이 특히 잘 맞습니다.

Canny 대신 Adaptive Threshold를 쓰는 이유는 명확합니다. Canny는 경계만 얇은 선으로 남기기 때문에 "문자의 내부"가 비어 있어 이후 윤곽선 추출·크기 필터가 예상처럼 작동하지 않습니다. 반면 Adaptive Threshold는 문자 내부가 채워진 **블롭(blob)**을 바로 돌려주므로 덩어리 기반 후보 탐색에 적합합니다.

### 3.3 윤곽선 추출과 BoundingRect

`findContours`는 이진 이미지에서 연결된 경계선을 찾아 좌표 리스트로 반환합니다. 내부적으로는 Suzuki와 Abe가 1985년 논문 *"Topological Structural Analysis of Digitized Binary Images by Border Following"* 에서 제안한 **경계선 추적(border following)** 알고리즘이 쓰입니다. 이 알고리즘은 외곽 경계(outer border)와 구멍 경계(hole border)를 구분해 계층 구조로 반환할 수 있습니다.

```python
contours, _ = cv2.findContours(
    edges, cv2.RETR_LIST, cv2.CHAIN_APPROX_SIMPLE)

char_boxes = []
for c in contours:
    x, y, w, h = cv2.boundingRect(c)
    area  = w * h
    ratio = w / h
    # 번호판 문자의 대략적 크기·비율
    if area < 80 or area > 1200:   continue
    if not (0.25 < ratio < 1.0):    continue
    char_boxes.append((x, y, w, h))
```

이 단계에서 남은 박스들은 "문자일 가능성이 있는 후보" 입니다. 아직 번호판 위치는 결정되지 않았습니다.

### 3.4 문자 그룹핑

번호판의 핵심 단서는 "**비슷한 크기의 문자 여러 개가 수평으로 일정 간격 배열** 되어 있다"는 것입니다. 이 제약을 써서 후보 박스들을 묶습니다.

```python
def find_plate(char_boxes, max_dy=10, max_dx_ratio=3.0, min_group=3):
    plates = []
    for i, (x1, y1, w1, h1) in enumerate(char_boxes):
        group = [(x1, y1, w1, h1)]
        for j, (x2, y2, w2, h2) in enumerate(char_boxes):
            if i == j:
                continue
            # 세로 중심선이 비슷하고, 가로 간격이 과하지 않으며, 높이가 유사
            if abs((y1 + h1 / 2) - (y2 + h2 / 2)) < max_dy and \
               0 < (x2 - (x1 + w1)) < max_dx_ratio * w1 and \
               0.7 < h1 / h2 < 1.3:
                group.append((x2, y2, w2, h2))
        if len(group) >= min_group:
            plates.append(group)
    return plates
```

세 가지 조건(세로 중심 일치·가로 간격 범위·높이 비슷)으로 "같은 줄의 문자들"을 묶고, 묶음 크기가 3 개 이상이면 번호판 후보로 채택합니다. 위 구현은 발상을 보여 주는 최소 예시입니다. 실제 프로덕션 코드에서는 중복 후보 제거, 그룹 병합, 재귀적 이웃 확장 같은 로직이 추가로 붙어야 합니다.

### 3.5 회전 보정과 크롭

차량 사진은 카메라 각도에 따라 번호판이 기울어 있을 수 있습니다. 문자 그룹의 회전각을 추정해 수평으로 바로 세운 뒤 크롭합니다.

```python
def rotate_plate(img, group):
    xs = [x + w / 2 for (x, y, w, h) in group]
    ys = [y + h / 2 for (x, y, w, h) in group]
    # 시작 문자와 끝 문자의 중심을 잇는 선의 기울기
    dx, dy = xs[-1] - xs[0], ys[-1] - ys[0]
    angle = np.degrees(np.arctan2(dy, dx))

    # 중심점 기준 회전
    cx, cy = np.mean(xs), np.mean(ys)
    M = cv2.getRotationMatrix2D((cx, cy), angle, 1.0)
    rotated = cv2.warpAffine(img, M, (img.shape[1], img.shape[0]))

    # 대략적인 번호판 영역만 크롭 (여유 있게)
    xmin = int(min(x for x, _, _, _ in group)) - 5
    xmax = int(max(x + w for x, _, w, _ in group)) + 5
    ymin = int(min(y for _, y, _, _ in group)) - 5
    ymax = int(max(y + h for _, y, _, h in group)) + 5
    return rotated[ymin:ymax, xmin:xmax]
```

더 정밀한 크롭이 필요하다면 `cv2.getRectSubPix`로 서브픽셀 정확도의 사각형 크롭을 얻을 수 있습니다. 이 시점에 잘라낸 이미지는 OCR 엔진(Tesseract 등)에 그대로 넣어 번호 문자열까지 얻을 수 있습니다. OCR 연결은 이 책 범위 밖이지만, 전통 CV 파이프라인 한 사이클이 완결되는 지점입니다.

## 4. 전통 CV의 한계

두 파이프라인 모두 잘 작동하지만 다음 상황에서 쉽게 흔들립니다.

- **조명·환경 변화**: 야간·역광·그림자에서는 색·에지 기준 모두 흐려짐
- **다양한 각도·왜곡**: 카메라 각도가 크게 벗어나면 비율·그룹핑 조건이 깨짐
- **하이퍼파라미터 튜닝 비용**: 블러 커널 크기, 이진화 C 값, 비율 범위 등 수십 개의 숫자를 이미지 세트마다 다시 맞춰야 함

이 세 한계를 동시에 해결하려는 흐름이 **딥러닝 기반 객체 탐지** 입니다. Part 5 Ch 05에서 YOLO·Mask R-CNN을 다루며, 전통 CV 파이프라인이 한 "박스 찾기" 과정을 단일 CNN이 end-to-end로 수행하게 됩니다.

## 5. 얼굴 랜드마크 - 정규화 맛보기

얼굴 "검출(box)"에서 한 걸음 더 나가면 **얼굴 랜드마크(landmarks)**가 등장합니다. 눈·코·입 끝점 같은 68 개 정도의 점을 찾아 얼굴을 표현하는 표현으로, 신원 비교·미소 검출·표정 분석 같은 다음 작업의 입력이 됩니다.

랜드마크가 있으면 "두 얼굴이 같은 사람인가"를 비교할 때 단순 픽셀 거리 대신 랜드마크 벡터 사이 거리를 씁니다.

```python
# 의사 코드 - 실제 랜드마크 추출은 dlib·mediapipe·face_recognition 등의 패키지 사용
def face_distance(lm1, lm2):
    # 두 랜드마크 집합을 동일 좌표계로 맞춤(Procrustes 정규화 등)
    # 이후 유클리드 거리 또는 코사인 유사도 계산
    aligned = procrustes_align(lm1, lm2)
    return np.linalg.norm(aligned.lm1 - aligned.lm2)
```

좌표계를 맞추지 않으면 "고개를 돌렸다"는 이유로 다른 사람처럼 보이는 결과가 나옵니다. **Procrustes 분석**으로 회전·크기·위치 차이를 제거한 뒤 거리를 재는 것이 표준입니다. 이 정규화 감각은 Part 5의 전이학습·XAI 실전 이후에도 여러 번 재등장합니다.

# 04. 전이학습 실전 - MobileNet·VGG·ResNet 사전학습 모델 활용

> 대형 CNN을 처음부터 학습시키려면 수십만~수백만 장의 라벨 이미지와 GPU 시간이 필요합니다. 현실 프로젝트는 그런 여건을 갖추기 어렵습니다. **전이학습(Transfer Learning)**은 ImageNet 같은 대규모 데이터로 이미 학습된 모델의 "시각 상식"을 가져와, 내 도메인의 작은 데이터로 미세 조정해 쓰는 접근입니다. 이 장에서는 그 개념, 대표 아키텍처, 실전 패턴을 한 사이클로 정리합니다.

## 1. 왜 전이학습인가

CNN의 앞쪽 층은 에지·색 패턴 같은 **범용 시각 피처**를 학습합니다. 이 피처들은 강아지 분류 모델이 찾은 것이든 자동차 분류 모델이 찾은 것이든 크게 다르지 않습니다. 반면 뒤쪽 층일수록 "이 문제에만 특화된" 고수준 표현이 됩니다.

이 점을 이용하면 다음이 가능합니다.

- **앞~중간 층**은 사전학습 가중치를 그대로 재사용 (공통 피처)
- **마지막 분류 층**만 내 도메인에 맞게 새로 얹고 학습

이 전략은 **적은 데이터·짧은 학습 시간** 으로도 "처음부터 학습" 대비 훨씬 높은 성능을 내며, 2015년 전후부터 실무 CV 프로젝트의 기본값이 되었습니다. 의료 영상·제조 불량 검출·생활 소품 분류처럼 데이터 확보가 어려운 도메인일수록 효과가 큽니다.

## 2. 사전학습 모델과 CNN 아키텍처의 진화

전이학습의 출발점이 되는 **Pre-trained 모델**은 대개 ImageNet (약 120만 장·1000 클래스)로 학습된 대표 CNN 입니다. 몇 가지만 핵심 특징과 함께 정리해 둡니다.

| 모델 | 등장 | 특징 | 파라미터 규모 |
|---|---|---|---|
| **VGG16 / VGG19** | 2014 (Simonyan & Zisserman) | 3×3 Conv만 깊게 쌓은 단순·직관적 구조 | ~138M |
| **ResNet** | 2015 (He 등) | **Residual 연결**로 매우 깊은 네트워크 학습 가능 (ResNet50·101·152) | ~25M (50) |
| **MobileNetV1 / V2** | 2017 / 2018 | Depthwise Separable Conv + Inverted Residual (V2)로 **모바일용 경량화** | V1 ~4.2M / V2 ~3.5M |
| **EfficientNet** | 2019 (Tan & Le) | 깊이·너비·해상도를 동시에 복합 스케일링 | B0 ~5.3M, B7 ~66M |

실무 선택 감각은 이렇게 정리됩니다.

- 성능이 최우선이고 자원이 충분: ResNet50·ResNet101·EfficientNet-B3 이상
- 모바일·엣지 디바이스 배포: MobileNetV2·V3, EfficientNet-B0
- 단순·디버깅 편의: VGG16 (해석 가능성이 높고 구조가 직관적)

요약하면, 자원이 넉넉하면 ResNet 계열, 가볍게 배포하려면 MobileNet 계열, 구조를 단순하게 보고 싶다면 VGG 계열을 먼저 떠올리면 됩니다.

Keras에는 이 모델들이 `tensorflow.keras.applications` 모듈로 사전학습 가중치와 함께 포함되어 있어, 한 줄로 로드 가능합니다.

```python
from tensorflow.keras.applications import (
    MobileNetV2, VGG16, ResNet50, EfficientNetB0
)

base = MobileNetV2(
    input_shape=(224, 224, 3),
    include_top=False,      # 분류층 제거, 피처 추출기만
    weights="imagenet",     # ImageNet 사전학습 가중치
)
```

`include_top=False`가 핵심입니다. 1000 클래스용 마지막 Dense 층을 떼어내고, 그 위에 내 도메인 클래스에 맞는 새 분류기를 얹는 형태가 전이학습의 표준 구성입니다.

## 3. Fine-tuning 전략

사전학습 모델을 내 데이터에 맞추는 방식은 크게 세 가지이며, "데이터 크기"와 "소스 도메인과의 유사도"로 결정합니다.

- **Feature Extraction (전부 Freezing)**: 사전학습 층을 모두 고정하고, 맨 위 분류기만 새로 학습. 데이터가 매우 적을 때
- **Partial Fine-tuning**: 앞쪽 몇 개 층은 고정하고, 뒤쪽 층 + 분류기만 재학습. 중간 규모 데이터
- **Full Fine-tuning**: 모든 층을 재학습(단, 아주 낮은 학습률로). 데이터가 충분히 많고 도메인 차이가 큰 경우

흔히 쓰이는 결정 매트릭스는 다음과 같습니다.

|  | 도메인 유사도 **높음** | 도메인 유사도 **낮음** |
|---|---|---|
| **데이터 많음** | Partial Fine-tuning | Full Fine-tuning |
| **데이터 적음** | Feature Extraction | 어려움 - 증강·더 작은 모델 고려 |

Fine-tuning 시 **학습률**은 처음부터 학습할 때보다 **훨씬 작게** 씁니다. 사전학습된 좋은 가중치를 큰 그래디언트로 흔들면 기존에 익힌 피처까지 잃어버릴 수 있습니다. 보통 `1e-4 ~ 1e-5` 범위에서 시작하며, 데이터가 적거나 도메인 차이가 작을수록 더 낮게 잡습니다.

## 4. 데이터 증강 - 작은 데이터를 넓히기

전이학습과 함께 반드시 쓰이는 기법이 **데이터 증강(Data Augmentation)** 입니다. 한 이미지를 회전·이동·줌·뒤집기로 변형해 "새 샘플처럼" 네트워크에 보여줍니다. 같은 객체의 다양한 모습을 학습해 **과적합**을 크게 줄입니다.

```python
from tensorflow.keras.preprocessing.image import ImageDataGenerator

train_gen = ImageDataGenerator(
    rescale=1.0 / 255,
    rotation_range=15,
    width_shift_range=0.1,
    height_shift_range=0.1,
    zoom_range=0.1,
    horizontal_flip=True,
    validation_split=0.2,
)

train_flow = train_gen.flow_from_directory(
    "data/train",
    target_size=(224, 224),
    batch_size=32,
    class_mode="categorical",
    subset="training",
)

val_flow = train_gen.flow_from_directory(
    "data/train",
    target_size=(224, 224),
    batch_size=32,
    class_mode="categorical",
    subset="validation",
)
```

주의할 변형이 있습니다. 숫자·문자·의료 영상처럼 **좌우 반전이 의미를 바꾸는 도메인** 에서는 `horizontal_flip=True`가 오히려 해가 됩니다. 도메인마다 "허용 가능한 변형"을 먼저 정해야 합니다.

최근 Keras 에는 모델 안에 증강층을 직접 넣는 `tf.keras.layers.RandomFlip` / `RandomRotation` / `RandomZoom` 같은 레이어가 추가되었습니다. 파이프라인이 단순해지고 GPU에서 증강까지 수행돼 속도도 유리합니다.

## 5. 실습 - MobileNetV2로 커스텀 이미지 분류

전이학습 실습의 대표 데이터셋으로 Kaggle의 **State Farm Distracted Driver Detection**을 기준으로 설명합니다. 운전자의 실내 촬영 사진 약 2만 장이 `c0` (정상 운전)부터 `c9` (뒷좌석 접촉)까지 10 개 클래스로 라벨링되어 있습니다. Kaggle에서 내려받은 뒤 클래스별 폴더로 정리해 두면 바로 `flow_from_directory`로 읽을 수 있습니다.

쓰레기 분리수거(6 클래스) 처럼 다른 공개 데이터셋도 폴더 구조만 맞으면 동일 코드로 학습 가능합니다.

```text
data/
  train/
    class_0/  *.jpg
    class_1/  *.jpg
    ...
  test/
    class_0/  *.jpg
    ...
```

### 5.1 모델 구성

```python
import tensorflow as tf
from tensorflow.keras.applications import MobileNetV2
from tensorflow.keras.models import Model
from tensorflow.keras.layers import (
    Dense, GlobalAveragePooling2D, Dropout, Input
)

NUM_CLASSES = 10
IMG_SIZE    = (224, 224)

base = MobileNetV2(
    input_shape=IMG_SIZE + (3,),
    include_top=False,
    weights="imagenet",
)
base.trainable = False          # 1단계: 전부 Freeze (Feature Extraction)

inputs  = Input(shape=IMG_SIZE + (3,))
x = base(inputs, training=False)
x = GlobalAveragePooling2D()(x)
x = Dropout(0.3)(x)
outputs = Dense(NUM_CLASSES, activation="softmax")(x)

model = Model(inputs, outputs)
model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3),
    loss="categorical_crossentropy",
    metrics=["accuracy"],
)
model.summary()
```

`GlobalAveragePooling2D`는 `Flatten` 대신 자주 쓰이는 선택입니다. 피처 맵 전체 채널을 평균 내서 차원을 크게 줄이므로 과적합이 적고 파라미터 수도 감소합니다.

### 5.2 1단계 학습 - 분류기만

사전학습 가중치를 건드리지 않고 새 분류기만 빠르게 맞춥니다.

```python
history1 = model.fit(
    train_flow,
    validation_data=val_flow,
    epochs=5,
)
```

5 에포크 정도면 분류기가 어느 정도 수렴합니다. 이 상태로도 데이터가 적은 문제에서는 충분히 좋은 성능이 나옵니다.

### 5.3 2단계 학습 - 상위 블록 Fine-tune

분류기가 안정됐다면, 사전학습 모델의 뒤쪽 몇 개 블록을 풀어 함께 학습시킵니다.

```python
base.trainable = True

# MobileNetV2의 총 레이어는 약 155 개. FREEZE_UNTIL=100 이면 뒤쪽 약 55 개가 풀립니다.
FREEZE_UNTIL = 100
for layer in base.layers[:FREEZE_UNTIL]:
    layer.trainable = False

# 학습률을 크게 낮춰 사전학습 가중치를 조심스럽게 건드리기
model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=1e-5),
    loss="categorical_crossentropy",
    metrics=["accuracy"],
)

history2 = model.fit(
    train_flow,
    validation_data=val_flow,
    epochs=10,
)
```

이 2단계 루틴("분류기 선행 -> 상위 블록 부분 Fine-tune")이 실무에서 가장 자주 쓰는 기본기입니다. 훨씬 공격적으로 `base.trainable = True`로 전 레이어를 한꺼번에 푸는 것도 가능하지만, 소규모 데이터에서는 기존 피처가 깨져 성능이 오히려 떨어지는 경우가 잦습니다.

### 5.4 학습 곡선과 평가

```python
import matplotlib.pyplot as plt

def plot_curves(history, title):
    plt.plot(history.history["accuracy"],     label="train")
    plt.plot(history.history["val_accuracy"], label="val")
    plt.title(title); plt.xlabel("epoch"); plt.ylabel("accuracy")
    plt.legend(); plt.show()

plot_curves(history1, "Stage 1: classifier only")
plot_curves(history2, "Stage 2: partial fine-tune")
```

훈련 정확도와 검증 정확도가 함께 오르다가 검증 곡선이 꺾이는 지점이 과적합 신호입니다. `EarlyStopping` 콜백을 `fit`에 넘겨 자동 중단시키는 것도 흔한 패턴입니다.

최종 평가는 Confusion Matrix를 함께 보는 것이 원칙입니다.

```python
from sklearn.metrics import confusion_matrix, classification_report
import numpy as np

test_gen = ImageDataGenerator(rescale=1.0 / 255)
test_flow = test_gen.flow_from_directory(
    "data/test",
    target_size=IMG_SIZE,
    batch_size=32,
    class_mode="categorical",
    shuffle=False,
)

y_true = test_flow.classes
y_prob = model.predict(test_flow)
y_pred = np.argmax(y_prob, axis=1)

print(classification_report(y_true, y_pred, target_names=list(test_flow.class_indices)))
print(confusion_matrix(y_true, y_pred))
```

## 6. 전이학습 vs 전통 머신러닝

같은 영상 분류 문제를 전이학습 대신 전통 머신러닝으로 푸는 길도 여전히 존재합니다. 의료 영상처럼 데이터가 정말 적은 도메인에서는 **손으로 설계한 피처 + 전통 분류기** 조합이 더 나을 때도 있습니다. 대표 피처 두 가지입니다.

- **GLCM (Gray Level Co-occurrence Matrix)**: 인접 픽셀 쌍의 밝기 쌍을 세어 만든 행렬에서 대비·동질성·엔트로피·상관 같은 통계를 추출. 질감(texture) 분석의 고전. Haralick (1973) 제안
- **GLRLM (Gray Level Run Length Matrix)**: 같은 밝기가 연속된 길이 분포를 집계. 질감의 "결"이 긴지 짧은지 포착

이 피처들을 추출해 Part 3에서 배운 RandomForest 나 SVM에 넣으면 의료 영상 분류에서도 상당한 베이스라인이 얻어집니다. 즉, 데이터가 아주 적은 도메인에서는 전통 피처가 아직도 실용적인 출발점이 될 수 있습니다.

예를 들어 전립선암 조직 이미지 수백 장 규모의 실험에서 GLCM 기반 피처로 약 0.96, GLRLM 기반 피처로 약 0.87 수준의 테스트 정확도가 보고된 바 있습니다. CNN 전이학습이 더 높은 성능을 내는 경우가 대부분이지만, **"왜 이 결과가 나왔는가"**를 설명할 수 있다는 점에서는 수작업 피처가 유리합니다. 해석 가능성이 중요한 도메인(의료·법률·금융)에서는 양쪽을 병행하는 경우가 흔합니다.

## 7. 전이학습의 확장

CV 영역 밖에서도 같은 발상이 지배적입니다.

- **자연어처리**: BERT·GPT 같은 대형 언어모델을 사전학습해 두고, 분류·요약·번역 같은 다운스트림 태스크에 Fine-tuning. Part 6 NLP 챕터에서 다시 만납니다
- **음성**: Wav2Vec·Whisper 같은 음성 기반 모델이 유사한 패턴
- **생성 모델**: StyleGAN의 사전학습 가중치로 특정 스타일 전이 (Part 5 Ch 06에서 연결)

요약하면 "대규모 범용 학습 + 소규모 도메인 적응"이라는 구도는 현대 딥러닝의 표준 레시피가 되었습니다.

## 마무리

전이학습은 "처음부터 학습"의 데이터·연산 부담을 크게 낮추면서, 실무에서 바로 쓸 수 있는 성능을 제공합니다. 이 챕터의 2단계 루틴(**분류기 선행 학습 -> 상위 블록 부분 Fine-tune**)과 데이터 증강·학습률 낮추기·GAP 분류기 구조는 이후 어느 도메인의 이미지 문제를 만나도 재사용 가능한 기본기입니다.

다음 챕터에서는 "이미지 전체의 클래스 한 개"를 넘어 "**이미지 안의 여러 객체 위치·종류**"를 동시에 찾는 **객체 탐지**로 넘어갑니다. YOLO와 Mask R-CNN이 주인공입니다.

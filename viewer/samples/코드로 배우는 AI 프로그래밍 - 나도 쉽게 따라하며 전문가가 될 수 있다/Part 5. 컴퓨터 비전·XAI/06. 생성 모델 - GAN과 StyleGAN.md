# 06. 생성 모델 - GAN과 StyleGAN

> 지금까지 본 신경망은 "주어진 입력을 분류·회귀" 하는 판별 모델(discriminative model) 이었습니다. **생성 모델(generative model)**은 방향이 반대입니다. 학습 데이터의 분포를 배워 **그 분포에서 새로운 샘플을 뽑아냅니다**. 실제로 존재하지 않는 사람의 얼굴 사진을 만들어 내거나, 있던 사진의 표정·헤어스타일을 자연스럽게 바꾸는 일이이 범주에 들어갑니다.

## 1. 판별 모델과 생성 모델

두 관점을 한 줄로 비교하면 다음과 같습니다.

| | 판별 (Discriminative) | 생성 (Generative) |
|---|---|---|
| 학습 목표 | 입력 x에서 라벨 y를 예측 | 데이터 분포 P(x) 자체를 모델링 |
| 출력 | 클래스·연속값 | 새 샘플 x' |
| 예시 | CNN 분류기, YOLO | GAN, VAE, Diffusion, Autoregressive LM |

같은 얼굴 데이터로 학습하더라도 분류기는 "나이·성별 예측"을 하고, 생성 모델은 "이 분포에 속할 법한 새 얼굴"을 내놓습니다. 이 장은 생성 모델 가운데서도 **GAN 계열** 에만 초점을 맞춥니다.

생성 모델의 대표 계보로는 **VAE**(2013, Kingma), **GAN**(2014, Goodfellow), **Autoregressive**(PixelCNN·GPT 계열), **Diffusion**(2020 DDPM 이후 Stable Diffusion 등)이 있습니다. VAE·Diffusion은 이 책 범위를 벗어나므로, 관심 독자는 공식 논문·튜토리얼을 참고해 주시기 바랍니다.

## 2. GAN의 원리 - 두 네트워크의 경쟁

**GAN (Generative Adversarial Network)**은 2014년 Ian Goodfellow 등이 제안한 구조입니다. 핵심은 **두 네트워크가 서로 속이고 간파하려는 경쟁**으로 학습을 끌고 간다는 점입니다.

- **Generator (G)**: 랜덤 노이즈 벡터 `z`를 받아 "진짜 같은" 이미지 `G(z)`를 생성
- **Discriminator (D)**: 입력이 진짜 학습 샘플인지 `G`가 만든 가짜인지 분류

학습은 한 스텝씩 교대로 진행됩니다.

1. `D` 학습: 진짜 이미지에는 `1`, `G(z)`에는 `0`이라고 올바르게 분류하도록 업데이트
2. `G` 학습: `D`가 `G(z)`를 `1` (진짜)로 속을 만큼 가짜를 더 잘 만들도록 업데이트

두 네트워크가 서로의 실력을 끌어올리며, 이상적인 수렴점에서는 `D`가 진짜·가짜를 5:5 로만 구분할 수 있습니다. 그 시점의 `G`는 학습 데이터 분포에서 샘플을 뽑는 것과 비슷한 수준의 이미지를 만들어 냅니다.

### 2.1 최소 GAN 골격 (Keras 의사 코드)

아래 구조는 **MNIST** (28×28 흑백)를 가정한 최소 골격입니다. Generator 출력 채널을 `1`로 두고 `tanh`를 써서 `[-1, 1]`로 정규화된 이미지를 내는 관례를 따릅니다. 컬러·고해상도 데이터로 옮기려면 출력 채널 수·입력 shape·네트워크 깊이를 같이 키워야 합니다.

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras import layers, Model

LATENT_DIM = 100

def make_generator():
    z = layers.Input(shape=(LATENT_DIM,))
    x = layers.Dense(7 * 7 * 128, activation="relu")(z)
    x = layers.Reshape((7, 7, 128))(x)
    x = layers.Conv2DTranspose(64, 4, strides=2, padding="same", activation="relu")(x)
    x = layers.Conv2DTranspose(1,  4, strides=2, padding="same", activation="tanh")(x)
    return Model(z, x, name="G")

def make_discriminator():
    img = layers.Input(shape=(28, 28, 1))
    x = layers.Conv2D(64, 4, strides=2, padding="same")(img)
    x = layers.LeakyReLU(0.2)(x)
    x = layers.Conv2D(128, 4, strides=2, padding="same")(x)
    x = layers.LeakyReLU(0.2)(x)
    x = layers.Flatten()(x)
    out = layers.Dense(1, activation="sigmoid")(x)
    return Model(img, out, name="D")

G = make_generator()
D = make_discriminator()
```

한 스텝의 학습 루프는 대략 다음과 같습니다.

```python
bce = tf.keras.losses.BinaryCrossentropy()
opt_d = tf.keras.optimizers.Adam(1e-4)
opt_g = tf.keras.optimizers.Adam(1e-4)

@tf.function
def train_step(real_imgs, batch_size):
    z = tf.random.normal([batch_size, LATENT_DIM])

    # 1) Discriminator 학습
    with tf.GradientTape() as tape_d:
        fake = G(z, training=True)
        pred_real = D(real_imgs, training=True)
        pred_fake = D(fake,      training=True)
        loss_d = bce(tf.ones_like(pred_real),  pred_real) \
               + bce(tf.zeros_like(pred_fake), pred_fake)
    grads_d = tape_d.gradient(loss_d, D.trainable_weights)
    opt_d.apply_gradients(zip(grads_d, D.trainable_weights))

    # 2) Generator 학습 (D의 판단을 1로 뒤집으려 함)
    with tf.GradientTape() as tape_g:
        fake = G(z, training=True)
        pred_fake = D(fake, training=True)
        loss_g = bce(tf.ones_like(pred_fake), pred_fake)
    grads_g = tape_g.gradient(loss_g, G.trainable_weights)
    opt_g.apply_gradients(zip(grads_g, G.trainable_weights))
```

이 골격을 MNIST 같은 간단 데이터에 몇 시간 돌리면 숫자 이미지가 흐릿하게 생성되기 시작합니다. 실제 고해상도 결과를 얻으려면 훨씬 큰 네트워크·데이터·학습 시간이 필요하며, 다음 섹션의 StyleGAN 같은 사전학습 모델을 가져다 쓰는 것이 현실적입니다.

## 3. GAN의 학습 안정성

GAN은 학습이 까다롭기로 악명 높습니다. 네 가지 대표 증상을 알아 두면 디버깅 시 도움이 됩니다.

- **Mode collapse**: `G`가 몇 가지 이미지만 반복 생성. 다양성이 사라짐
- **학습 불균형**: `D`가 너무 강해지면 `G`가 아무 신호도 못 받아 정체
- **Oscillation**: 두 네트워크의 손실이 수렴하지 않고 왔다 갔다
- **Gradient 소실**: 초기 `D`가 너무 잘 판단해 `G` 학습이 죽음

해결책으로 자리 잡은 기법으로는 **DCGAN** (Radford 2015), **WGAN** (Arjovsky 2017), **Spectral Normalization** (Miyato 2018), **TTUR** (two time-scale update rule) 등이 있습니다.

실전에서는 보통 검증된 구조(DCGAN·StyleGAN 계열)를 그대로 가져다 쓰고, 하이퍼파라미터를 과하게 건드리지 않는 것이 가장 안전한 출발입니다.

## 4. GAN의 주요 변형

GAN 발표 이후 다양한 파생 모델이 등장했습니다. 실무에서 자주 거론되는 몇 가지입니다.

- **DCGAN** (2015): Conv 기반 G/D, 후속 모든 이미지 GAN의 기본 설계 지침 제공
- **Conditional GAN (cGAN)** (2014): 조건 벡터(클래스 라벨·텍스트)를 함께 넣어 "특정 종류"를 생성
- **Pix2Pix** (2017): 이미지-to-이미지 변환 (스케치 -> 사진, 낮 -> 밤)
- **CycleGAN** (2017): 페어 데이터 없이도 A 스타일 <-> B 스타일 변환 (말 -> 얼룩말)
- **StyleGAN / StyleGAN2 / StyleGAN3** (2019·2020·2021): 고해상도 얼굴 생성과 세밀한 스타일 제어. NVIDIA

Conditional·CycleGAN 계열은 "제어 가능한 생성" 방향의 발전이고, StyleGAN 계열은 "품질과 해상도" 방향의 발전입니다.

## 5. StyleGAN과 Latent Space

StyleGAN (Karras, NVIDIA 2019)은 GAN 생성 품질의 상한을 크게 끌어올린 모델입니다. StyleGAN은 1024×1024 고해상도 얼굴 생성의 품질을 실용적인 수준으로 밀어 올렸고, 후속 StyleGAN2·3을 거치며 아티팩트가 크게 줄었습니다.

같은 NVIDIA 팀의 **PGGAN**이 2017년에 진행적 성장으로 1024×1024 해상도를 먼저 달성했고, StyleGAN은 그 위에 스타일 기반 구조를 얹은 계보라고 이해하면 됩니다.

### 5.1 Latent Space

StyleGAN의 생성자 입력은 고정 차원(예: 512)의 **latent vector** `z` 입니다. 이 공간의 점 하나가 "한 얼굴"에 대응하며, 학습된 공간은 의미 있는 축을 가집니다. "나이" 축, "성별" 축, "표정" 축이 암묵적으로 형성되어 있어, 두 벡터 사이를 선형 보간하면 **자연스러운 몰핑(morphing)**이 만들어집니다.

```python
# 의사 코드 - 실제 StyleGAN 사전학습 모델 사용 (예: NVIDIA 공식 레포)
z_a = sample_latent()         # 얼굴 A의 잠재 벡터
z_b = sample_latent()         # 얼굴 B의 잠재 벡터

for alpha in np.linspace(0, 1, 30):
    z = (1 - alpha) * z_a + alpha * z_b
    img = G.synthesize(z)     # 얼굴 A -> B로 서서히 변형되는 프레임
```

얼굴 몰핑 비디오가 SNS·전시·광고 등에서 유행했던 기술적 배경이 바로 이 latent space 보간입니다.

### 5.2 StyleGAN의 구조적 특징

- **스타일 매핑 네트워크**: 입력 `z`를 중간 공간 `w`로 변환한 뒤, 네트워크의 각 층에 "스타일"로 주입
- **AdaIN (Adaptive Instance Normalization)**: 각 층의 특징 맵 통계를 `w`로 조정해 스타일을 반영
- **progressive growing 제거, skip·residual 연결 도입**: v1의 점진적 해상도 증가 방식을 v2에서 걷어내고, 입력/출력 skip 또는 residual 연결을 조합해 동등 이상의 성능을 얻음
- **Noise 주입**: 각 해상도마다 랜덤 노이즈를 더해 미세 디테일(머릿결·주름 등)을 학습

StyleGAN 계열 사전학습 모델은 NVIDIA 공식 GitHub와 Hugging Face에서 내려받을 수 있으며, Colab에서 몇 줄 코드로 얼굴 샘플링과 몰핑이 가능합니다. 본 챕터에서는 코드 세부를 다루지 않지만, 실습을 원하신다면 "stylegan2-ada-pytorch" 또는 "stylegan3" 레포를 참고하시길 권합니다.

## 6. 얼굴 몰핑 파이프라인

StyleGAN으로 얼굴 몰핑 비디오를 만드는 전체 흐름은 다음과 같습니다.

```text
사전학습 StyleGAN 로드
  -> latent 샘플링으로 얼굴 A, B, C, ... 시드 얻기
  -> 각 시드 사이를 선형 보간해 중간 latent 벡터 수백 개 생성
  -> 각 벡터를 generator에 통과시켜 프레임 이미지 수백 장 확보
  -> ffmpeg 등으로 프레임을 이어붙여 mp4 영상 생성
```

이 파이프라인은 "사전학습 모델 + latent 보간" 두 단계의 조합이라, 사용자가 직접 모델을 학습시킬 필요가 거의 없습니다. 몇 시간 분량의 GPU 시간과 준비된 시드만 있으면 됩니다.

## 7. 데이터 증강에의 활용

생성 모델의 실무적 용도 중 흔한 것이 **소수 클래스 데이터 증강** 입니다. 의료 영상처럼 양성 샘플이 훨씬 적은 문제에서, GAN으로 양성 이미지를 추가 생성해 훈련 데이터를 보강하면 분류 모델의 recall이 크게 오르는 사례가 보고되어 있습니다.

다만 몇 가지 주의점이 있습니다.

- GAN이 생성한 샘플은 **원본 분포를 100% 보존하지 않으므로**, 검증·테스트 세트에는 섞지 않고 **훈련 세트에만** 넣어야 함
- 원본 샘플이 수십 장 수준으로 너무 적으면 **mode collapse**가 쉽게 나타나 결과가 한두 가지로 수렴하고 다양성이 거의 사라집니다. 실무 보고에 따르면 최소 수백 장 이상이 있어야 출발선
- 원본 데이터의 편향이 그대로 확대·증폭될 수 있음

실무에서는 **전통 데이터 증강 (rotation·flip·scale) + 소수 GAN 샘플** 조합이 실용적입니다.

## 8. 생성 모델의 윤리·법적 이슈

고품질 생성 모델은 기술적 가능성뿐 아니라 사회적 논점을 빠르게 만들었습니다.

- **Deepfake**: 실존 인물의 얼굴·목소리를 가짜 영상에 합성해 허위 정보 유포
- **저작권**: 사전학습 데이터에 포함된 작품의 스타일을 재생성하는 행위의 법적 지위
- **신원 도용·명예훼손**: 제3자 얼굴을 동의 없이 생성·활용
- **합성 미디어 탐지**: 생성-탐지의 군비 경쟁 (디지털 워터마킹, 출처 메타데이터 표준화 등)

각국은 생성 AI 콘텐츠에 **워터마크·출처 표기**를 의무화하는 방향으로 제도를 정비하고 있습니다(EU AI Act, 한국 AI 기본법 등).

엔지니어·제품 설계자는 "무엇을 생성할 수 있는가"와 함께 "무엇을 생성하면 안 되는가"를 설계 단계에서 함께 고려해야 합니다. 이 주제는 부록 A (AI 윤리·사회)에서 한 걸음 더 다룹니다.

## 마무리

GAN은 "경쟁으로 학습한다"는 단순한 발상에서 출발해, 고해상도 얼굴 생성·이미지 번역·데이터 증강까지 빠르게 확장된 생성 AI의 대표 계보입니다. 2020년대 들어 Diffusion 모델이 주류 자리를 일부 가져갔지만, StyleGAN 류의 빠른 샘플링과 제어 가능한 latent space는 여전히 많은 응용에서 유효합니다.

# 03. 합성곱 신경망 (CNN) 기초

> 이미지는 공간적으로 가까운 픽셀들끼리 의미를 이룹니다. 이 구조를 네트워크가 활용하도록 설계한 것이 **합성곱 신경망(Convolutional Neural Network, CNN)**입니다. 이 챕터에서는 MLP의 한계부터 시작해 합성곱·풀링·파라미터 계산·Keras 실습까지 훑고, CIFAR-10에서 전통 머신러닝과의 격차를 확인해 봅니다.

## 1. MLP로 이미지를 처리할 때의 한계

앞 두 챕터의 MLP는 입력이 1차원 벡터입니다. 28×28 MNIST 이미지를 넣으려면 평탄화해 `(784,)` 벡터로 바꿉니다. 이 순간 세 가지 정보가 손실됩니다.

- **공간 인접성**: 옆 픽셀이 같은 획의 일부라는 정보가 사라짐
- **이동 불변성**: 같은 숫자가 살짝 이동해도 픽셀 벡터는 크게 달라짐
- **파라미터 폭발**: 첫 은닉층만 해도 `784 × 은닉 크기`만큼 가중치가 필요. 입력이 커지면 감당 불가

이미지·음성·자연어 같은 "위치가 의미를 가진 데이터"에서는 MLP의 피처 처리 방식 자체를 바꿔야 합니다. 그 답이 합성곱입니다.

## 2. 합성곱 연산

**합성곱(Convolution)**은 작은 크기의 **커널(kernel, filter)**을 이미지 위에서 슬라이딩하며 각 위치에서 내적을 계산하는 연산입니다. 3×3 커널을 예로 들면 한 위치에서 `3×3=9` 개 픽셀과 9 개 가중치를 곱해 더한 값 하나를 새 이미지의 해당 위치에 기록합니다.

```text
입력 5x5
 1 1 1 0 0
 0 1 1 1 0           커널 3x3               출력 3x3
 0 0 1 1 1    conv    1 0 1     =           4 3 4
 0 0 1 1 0            0 1 0                 2 4 3
 0 1 1 0 0            1 0 1                 2 3 4
```

### 2.1 왜 합성곱이 이미지에 잘 맞는가

- **지역 수용 영역**: 커널이 한 번에 보는 영역이 작아서 "선·에지·모서리 교차점" 같은 **지역적 패턴**을 학습하기 쉬움
- **가중치 공유**: 같은 커널이 이미지 전 영역을 돌기 때문에, "이 모양"을 이미지 어디에서든 같은 방식으로 찾게 됨 (이동 불변성)
- **파라미터 절약**: 입력 크기와 무관하게 커널 파라미터만 학습. 3×3 커널은 가중치 9 개뿐

### 2.2 주요 하이퍼파라미터

합성곱 층 하나에는 네 가지 설정이 있습니다.

- **커널 크기 (kernel_size)**: 3×3·5×5·7×7이 흔함
- **필터 수 (filters)**: 같은 영역을 보는 서로 다른 커널을 몇 개 둘지. 출력의 **채널 수**가 됨
- **스트라이드 (stride)**: 한 번에 몇 칸씩 건너뛸지. 2로 두면 출력 크기가 대략 절반
- **패딩 (padding)**: 테두리에 0을 덧대 입력 크기를 보존할지 (`"same"`), 덧대지 않을지 (`"valid"`)

### 2.3 풀링 - 공간 크기를 줄이는 연산

합성곱 뒤에는 보통 **풀링(pooling)**이 따라 나옵니다. 일정 영역에서 최댓값(Max Pooling) 또는 평균(Average Pooling)만 남겨 공간 크기를 축소하는 연산입니다. 파라미터가 없고, 계산이 가벼우며, 작은 이동·왜곡에 대한 강건성을 얻는 효과가 있습니다.

```text
2x2 Max Pooling 예
 1 3 | 2 4        3 4
 2 1 | 0 1   ->   2 3
 -------------
 1 0 | 3 2
 2 1 | 1 3
```

## 3. CNN의 전형적 구조

대부분의 CNN은 "Conv -> ReLU -> Pool" 블록을 몇 번 쌓은 뒤, 마지막에 특징을 평탄화해 Dense 층으로 분류하는 구조를 갖습니다.

```text
입력 이미지
  -> Conv -> ReLU -> Pool
  -> Conv -> ReLU -> Pool
  -> Flatten
  -> Dense -> ReLU
  -> Dense -> softmax (클래스 확률)
```

앞쪽 Conv 블록이 "이미지를 점점 작지만 깊은 피처 맵으로" 압축하고, 뒤쪽 Dense 블록이 그 피처로 분류를 수행합니다. LeNet-5 (Yann LeCun, 1998)·AlexNet (Krizhevsky 등, 2012)·VGG (Simonyan & Zisserman, 2014)·ResNet (He 등, 2015) 같은 대표 아키텍처는 모두 이 골격의 변형입니다.

## 4. 파라미터 수 계산

CNN의 파라미터 수는 MLP 대비 극적으로 작습니다. 간단한 예로 계산해 봅니다. 입력 `(28, 28, 1)`에서 시작해 다음 블록을 지나가는 경우입니다.

```text
Conv2D(filters=32, kernel=3x3, padding="same")
  파라미터: (3·3·1)·32 + 32(bias) = 320
  출력 shape: (28, 28, 32)

MaxPool(2x2)
  파라미터: 0
  출력 shape: (14, 14, 32)

Conv2D(filters=64, kernel=3x3, padding="same")
  파라미터: (3·3·32)·64 + 64 = 18,496
  출력 shape: (14, 14, 64)

MaxPool(2x2)
  파라미터: 0
  출력 shape: (7, 7, 64)

Flatten()
  파라미터: 0
  출력 shape: (3136,)

Dense(128)
  파라미터: 3136·128 + 128 = 401,536

Dense(10, softmax)
  파라미터: 128·10 + 10 = 1,290
```

Conv 층의 파라미터 수 공식은 `(커널_H · 커널_W · 입력_채널) · 출력_채널 + 출력_채널(bias)`입니다. 같은 모델을 MLP로 짜려면 `784 · 128 + ... `만 해도 10만 단위 가중치가 필요하고, 이미지 크기가 커지면 더 비대해집니다. CNN은 "공간을 이용해 파라미터를 줄인다"는 표현이 딱 맞습니다.

## 5. Keras로 MNIST CNN 실습

### 5.1 데이터 준비

MNIST는 0~9 손글씨 숫자 70,000 장(학습 60k + 테스트 10k)의 28×28 흑백 이미지입니다. Keras에 내장돼 있어 다운로드 한 줄로 끝납니다.

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras.datasets import mnist
from tensorflow.keras.utils import to_categorical

(X_train, y_train), (X_test, y_test) = mnist.load_data()

# CNN 입력은 (H, W, C) 형태가 표준. 흑백이므로 C=1
X_train = X_train.astype("float32").reshape(-1, 28, 28, 1) / 255.0
X_test  = X_test.astype("float32").reshape(-1, 28, 28, 1) / 255.0

y_train = to_categorical(y_train, num_classes=10)
y_test  = to_categorical(y_test, num_classes=10)

X_train.shape   # (60000, 28, 28, 1)
```

### 5.2 모델 구성

앞서 계산한 Conv-Pool 두 번 + Dense 두 번 구조를 그대로 옮깁니다.

```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense

model = Sequential([
    Conv2D(32, (3, 3), padding="same", activation="relu",
           input_shape=(28, 28, 1)),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), padding="same", activation="relu"),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation="relu"),
    Dense(10,  activation="softmax"),
])

model.compile(optimizer="adam",
              loss="categorical_crossentropy",
              metrics=["accuracy"])

model.summary()
```

`model.summary()` 출력 하단의 `Total params` 값 **421,642** 개는 앞에서 손으로 계산한 합계(`320 + 18,496 + 401,536 + 1,290`)와 정확히 일치합니다.

### 5.3 학습과 평가

```python
history = model.fit(
    X_train, y_train,
    epochs=5, batch_size=128,
    validation_split=0.1, verbose=1,
)

test_loss, test_acc = model.evaluate(X_test, y_test, verbose=0)
# 에포크 5 기준 테스트 정확도 대략 0.99 근방
```

MLP로 MNIST를 풀면 같은 에포크에서 보통 0.97 ~ 0.98 수준에 머뭅니다. CNN은 동일 조건에서 오류율을 절반 이하로 낮추며 0.99 근방에 도달합니다. 이미지 구조를 살린 설계가 곧바로 성능 차이로 드러나는 순간입니다.

모델을 평가할 때는 전체 정확도 한 숫자에만 의존하지 말고, 클래스별 precision·recall과 Confusion Matrix를 함께 확인하는 것이 기본입니다. MNIST 처럼 균형잡힌 데이터에서는 영향이 적지만, 클래스 비율이 기울어진 실 데이터에서는 accuracy가 높아도 특정 클래스의 recall이 0에 가까운 경우가 흔합니다. 이 감각은 Part 3 Ch 04의 평가 지표 내용을 그대로 적용하면 됩니다.

## 6. 전통 머신러닝 vs CNN - CIFAR-10 사례

MNIST는 비교적 단순한 문제라 전통 머신러닝도 90% 대 성능을 냅니다. 난이도를 한 단계 올려 **CIFAR-10** (32×32 컬러, 10 클래스, 60,000 장)에서 비교하면 격차가 선명해집니다.

```python
from tensorflow.keras.datasets import cifar10
from sklearn.ensemble import RandomForestClassifier

(Xc_train, yc_train), (Xc_test, yc_test) = cifar10.load_data()

# Random Forest는 1차원 입력을 기대
Xc_train_flat = Xc_train.reshape(len(Xc_train), -1) / 255.0
Xc_test_flat  = Xc_test.reshape(len(Xc_test),  -1) / 255.0

rf = RandomForestClassifier(n_estimators=100, random_state=42, n_jobs=-1)
rf.fit(Xc_train_flat, yc_train.ravel())
rf.score(Xc_test_flat, yc_test.ravel())
# 약 0.45 전후 (데이터·시드에 따라 0.4 대 초중반)
# 이미지 구조를 버리고 픽셀을 벡터로만 본 대가
```

CIFAR-10에서는 이미지 구조를 보존하는 CNN이 RandomForest보다 훨씬 유리합니다. 같은 데이터에 앞에서 본 소형 CNN(Conv-Pool 2회 + Dense)을 돌리면 10 에포크 내외로 0.70 ~ 0.75 수준의 정확도가 어렵지 않게 나옵니다. 더 깊은 모델·데이터 증강·전이학습까지 더하면 0.9 이상도 가능합니다.

반면 RandomForest 학습은 5만 장·3,072 피처 기준으로 장비에 따라 수 분 걸릴 수 있습니다. 경향만 확인하고 싶다면 앞 10,000 장만 슬라이싱해 학습해도 결과는 크게 달라지지 않습니다. 이런 격차가 "이미지에는 CNN"이라는 실무 격언의 근거입니다.

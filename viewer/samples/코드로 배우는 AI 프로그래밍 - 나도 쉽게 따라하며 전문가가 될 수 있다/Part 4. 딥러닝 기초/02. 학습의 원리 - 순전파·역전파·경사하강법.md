# 02. 학습의 원리 - 순전파·역전파·경사하강법

> 앞 챕터에서 Keras의 `model.fit(...)` 한 줄이 수많은 가중치를 데이터에 맞춰 주는 것을 보았습니다. 이 챕터에서는 그 한 줄 안에서 실제로 벌어지는 일을 풀어 봅니다. 손실 함수, 경사하강법, 역전파 세 개의 개념이 한 덩어리로 맞물려 현대 딥러닝의 학습 엔진을 구성합니다.

## 1. 연결주의 학습의 본질 - 가중치 최적화

신경망이 "배운다"는 것은 결국 **가중치(weight)와 편향(bias)를 데이터에 맞게 조정한다**는 뜻입니다. 구조(층 수, 유닛 수, 활성화 함수)는 사람이 정해 두고, 학습 루프는 이 파라미터들을 수치로 업데이트할 뿐입니다.

학습은 다음 세 조각이 반복되는 루프입니다.

1. **순전파(Forward pass)**: 입력을 현재 가중치로 흘려 예측값을 얻음
2. **손실(Loss) 계산**: 예측과 정답의 차이를 하나의 수치로 측정
3. **역전파(Backward pass) + 경사하강법**: 손실을 줄이는 방향으로 가중치를 조금씩 업데이트

이 사이클을 수많은 샘플·에포크에 걸쳐 반복하면서 가중치가 점점 "입력 -> 정답" 매핑을 잘 근사하도록 수렴합니다.

## 2. 손실 함수 - "얼마나 틀렸는가"의 수치화

가중치를 어느 방향으로 움직일지 결정하려면 "지금 얼마나 틀렸는가"를 하나의 수치로 표현해야 합니다. 이 수치가 **손실(loss)**이며, 손실을 계산하는 함수가 **손실 함수(loss function)**입니다. 문제 유형에 맞는 함수가 정해져 있습니다.

- **회귀 문제**: 평균 제곱 오차 (MSE)
    ```text
    MSE = (1/N) · Σ (y_true - y_pred)^2
    ```
- **이진 분류**: 이진 교차 엔트로피 (Binary Cross-Entropy)
    ```text
    BCE = -(1/N) · Σ [ y·log(p) + (1-y)·log(1-p) ]
    ```
- **다중 분류**: 범주형 교차 엔트로피 (Categorical Cross-Entropy)
    ```text
    CCE = -(1/N) · Σ Σ_k  y_k · log(p_k)
    ```

회귀는 보통 MSE를, 분류는 교차 엔트로피 계열 손실을 기본으로 생각하면 됩니다. 교차 엔트로피는 "모델이 정답 클래스에 얼마나 낮은 확률을 부여했는가"에 큰 페널티를 줍니다. 정답에 `1.0` 가까이 확률을 주면 손실이 `0`에 가깝고, `0.01`처럼 낮게 주면 손실이 크게 튑니다. Keras에서는 `loss="mse"`·`"binary_crossentropy"`·`"categorical_crossentropy"` 같은 문자열로 선택합니다.

## 3. 경사하강법 - 손실이 작아지는 방향으로

손실은 가중치의 함수 `L(W)`로 쓸 수 있습니다. 학습의 목표는 이 함수의 최솟값에 이르는 `W`를 찾는 일입니다. **경사하강법(Gradient Descent)**은 가장 기본적인 최적화 알고리즘입니다.

```text
W_new = W - lr · ∂L/∂W
```

`∂L/∂W`는 손실을 가중치로 미분한 값(기울기, gradient)으로 "가중치를 아주 조금 키우면 손실이 어느 방향으로 얼마나 변하는가"를 나타냅니다. 손실이 작아지려면 기울기의 **반대 방향**으로 가중치를 움직여야 하고, 얼마나 움직일지가 **학습률(learning rate, lr)**입니다.

### 3.1 학습률의 감각

- 너무 크면: 최솟값을 지나쳐 튕기거나 발산
- 너무 작으면: 수렴이 느리거나 국소 최솟값에 갇힘
- 실전: `1e-3 ~ 1e-4` 정도에서 시작해 결과를 보며 조정

Adam 같은 현대 옵티마이저는 학습률을 파라미터별로 자동 조정하지만, 초기 학습률은 여전히 사람이 정해야 할 중요한 하이퍼파라미터입니다.

### 3.2 1차원 장난감 예제

손실 함수가 `L(w) = (w - 3)^2`인 간단한 경우를 경사하강법으로 풀어 봅니다. 최솟값은 명백히 `w = 3`입니다.

```python
import numpy as np

def gradient_descent(L_prime, w0, lr=0.1, steps=50):
    w = w0
    traj = [w]
    for _ in range(steps):
        w = w - lr * L_prime(w)
        traj.append(w)
    return traj

# L(w) = (w - 3)^2  ->  L'(w) = 2*(w - 3)
traj = gradient_descent(lambda w: 2 * (w - 3), w0=0.0, lr=0.1, steps=30)
round(traj[-1], 4)
# 2.9963   (30번 스텝 만에 3에 근접)
```

같은 원리를 수천~수백만 차원 가중치 벡터로 확장한 것이 신경망 학습입니다.

## 4. 기울기는 어떻게 구하는가 - 수치 미분 vs 역전파

기울기 `∂L/∂W`를 얻는 방법은 크게 두 가지입니다.

### 4.1 수치 미분

정의식에 따라 유한 차분으로 근사합니다.

```python
def numerical_gradient(f, w, h=1e-4):
    grad = np.zeros_like(w)
    for i in range(w.size):
        orig = w.flat[i]
        w.flat[i] = orig + h;  fxh1 = f(w)
        w.flat[i] = orig - h;  fxh2 = f(w)
        grad.flat[i] = (fxh1 - fxh2) / (2 * h)
        w.flat[i] = orig
    return grad
```

이해하기는 쉽지만 가중치가 수만 개만 돼도 파라미터 하나당 두 번의 순전파가 필요해 **계산 비용이 현실성을 잃습니다**. 이 방법만 쓰면 현대 딥러닝이 불가능합니다.

### 4.2 역전파

**역전파(Backpropagation)**는 미분의 연쇄 법칙을 이용해 **모든 가중치의 기울기를 한 번의 역방향 패스**로 구해 내는 알고리즘입니다. 1986년 Rumelhart·Hinton·Williams의 논문을 계기로 다층 신경망 학습이 현실이 되었습니다.

핵심 아이디어는 신경망을 **계산 그래프**로 보고 출력에서부터 입력 방향으로 기울기를 전파하는 것입니다. 각 노드(연산)는 자기 자신이 입력·가중치·이전 그래디언트로부터 다음 그래디언트를 어떻게 계산해야 하는지만 알면 됩니다.

### 4.3 계산 그래프로 본 역전파 - 덧셈·곱셈

가장 단순한 두 연산의 역전파 규칙을 적어 두면 이후의 복잡한 네트워크도 이 규칙의 조합으로 읽힙니다.

- **덧셈 노드**: 상류 그래디언트를 두 입력에 **그대로** 전달
- **곱셈 노드**: 상류 그래디언트를 **상대편 입력 값**으로 곱해 전달

예를 들어 `z = x · y`에서 `∂z/∂x = y`, `∂z/∂y = x`이므로, 상류에서 전달된 `∂L/∂z`에 각각 `y`, `x`를 곱해 아래로 흘려보냅니다. Affine (행렬곱 + 편향), ReLU, Softmax, 교차 엔트로피 같은 복잡한 층도 결국 이 규칙들을 일반화한 미분 공식을 갖고 있습니다. Keras·PyTorch는 이런 공식을 내부적으로 구현해 두고 자동으로 계산해 줍니다.

## 5. 손으로 짜 보는 2층 신경망 학습

이해를 굳히기 위해 NumPy만으로 2층 MLP의 학습 루프를 직접 구현해 봅니다. Iris를 입력 4 -> 은닉 16 -> 출력 3 구조로 분류합니다. MNIST처럼 이미지 스트림이 들어오는 경우의 학습 루프는 Part 4 Ch 03에서 합성곱 구조와 함께 다시 다룹니다.

```python
import numpy as np
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

iris = load_iris()
X = StandardScaler().fit_transform(iris.data)          # (150, 4)
Y = np.eye(3)[iris.target]                             # one-hot (150, 3)

X_train, X_test, Y_train, Y_test = train_test_split(
    X, Y, test_size=0.2, random_state=42, stratify=iris.target)
```

### 5.1 순전파

```python
def softmax(z):
    z = z - z.max(axis=1, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=1, keepdims=True)

def forward(X, W1, b1, W2, b2):
    h = np.maximum(0, X @ W1 + b1)        # ReLU 은닉층
    y = softmax(h @ W2 + b2)              # softmax 출력
    return h, y

def cross_entropy(y_pred, y_true):
    eps = 1e-9
    return -np.mean(np.sum(y_true * np.log(y_pred + eps), axis=1))
```

### 5.2 역전파

먼저 두 가지 간결 공식만 짚어 두면 코드가 읽힙니다.

- **softmax + 교차 엔트로피 결합 그래디언트**: 각각 따로 미분하면 복잡하지만, 둘을 합친 `L`을 출력 직전 `z`로 미분하면 `(p - t)/N`으로 깔끔해집니다 (`p` = softmax 출력, `t` = 원-핫 정답). 이 "상쇄" 때문에 softmax·CCE는 실전에서 거의 항상 짝을 이뤄 쓰입니다
- **ReLU 역전파**: `h = max(0, a)`를 미분하면 `a > 0`에서 1, 그 외 0 입니다. 따라서 역전파에서 상류 그래디언트 `dh`에 `h <= 0` 위치를 0으로 마스킹하는 것이 ReLU의 역전파 전부입니다

이 두 공식을 식만 옮겨 구현하면 다음과 같습니다.

```python
def backward(X, h, y_pred, y_true, W2):
    N = X.shape[0]
    # softmax + cross-entropy의 결합 그래디언트는 간결
    dz2 = (y_pred - y_true) / N            # (N, 3)
    dW2 = h.T @ dz2                        # (16, 3)
    db2 = dz2.sum(axis=0)                  # (3,)

    dh  = dz2 @ W2.T                       # (N, 16)
    dh[h <= 0] = 0                         # ReLU의 역전파
    dW1 = X.T @ dh                         # (4, 16)
    db1 = dh.sum(axis=0)                   # (16,)
    return dW1, db1, dW2, db2
```

### 5.3 학습 루프

```python
np.random.seed(0)
W1 = np.random.randn(4, 16) * 0.1
b1 = np.zeros(16)
W2 = np.random.randn(16, 3) * 0.1
b2 = np.zeros(3)

lr = 0.05
for epoch in range(500):
    h, y_pred = forward(X_train, W1, b1, W2, b2)
    loss = cross_entropy(y_pred, Y_train)
    dW1, db1, dW2, db2 = backward(X_train, h, y_pred, Y_train, W2)
    W1 -= lr * dW1; b1 -= lr * db1
    W2 -= lr * dW2; b2 -= lr * db2

# 테스트 정확도
_, y_test_pred = forward(X_test, W1, b1, W2, b2)
acc = (y_test_pred.argmax(axis=1) == Y_test.argmax(axis=1)).mean()
# seed 0 기준 약 0.97. 시드·초기값을 바꾸면 0.93 ~ 1.0 범위에서 변동
```

Keras가 은닉되어 있는 `fit()` 한 줄 안에서 이와 거의 같은 일이 벌어집니다. 차이는 (1) 미분 공식을 프레임워크가 자동으로 계산해 주고, (2) GPU에서 병렬화되며, (3) Adam·BatchNorm·정규화 같은 부가 기법이 끼어 있다는 정도입니다.

### 5.4 층을 더 쌓으면

이 코드의 은닉층을 하나 늘려 3층 또는 4층 구조로 확장하면, `W1/b1 -> W2/b2 -> W3/b3 -> W_out/b_out` 처럼 파라미터 쌍이 하나씩 더 붙고 순전파·역전파에도 같은 패턴이 한 번씩 더 반복됩니다. 기본 틀이 동일하므로 **늘리는 비용은 크지 않지만**, 데이터가 작을 때는 층이 깊어질수록 학습이 불안정해지거나 과적합이 쉽게 옵니다. 작은 데이터(Iris 수준)는 얕은 네트워크로 시작해 점진적으로 키우는 것이 정석입니다.

## 6. 미니배치 학습

데이터 전체(`N`개)를 한 번에 넣어 기울기를 계산하면 메모리도 많이 들고 매 업데이트가 무거워집니다. 반대로 샘플 하나씩 넣으면 가중치가 매번 크게 흔들려 수렴이 불안정합니다. 실전의 타협점이 **미니배치(mini-batch)**입니다.

- 데이터를 셔플한 뒤 `batch_size` 개씩 잘라 각 배치마다 한 번의 순전파·역전파·업데이트를 수행
- 한 에포크(epoch) = 전체 데이터를 한 번 훑는 한 사이클
- 배치가 작을수록 업데이트가 잦고 노이즈가 커져 일반화에 도움, 클수록 기울기 추정이 안정

배치 크기는 보통 `32·64·128` 중에서 시작합니다. GPU 메모리 한도에 맞춰 위로 올리고, 소규모 데이터라면 아래로 내려 잡습니다.

## 7. Gradient Check - 직접 짠 역전파를 검증하기

역전파 공식은 손으로 쓰다 보면 부호나 인덱스에서 실수가 나기 쉽습니다. **Gradient Check**는 수치 미분과 역전파로 구한 그래디언트를 비교해 구현 오류를 잡는 표준 점검 기법입니다.

예를 들어 앞의 2층 신경망 예제에서 만든 `W1` 그래디언트 하나를 점검한다면 이렇게 씁니다.

```python
# 역전파로 구한 그래디언트
h, y_pred = forward(X_train, W1, b1, W2, b2)
dW1_bp, _, _, _ = backward(X_train, h, y_pred, Y_train, W2)

# 수치 미분으로 구한 그래디언트 (W1 전용 loss 래퍼)
def loss_W1(W1_try):
    _, y = forward(X_train, W1_try, b1, W2, b2)
    return cross_entropy(y, Y_train)

dW1_num = numerical_gradient(loss_W1, W1.copy())

rel_err = np.linalg.norm(dW1_bp - dW1_num) / (
    np.linalg.norm(dW1_bp) + np.linalg.norm(dW1_num) + 1e-9)
assert rel_err < 1e-6   # 이 정도면 거의 일치
```

프레임워크를 쓰면 자동 미분이 처리해 주지만, 자신의 구현을 공부하거나 연구 목적으로 새 레이어를 만들 때는 반드시 거쳐야 하는 단계입니다.

## 8. Keras `fit()`이 내부적으로 하는 일

이 챕터의 이해로 다시 Keras 학습 한 줄을 보면 의미가 달라집니다.

```python
history = model.fit(
    X_train, y_train,
    epochs=100, batch_size=32,
    validation_split=0.2,
)
```

이 한 줄 안에서 벌어지는 일을 순서대로 적으면 다음과 같습니다.

1. `batch_size` 크기로 데이터를 나눔
2. 각 배치에 대해 **순전파**로 예측 계산
3. `compile`에서 고른 **손실 함수**로 손실 계산
4. 자동 미분 엔진이 각 가중치의 **기울기**를 역전파로 계산
5. 옵티마이저(Adam 등)가 기울기로 **가중치 업데이트**
6. 2~5를 한 에포크 내내 반복
7. `validation_split`이 설정되어 있으면 에포크 끝에 검증 손실·지표 측정
8. `epochs`만큼 반복

`model.fit()`이 블랙박스처럼 느껴지지 않는다면, 앞 챕터들에서 sklearn이 감추던 부분을 한 단계 더 밑에서 보게 된 셈입니다.

## 마무리

이 챕터의 세 기둥(손실 함수·경사하강법·역전파)은 현대 딥러닝 학습의 공통 토대입니다. CNN·RNN·Transformer 어떤 구조가 오더라도 "순전파로 손실 계산 -> 역전파로 기울기 계산 -> 옵티마이저로 업데이트"라는 큰 틀은 변하지 않습니다. 다음 챕터에서는 이 토대 위에 "공간 구조"를 담는 첫 심화 구조인 **합성곱 신경망(CNN)**으로 넘어가, 이미지 인식에서 왜 MLP보다 CNN이 압도적으로 잘 작동하는지 살펴봅니다.

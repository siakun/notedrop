# 04. 순환 신경망 (RNN·LSTM) 개요

> CNN이 공간 구조를 담았다면, **순환 신경망(Recurrent Neural Network, RNN)**은 시간·순서 구조를 담습니다. 문장의 앞뒤 단어, 시계열의 과거와 현재처럼 "이전 입력이 다음 해석에 영향을 주는" 데이터에 맞춰 설계된 구조입니다. 이 챕터는 개요 수준으로 RNN·LSTM·GRU를 훑고, 이후 주류로 자리 잡은 Transformer까지 방향만 짚어 Part 4를 마무리합니다.

## 1. 시퀀스 데이터의 특성

이미지는 한 장을 통째로 넣어 분류할 수 있지만, 시퀀스는 다릅니다. 같은 단어 `"은"`이라도 앞에 나온 주어에 따라 의미가 달라지고, 주식 종가는 당일 값만이 아니라 **최근 며칠간의 흐름**이 중요합니다. MLP·CNN은 입력 길이가 고정된 벡터·이미지를 전제하지만, 시퀀스는 길이도 들쑥날쑥합니다.

대표적인 시퀀스 데이터는 다음과 같습니다.

- **자연어 텍스트**: 단어·토큰의 순열
- **음성 파형**: 시간축 위의 샘플 값
- **시계열**: 주가·온도·센서 측정치
- **영상**: 프레임의 시퀀스 (이미지 + 시간)

이 데이터들을 다루려면 네트워크가 "이전 시점의 상태를 어떤 형태로든 기억"하면서 다음 입력을 받아들여야 합니다.

## 2. RNN - 은닉 상태가 시간을 타고 흐름

기본 아이디어는 단순합니다. 각 시점 `t`에서 입력 `x_t`와 **이전 은닉 상태** `h_{t-1}`를 함께 받아 새 은닉 상태 `h_t`를 계산합니다. 같은 파라미터가 모든 시점에서 반복 사용되기 때문에 "Recurrent"라는 이름이 붙었습니다.

```text
h_t = tanh(W_xh · x_t + W_hh · h_{t-1} + b_h)
y_t = W_hy · h_t + b_y
```

`h_t`는 "지금까지 본 입력 전체를 요약한 벡터"로 볼 수 있고, 이 벡터가 다음 시점의 판단에 참고됩니다. 같은 `W_xh`·`W_hh`가 시점마다 재사용되어 파라미터 수가 시퀀스 길이와 무관하게 일정합니다. CNN의 "공간 축 가중치 공유"와 비슷한 발상의 "시간 축 가중치 공유"입니다.

### 2.1 기본 RNN의 한계

이론적으로는 충분히 긴 과거를 기억할 수 있어야 하지만, 실제로는 그렇지 못합니다. 역전파 시점에 기울기가 시간 축을 거슬러 올라가며 곱해지는데 이 과정에서 **기울기가 폭발하거나 사라지는(exploding / vanishing gradient)** 문제가 발생합니다. 결과적으로 기본 RNN은 5 ~ 10 스텝 정도의 짧은 의존만 잘 학습하고, 더 긴 맥락은 흐려지는 경향이 있습니다. 이 한계가 곧 LSTM의 존재 이유입니다.

## 3. LSTM - 게이트로 장기 기억 관리

**LSTM (Long Short-Term Memory)**은 기억과 망각을 조절하는 구조입니다. 핵심 아이디어는 "정보를 얼마나 기억할지, 얼마나 잊을지를 **게이트(gate)**라는 조절 장치로 학습하게 한다"는 데 있습니다. 이 구조는 1997년 Hochreiter와 Schmidhuber가 제안했습니다.

한 LSTM 셀은 은닉 상태 `h_t` 외에 **셀 상태(cell state) `c_t`**라는 별도의 "장기 기억 통로"를 함께 흘려보냅니다. 이 셀 상태를 세 개의 게이트가 조절합니다.

- **Forget gate**: 셀 상태에서 얼마나 버릴지
- **Input gate**: 새 입력에서 얼마나 받아들여 셀 상태에 더할지
- **Output gate**: 셀 상태에서 얼마나 꺼내 은닉 상태로 보낼지

게이트는 모두 sigmoid 출력으로 `0 ~ 1` 값을 내어 "얼마나 열고 닫을지"를 학습합니다. 덕분에 LSTM은 **수십~수백 스텝** 규모의 장기 의존성을 다룰 수 있고, 2010년대 중후반까지 자연어·음성·번역의 주력 구조였습니다.

## 4. GRU - 더 가벼운 대안

**GRU (Gated Recurrent Unit)**는 2014년 Cho 등이 제안한 LSTM의 간소화 버전입니다. 셀 상태를 따로 두지 않고 은닉 상태 하나로 합친 뒤, 게이트 개수를 2 개(update, reset)로 줄였습니다. 파라미터가 적어 학습이 빠르고, 성능은 LSTM과 비슷한 수준을 내는 경우가 많아 실무에서도 자주 쓰입니다.

| 모델 | 게이트 수 | 상태 | 파라미터 | 특징 |
|---|---|---|---|---|
| 기본 RNN | 0 | `h_t` | 최소 | 장기 의존성 약함 |
| LSTM | 3 | `h_t`, `c_t` | 가장 많음 | 장기 의존성 강함 |
| GRU | 2 | `h_t` | LSTM의 약 3/4 | LSTM과 유사 성능, 더 가벼움 |

## 5. Keras로 맛보기 - 사인파 다음 값 예측

간단한 시계열 회귀로 감을 잡아 봅니다. 노이즈를 섞은 사인파를 만들고, 앞 20 스텝으로 그다음 값을 예측하는 LSTM을 돌립니다.

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, SimpleRNN, GRU, Dense

np.random.seed(0)
tf.random.set_seed(0)

# 1) 사인파 시계열 생성
t = np.linspace(0, 100, 1000)
series = np.sin(t) + 0.1 * np.random.randn(len(t))

# 2) 윈도우로 슬라이스: 앞 20 스텝 -> 그다음 1 값
WINDOW = 20
X, y = [], []
for i in range(len(series) - WINDOW):
    X.append(series[i : i + WINDOW])
    y.append(series[i + WINDOW])
X = np.array(X).reshape(-1, WINDOW, 1)   # (N, 20, 1) - (샘플, 타임스텝, 피처)
y = np.array(y)

# 3) 학습/테스트 분할
split = int(len(X) * 0.8)
X_train, X_test = X[:split], X[split:]
y_train, y_test = y[:split], y[split:]

# 4) LSTM 모델
model = Sequential([
    LSTM(32, input_shape=(WINDOW, 1)),
    Dense(1),
])
model.compile(optimizer="adam", loss="mse")
model.fit(X_train, y_train, epochs=10, batch_size=32, verbose=0)

model.evaluate(X_test, y_test, verbose=0)
# 시드·노이즈에 따라 테스트 MSE 대략 0.01 ~ 0.03 내외
```

입력 shape `(WINDOW, 1)`의 첫 차원이 타임스텝, 둘째 차원이 각 시점의 피처 개수입니다. 여러 피처를 가진 시계열이라면 `(WINDOW, n_features)`로 확장하면 그대로 받아들입니다. `LSTM` 대신 `SimpleRNN` 또는 `GRU`로 갈아 끼워 (위 import에 이미 포함) 비교해 보면 세 구조의 감이 직접 잡힙니다.

## 6. 텍스트에서의 RNN·LSTM

문자·단어를 토큰 시퀀스로 바꿔 RNN에 흘려보내면 언어 모델·분류·번역을 만들 수 있습니다. 이 흐름의 핵심 조각은 다음 세 가지로 Part 6 자연어처리에서 본격적으로 다룹니다.

- **토큰화·임베딩**: 단어를 고정 차원 벡터로 변환
- **RNN/LSTM 인코더**: 시퀀스를 하나의 벡터로 요약
- **디코더**: 요약 벡터에서 출력 시퀀스를 생성 (번역·요약·대화)

RNN·LSTM은 한동안 번역과 생성 모델의 주류였습니다. 2014년 Sutskever·Vinyals·Le의 **seq2seq** 논문이 이 구조로 기계 번역 성능을 크게 끌어올렸고, 이후 **Attention 메커니즘**이 더해지며 그 흐름이 강화되었습니다.

## 7. Transformer 로의 전환

2017년 Vaswani 등의 *"Attention is All You Need"* 이후 NLP의 중심은 빠르게 **Transformer**로 이동했습니다. 핵심 차이는 "시간 축을 순차적으로 따라가지 않는다"입니다. 입력 시퀀스를 **한 번에** 보고, 토큰 사이의 관계를 **self-attention**으로 계산합니다.

- RNN·LSTM: 순차 처리 때문에 긴 문장에서 느리고, 먼 거리 의존성이 여전히 약함
- Transformer: 병렬 처리가 쉽고, 토큰 간 거리와 무관한 직접적 상호 참조가 가능

GPT 시리즈·BERT·T5·LLaMA 같은 대규모 언어 모델은 모두 Transformer 계열입니다. 2020년대 이후 실무 NLP에서 Transformer가 주류가 된 이유는 병렬 처리가 쉽고, 긴 거리의 토큰 관계도 직접 다루기 좋기 때문입니다.

그렇다고 RNN·LSTM이 완전히 사라진 것은 아닙니다. **가벼운 시계열 예측·온디바이스 모델·스트리밍 음성 처리** 같은 영역에서는 여전히 현역입니다. 입력 길이가 짧고 자원이 빠듯한 상황에서는 Transformer의 오버헤드가 오히려 부담이 될 수 있습니다.

Transformer의 구조·Attention 수식·미세 조정 기법은 Part 6 자연어처리 끝에서 한 번 더 짚습니다.

# 01. 강화학습 입문 - 확률 기초와 멀티암드 밴딧

> **강화학습**은 정답 레이블 대신, 환경과 상호작용하며 받는 **보상**만으로 정책을 학습하는 방식입니다. 이 챕터에서는 먼저 강화학습의 전체 그림을 잡고, 이어서 확률과 조건부 기대값 같은 기초 수학을 정리합니다. 마지막에는 가장 단순한 강화학습 문제인 **멀티암드 밴딧**을 정책 경사로 구현해 봅니다.

## 1. 강화학습이란

머신러닝은 학습 신호의 종류에 따라 세 갈래로 나뉩니다.

| 유형 | 입력 | 출력 | 학습 신호 |
|---|---|---|---|
| 지도학습 | 피처 X | 정답 레이블 Y | 정답과의 오차 최소화 |
| 비지도학습 | 피처 X | (군집·표현) | 데이터 내재 구조 |
| 강화학습 | 환경의 상태 | 행동(Action) | 보상(Reward) 최대화 |

> [!note] 강화학습의 정의
> 에이전트(Agent)가 역동적인 환경(Environment)과 반복적으로 상호작용하면서, 시행착오를 통해 **누적 보상(Cumulative Reward)을 최대화**하는 정책을 학습하는 머신러닝 기법입니다.

지도학습은 "이 입력이 오면 저 정답을 출력하라" 라고 정답이 주어집니다. 강화학습은 정답도, 명시적 프로그램도 없습니다. **오직 보상 신호** 만으로 "어떤 상태에서 어떤 행동이 좋은가"를 학습해야 합니다.

### 1.1 5대 구성 요소

강화학습 문제를 정의할 때 반드시 등장하는 다섯 가지 요소가 있습니다.

| 개념 | 강아지 훈련 비유 | 자율주차 비유 |
|---|---|---|
| Agent | 강아지(학습 주체) | 자동차 제어 컴퓨터 |
| Environment | 훈련사 + 주변 환경 | 도로, 다른 차, 날씨 |
| Observation | 훈련사의 명령·제스처 | 카메라·GPS·LiDAR 값 |
| Action | 앉기·점프·물기 | 조향·가속·제동 |
| Reward | 간식·칭찬 | 주차 성공 +, 충돌 - |
| Policy | 관측 -> 행동 대응 규칙 | 센서값 -> 조작 대응 규칙 |

> [!info] 신경망 학습 목표와의 차이
> 지도학습 신경망은 **비용 함수(Cost)를 최소화**해 가중치를 학습합니다. 강화학습은 **누적 보상(Reward)을 최대화**하는 정책을 학습합니다. 코스트 최소화 vs 리워드 최대화 가 핵심 대비입니다.

### 1.2 강화학습 워크플로우

전형적인 강화학습 프로젝트는 다음 단계를 따릅니다.

1. **환경 구성**: OpenAI Gym 등 시뮬레이터를 쓰거나, 실제 물리 시스템에 연결
2. **보상 신호 정의**: 목표 달성 시 +, 실패 시 - (설계가 까다로움)
3. **에이전트 설계**: 정책 + 학습 알고리즘 선택
4. **훈련 루프**: 환경과 상호작용하며 정책 업데이트
5. **검증·배포**: 다양한 시나리오에서 검증 후 서비스 투입

> [!warning] 환경 구성이 가장 큰 난관
> 강화학습이 지도학습만큼 널리 쓰이지 않는 이유는 "문제를 환경으로 변환하는 단계" 자체가 어렵기 때문입니다. 자율주행·로봇 제어는 시뮬레이터 품질이 학습 성능을 그대로 좌우합니다.

## 2. 알고리즘 분류

강화학습 알고리즘은 **환경 모델을 아는가**와 **무엇을 직접 학습하는가** 두 축으로 분류됩니다.

```text
강화학습
├── Model-based
│   ├── Given Model      (예: 게임 룰이 주어지는 알파제로)
│   └── Learn Model      (모델 자체를 학습)
└── Model-free
    ├── Value-based      (예: DQN, Q-learning)
    ├── Policy-based     (예: Policy Gradient)
    └── Actor-Critic     (Value + Policy 병행)
```

### 2.1 Model-based vs Model-free

- **Model-based**: 상태 전이 확률과 보상 함수를 알고 있는 경우. 에이전트가 직접 행동하지 않고도 시뮬레이션으로 최적 행동을 계획할 수 있습니다. 바둑·체스처럼 **규칙이 완전히 주어지는** 환경에 적합.
- **Model-free**: 환경 모델 없이 **경험만으로** 학습. 실세계에서 환경을 완벽히 아는 경우가 드물기 때문에 대부분의 실용 알고리즘은 이쪽에 속합니다.

### 2.2 Value / Policy / Actor-Critic

Model-free 계열은 다시 세 갈래로 나뉩니다.

- **Value-based**: 가치 함수 V(s) 또는 Q(s, a)를 학습. 각 상태에서 가장 높은 가치를 주는 행동을 선택하는 것이 암묵적 정책. 대표 DQN
- **Policy-based**: 정책 π(a|s)를 직접 학습. 기대 보상을 목표로 곧바로 최적화하므로 학습이 안정적. 이 챕터의 밴딧 실습이 이 계열
- **Actor-Critic**: 정책(Actor)과 가치 함수(Critic)를 동시 학습. 정책 경사의 분산을 가치 함수로 줄여 수렴을 빠르게 하는 혼합형. 현대 PPO·A3C 등의 기반

## 3. 확률 기초

강화학습은 본질적으로 확률 기반 의사결정을 다룹니다. 보상이 확률적으로 분배되는 환경에서 **기대 보상을 최대화**해야 하므로, 확률변수·분포·기대값 개념이 필수입니다.

### 3.1 확률변수

> [!note] 확률변수 (Random Variable)
> 무작위 실험에서 일어날 수 있는 결과 하나하나에 수치를 할당하는 **함수**입니다. 표본공간 Ω 를 정의역, 실수 ℝ 를 공역으로 합니다.
>
> $X \colon \Omega \to \mathbb{R}$

**예시**

- 동전 1회 던지기: X = 앞이면 1, 뒤면 0
- 주사위 1회: X $\in$ {1, 2, 3, 4, 5, 6}
- 동전 2회 던져 앞면 횟수: X $\in$ {0, 1, 2}

### 3.2 확률분포

확률변수가 가질 수 있는 모든 값과 그에 대응하는 확률의 짝을 모아 놓은 것이 **확률분포**입니다. 동전 2회 던지기에서 앞면 횟수의 분포는 다음과 같습니다.

| X (앞면 횟수) | 경우 | P(X) |
|---|---|---|
| 0 | (뒤,뒤) | 1/4 |
| 1 | (앞,뒤), (뒤,앞) | 2/4 |
| 2 | (앞,앞) | 1/4 |

모든 경우의 확률을 합하면 1이 됩니다(1/4 + 2/4 + 1/4 = 1). 이산형이 아닌 연속형 확률변수는 확률밀도함수(PDF)로 표현하며, 구간의 적분값이 확률이 됩니다.

## 4. 조건부 확률과 베이즈 정리

### 4.1 조건부 확률

> [!note] 조건부 확률 (Conditional Probability)
> 사건 B가 일어났을 때 사건 A가 일어날 확률. P(A | B)로 표기합니다.
>
> $P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}$

P(A | B)와 P(B | A)는 **일반적으로 다릅니다**. 분모가 다르기 때문입니다.

### 4.2 베이즈 정리

$P(A \mid B) = \dfrac{P(B \mid A) \cdot P(A)}{P(B)}$

- P(A): 사전 확률(Prior)
- P(B | A): 우도(Likelihood)
- P(A | B): 사후 확률(Posterior)
- P(B): 증거(Evidence)

> [!example] 초콜릿 선물 예시
> - P(초콜릿 줌 | 좋아함) = 0.4
> - P(초콜릿 줌 | 좋아하지 않음) = 0.3 (예의상)
> - P(좋아함) = 0.5
>
> 전체확률: P(초콜릿 줌) = 0.5 x 0.4 + 0.5 x 0.3 = 0.35
> 사후확률: P(좋아함 | 초콜릿 줌) = (0.4 x 0.5) / 0.35 $\approx$ 0.571

### 4.3 예시 - 마라톤 동호회 분할표

50 명 중 완주·성별 분포를 정리한 표입니다.

| 성별 | 완주 | 기권 | 합계 |
|---|---|---|---|
| 남성 | 27 | 8 | 35 |
| 여성 | 9 | 6 | 15 |
| 합계 | 36 | 14 | 50 |

- **결합 확률** P(여성 $\cap$ 기권) = 6 / 50 = 0.12
- **조건부 확률** P(기권 | 여성) = 6 / 15 = 0.4
- **조건부 확률** P(완주 | 여성) = 9 / 15 = 0.6

조건이 주어지면 분모가 변하므로 확률도 달라집니다. 이 감각이 강화학습에서 "상태를 주었을 때의 기대 보상"을 계산할 때 곧바로 쓰입니다.

## 5. 기대값과 조건부 기대값

### 5.1 기대값

> [!note] 기대값 (Expected Value)
> 확률변수의 **이론적 평균값**. 각 값에 해당 확률을 곱해 모두 합한 값입니다.
>
> $E[X] = \sum_{i} x_i \cdot P(x_i)$

**공정한 주사위**

$E[X] = 1 \cdot \tfrac{1}{6} + 2 \cdot \tfrac{1}{6} + 3 \cdot \tfrac{1}{6} + 4 \cdot \tfrac{1}{6} + 5 \cdot \tfrac{1}{6} + 6 \cdot \tfrac{1}{6} = 3.5$

**편향된 주사위** (홀수가 2배 자주 나오는 경우: 홀수 2/9, 짝수 1/9)

$E[X] = 1 \cdot \tfrac{2}{9} + 2 \cdot \tfrac{1}{9} + 3 \cdot \tfrac{2}{9} + 4 \cdot \tfrac{1}{9} + 5 \cdot \tfrac{2}{9} + 6 \cdot \tfrac{1}{9} = \tfrac{30}{9} \approx 3.33$

### 5.2 조건부 기대값

> [!note] 조건부 기대값
> 확률변수 X가 특정 값을 가졌을 때 확률변수 Y의 기대값입니다. 벨만 방정식의 뼈대가 됩니다.
>
> $E[Y \mid X = x] = \sum_{i} y_i \cdot P(Y = y_i \mid X = x)$

**예시**: 주사위 1회에서

- A = 1 (짝수 2, 4, 6) / 0 (나머지)
- B = 1 (값이 2, 3, 5) / 0 (나머지)

| 눈금 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| A | 0 | 1 | 0 | 1 | 0 | 1 |
| B | 0 | 1 | 1 | 0 | 1 | 0 |

- $E[A]$ = (0 + 1 + 0 + 1 + 0 + 1) / 6 = 1/2
- $E[A \mid B = 1]$: B = 1 인 경우(2, 3, 5)에서 A의 평균 = (1 + 0 + 0) / 3 = 1/3

두 값이 1/2 vs 1/3으로 다릅니다. 조건이 주어지면 분포가 달라지기 때문입니다. 다음 챕터(Part 7 Ch 02)에서 다룰 **상태 가치 함수 V(s)**는 정확히 이 조건부 기대값 형태로 정의됩니다.

$V(s) = E[G_t \mid S_t = s]$

### 6.1 정규 분포

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

rv = stats.norm()                         # 표준 정규 분포 (평균 0, 분산 1)
xx = np.linspace(-8, 8, 200)

plt.plot(xx, rv.pdf(xx))
plt.title("Normal PDF")
plt.xlabel("x"); plt.ylabel("p(x)")
plt.grid(); plt.show()
```

`rv.pdf(xx)`가 각 x 에서의 확률밀도값입니다. 샘플을 많이 뽑아 히스토그램을 그리면 PDF 곡선에 가까워집니다(대수의 법칙).

```python
samples = rv.rvs(size=10000, random_state=0)
plt.hist(samples, bins=40, density=True, alpha=0.6)
plt.plot(xx, rv.pdf(xx), linewidth=2)
plt.title("Normal samples vs PDF")
plt.show()
```

### 6.2 베르누이 분포

동전 던지기처럼 결과가 0 또는 1 인 분포입니다. 성공 확률 p 하나로 결정됩니다.

```python
mu = 0.5
rv = stats.bernoulli(mu)

x = np.array([0, 1])
plt.bar(x, rv.pmf(x))
plt.xticks([0, 1]); plt.ylim(0, 1)
plt.title(f"Bernoulli (p={mu})")
plt.show()
```

### 6.3 이항 분포

베르누이 시행을 n 번 반복해 성공 횟수의 분포를 본 것이 이항분포입니다.

```python
n, p = 2, 0.5
rv = stats.binom(n, p)

x = np.arange(n + 1)
plt.bar(x, rv.pmf(x))
plt.title(f"Binomial (n={n}, p={p})")
plt.show()

print(rv.pmf(0), rv.pmf(1), rv.pmf(2))
# 0.25 0.5 0.25
```

n=2, p=0.5 이항 분포는 앞에서 본 "동전 2회 앞면 횟수" 예시와 정확히 일치합니다.

## 7. 멀티암드 밴딧 (MAB)

### 7.1 문제 정의

> [!note] Multi-Armed Bandit (MAB)
> N 개의 손잡이를 가진 슬롯머신입니다. 손잡이마다 서로 다른 확률 분포로 보상을 주고, 에이전트는 **어느 손잡이가 가장 높은 기대 보상을 주는지** 찾아야 합니다. 강화학습에서 가장 단순한 프로토타입 문제입니다.

밴딧은 강화학습의 3 대 의존성 중 일부만 갖습니다.

| 의존성 | 기본 MAB의 모습 |
|---|---|
| Action 의존성 | 손잡이마다 보상 확률 다름 (있음) |
| Time 의존성 | 단일 스텝이라 단순 |
| State 의존성 | 상태 없음 |

덕분에 "**상태 없이 순수한 행동 선택**" 문제로 단순화되어 정책 경사의 핵심 아이디어를 빠르게 확인할 수 있습니다.
상태가 추가된 형태는 뒤의 Contextual Bandit 실습에서 다시 보게 됩니다.

### 7.2 정책 경사 손실

정책 π 가 각 손잡이에 대한 softmax 확률 분포이고, 에이전트가 이번 스텝에서 행동 `a`를 골라 보상 `r`을 받았다고 합시다. 이때 **선택한 행동의 확률**을 $\pi(a)$로 쓰면 정책 경사의 기본 손실 함수는 다음과 같습니다.

직관은 간단합니다. 좋은 보상을 준 행동은 다음에 더 자주 고르게 하고, 나쁜 보상을 준 행동은 덜 고르게 만드는 것입니다.

$\mathcal{L} = -\log \pi(a) \cdot r$

$\pi(a) \in (0, 1)$ 이므로 $\log \pi(a) < 0$, 따라서 $-\log \pi(a) > 0$ 입니다. 핵심은 이 로스를 줄이기 위한 그래디언트가 어느 방향을 향하느냐입니다.

- **보상이 양수**이면: 로스를 줄이려면 $\log \pi(a)$를 키워야 하므로 해당 행동의 확률 $\pi(a)$가 **증가**하는 방향으로 가중치가 갱신됩니다.
- **보상이 음수**이면: 부호가 뒤집혀 같은 항이 "커지면 로스가 더 작아지는" 관계가 반대로 바뀌므로, 해당 행동의 확률이 **감소**하는 방향으로 갱신됩니다.

이 단순한 규칙이 정책 경사의 전부입니다. 뒤 챕터의 복잡한 PPO·A3C도 결국 이 아이디어를 확장한 형태입니다.

## 8. 실습 1 - 4-손잡이 단일 밴딧

### 8.1 환경 정의

```python
import numpy as np
import tensorflow as tf

np.random.seed(0)
tf.random.set_seed(0)

# 4 개 손잡이. 값이 작을수록 + 보상 확률이 높아짐
# 정답: 인덱스 3 (값 -5)이 최적
bandit_arms = np.array([0.2, 0.0, -0.2, -5.0])
num_arms = len(bandit_arms)

def pull_bandit(arm_value: float) -> int:
    """정규분포 난수가 arm_value보다 크면 +1, 작으면 -1."""
    return 1 if np.random.randn() > arm_value else -1
```

`pull_bandit`은 각 손잡이가 주는 확률적 보상을 모사합니다. `arm_value`가 작을수록 `np.random.randn() > arm_value` 조건이 만족될 가능성이 높아 +1 보상을 자주 돌려줍니다.

### 8.2 정책 네트워크와 학습 루프

```python
# 각 손잡이에 대한 학습 가능한 선호도(logit)
weights = tf.Variable(tf.ones([num_arms]), dtype=tf.float32)
optimizer = tf.keras.optimizers.Adam(learning_rate=1e-3)

total_episodes = 1000
rewards_sum = np.zeros(num_arms)

for ep in range(total_episodes):
    # 1. 현재 정책(softmax 확률)
    policy = tf.nn.softmax(weights).numpy()

    # 2. 정책 비례 샘플링 (탐색 + 활용)
    action = np.random.choice(num_arms, p=policy)

    # 3. 환경과 상호작용해 보상 수령
    reward = pull_bandit(bandit_arms[action])

    # 4. 정책 경사 업데이트
    with tf.GradientTape() as tape:
        probs = tf.nn.softmax(weights)
        loss = -tf.math.log(probs[action]) * reward

    grads = tape.gradient(loss, [weights])
    optimizer.apply_gradients(zip(grads, [weights]))

    rewards_sum[action] += reward

best = int(np.argmax(weights.numpy()))
print("final weights:", weights.numpy())
print(f"에이전트가 선택한 최적 손잡이: {best + 1} 번")
print(f"실제 최적(정답): {int(np.argmin(bandit_arms)) + 1} 번")
```

시드를 고정했기 때문에 위 코드는 인덱스 3 (정답)에 안정적으로 수렴합니다. 에피소드를 10~50 회로 줄이면 학습이 덜 되어 엉뚱한 손잡이를 고르기도 합니다. `bandit_arms` 배열을 `[0.2, 0, -5, 0.2]` 처럼 바꿔 정답 위치를 옮기거나, 시드를 지워 여러 실행의 수렴 편차를 관찰해 보세요.

> [!info] Softmax 샘플링 이 곧 탐색 + 활용
> 정책이 [0.1, 0.1, 0.1, 0.7] 이라도 확률 0.3 으로는 다른 손잡이를 뽑습니다. 이 자체가 자연스러운 **탐색(exploration)** 역할을 합니다. 뒤에서 다룰 $\epsilon$-greedy는 이 탐색을 명시적으로 주입하는 다른 방식입니다.

## 9. 실습 2 - Contextual Bandit

### 9.1 문제 정의

기본 MAB에 "**어떤 슬롯머신인지**" 라는 상태(Context)가 추가된 문제입니다. 슬롯머신 3 대, 각 머신마다 4 개 손잡이 (총 12 개 조합)를 두고, 머신은 환경이 랜덤 선택합니다. 에이전트는 **각 머신마다 최적 손잡이**가 다르다는 사실을 학습해야 합니다.

### 9.2 환경 클래스

```python
class ContextualBandit:
    def __init__(self):
        # 머신 x 손잡이. 값이 작을수록 + 보상 확률 큼
        # 머신 0: 손잡이 4 (index 3), 머신 1: 손잡이 2 (index 1),
        # 머신 2: 손잡이 1 (index 0)이 각각 최적
        self.bandits = np.array([
            [ 0.2,  0.0, -0.0, -5.0],
            [ 0.1, -5.0,  1.0,  0.25],
            [-5.0,  5.0,  5.0,  5.0],
        ])
        self.num_bandits, self.num_actions = self.bandits.shape
        self.state = 0

    def get_bandit(self) -> int:
        """랜덤으로 슬롯머신을 선택하고 상태 번호를 돌려줍니다."""
        self.state = np.random.randint(self.num_bandits)
        return self.state

    def pull_arm(self, action: int) -> int:
        arm_value = self.bandits[self.state, action]
        return 1 if np.random.randn() > arm_value else -1
```

### 9.3 정책 네트워크 (Keras Dense)

상태(머신 번호)를 원핫 벡터로 만들어 Dense 층 한 개를 태운 뒤 softmax로 행동 확률을 얻는 아주 작은 네트워크입니다.

```python
class ContextualAgent(tf.keras.Model):
    def __init__(self, num_states: int, num_actions: int):
        super().__init__()
        self.num_states = num_states
        self.fc = tf.keras.layers.Dense(
            num_actions,
            activation="softmax",
            kernel_initializer="ones",
            use_bias=False,
        )

    def call(self, state_idx):
        # state_idx: (batch,) int32
        one_hot = tf.one_hot(state_idx, depth=self.num_states)
        return self.fc(one_hot)                     # (batch, num_actions)
```

### 9.4 학습 루프 ($\epsilon$-greedy 탐색)

```python
np.random.seed(0)
tf.random.set_seed(0)

env = ContextualBandit()
agent = ContextualAgent(env.num_bandits, env.num_actions)
# 단순 정책 경사에서는 plain SGD 만으로도 수렴이 가능하다는 감각을 보이기 위해
# Adam 대신 SGD를 씁니다. Adam으로 바꾸면 더 빠르게 수렴합니다.
optimizer = tf.keras.optimizers.SGD(learning_rate=1e-3)

total_episodes = 10000
epsilon = 0.1                                       # 10% 확률로 무작위 탐색
rewards = np.zeros((env.num_bandits, env.num_actions))

for ep in range(total_episodes):
    s = env.get_bandit()
    s_tensor = tf.constant([s], dtype=tf.int32)

    # epsilon-greedy 탐색
    if np.random.rand() < epsilon:
        action = np.random.randint(env.num_actions)
    else:
        probs = agent(s_tensor).numpy()[0]
        action = int(np.argmax(probs))

    reward = env.pull_arm(action)

    with tf.GradientTape() as tape:
        probs = agent(s_tensor)[0]
        loss = -tf.math.log(probs[action]) * reward

    grads = tape.gradient(loss, agent.trainable_variables)
    optimizer.apply_gradients(zip(grads, agent.trainable_variables))

    rewards[s, action] += reward

# 머신별 최적 손잡이 확인
for m in range(env.num_bandits):
    probs = agent(tf.constant([m], dtype=tf.int32)).numpy()[0]
    chosen = int(np.argmax(probs)) + 1
    true_best = int(np.argmin(env.bandits[m])) + 1
    print(f"머신 {m + 1}: 예측 {chosen}번 / 정답 {true_best}번")
```

시드를 고정한 실행에서는 세 머신 모두 정답을 맞춥니다 (머신 1 -> 4번, 머신 2 -> 2번, 머신 3 -> 1번). 시드를 지우면 학습률·초기화·탐색 확률에 따라 일부 머신에서 오답이 섞여 나오기도 하므로, 결과가 흔들리면 에피소드 수를 늘리거나 옵티마이저를 `Adam`으로 바꿔 보세요. $\epsilon$-greedy의 10% 탐색은 "늘 같은 손잡이만 뽑아 지역해에 갇히는" 상황을 막아 줍니다.

## 10. 정리

| 개념 | 한 줄 요약 |

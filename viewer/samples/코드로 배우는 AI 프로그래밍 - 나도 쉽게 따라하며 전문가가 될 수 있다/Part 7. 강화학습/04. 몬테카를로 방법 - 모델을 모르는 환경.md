# 04. 몬테카를로 방법 - 모델을 모르는 환경

> 앞 챕터의 동적 프로그래밍은 **환경을 안다**는 강한 전제를 깔고 있었습니다. 하지만 실제 응용에서는 상태 전이 확률도, 보상 함수도 사전에 주어지지 않는 경우가 훨씬 많습니다. 그래서 모델 없이도 배울 수 있는 접근이 필요합니다. 이 챕터에서는 에이전트가 직접 모은 **에피소드 샘플** 만으로 가치 함수를 학습하는 **몬테카를로(MC) 방법**을 다룹니다.

## 1. DP에서 모델-프리로

Part 7 Ch 03의 동적 프로그래밍은 벨만 (최적) 방정식을 수치적으로 푸는 알고리즘이었습니다. 이를 돌리려면 다음 두 가지가 반드시 주어져야 합니다.

- 상태 전이 확률 $P(s' \mid s, a)$
- 보상 함수 $R(s, a)$

하지만 현실에서는 이 두 값을 사전에 아는 경우가 드뭅니다. 로봇 제어·게임·자율주행처럼 복잡한 환경일수록 상태 전이가 해석적으로 기술되지 않습니다. 모델을 모를 때도 돌아가는 기법이 필요합니다.

> [!note] 모델-프리(Model-Free) 강화학습
> 상태 전이 확률과 보상 함수를 모르는 상태에서, 에이전트가 환경과 상호작용해 얻은 **에피소드 샘플** 만으로 가치 함수·정책을 추정하는 접근입니다. 대표 기법이 **몬테카를로(MC)**와 **시간차 학습(TD)** 입니다.

DP와 MC를 한 표로 비교하면 성격 차이가 분명해집니다.

| 비교 축 | DP (모델 기반) | MC (모델 프리) |
|---|---|---|
| 필요 정보 | 전이 확률 + 보상 함수 전부 | 에피소드 샘플만 |
| 갱신 단위 | 모든 상태 일괄 벨만 갱신 | 방문한 상태만 샘플 평균 |
| 부트스트랩 | 다음 상태 추정치를 재귀 사용 | 사용하지 않음. 에피소드 끝까지의 실제 리턴 사용 |
| 수렴 특성 | 결정적, 빠름 | 확률적, 느림 (샘플 수에 비례) |
| 적용 전제 | 환경을 완전히 알 때만 | 에피소드를 수집할 수만 있으면 |

이 챕터에서는 MC를, Part 7 Ch 05에서 TD와 Q 러닝·DQN을 이어서 다룹니다.

## 2. 몬테카를로의 직관 - $\pi$ 값 추정

**몬테카를로(Monte Carlo)**는 "반복된 무작위 추출로 결정론적인 값을 수치 근사하는 알고리즘"의 총칭입니다. 핵심 원리는 단순합니다. "표본 평균은 시행 횟수가 늘수록 참값에 수렴한다" (대수의 법칙).

> [!note] MC 수치 근사의 성질
> - **불편성**: 시행 횟수가 늘면 추정치 평균이 참값에 접근
> - **분산 감소**: 시행 횟수가 늘수록 추정치 분산이 0으로 감소

### $\pi$ 값 추정

단위 원(반지름 1)의 1사분면 면적이 $\pi/4$ 라는 사실을 이용합니다. $x, y$를 $[0, 1]$에서 균등 샘플링하고 $x^2 + y^2 \le 1$이 만족되는 비율을 재면 그 값이 $\pi/4$에 수렴합니다.

```python
import random

def estimate_pi(n: int) -> float:
    inside = 0
    for _ in range(n):
        x, y = random.random(), random.random()
        if x * x + y * y <= 1:
            inside += 1
    return 4 * inside / n

random.seed(0)
for n in (100, 1_000, 10_000, 1_000_000):
    print(f"n={n:>8}  ->  pi ~= {estimate_pi(n):.5f}")
# 샘플 수가 늘수록 3.14159...에 접근 (정확한 값은 시드·런마다 조금씩 달라짐)
```

시행 수가 100에서 100 만으로 늘수록 추정치의 분산이 줄고 참값 3.14159...에 접근합니다. **MC 강화학습에서도 같은 원리로, 에피소드 샘플을 많이 모을수록 가치 함수 추정치가 참값에 수렴** 합니다.

## 3. MC 정책 평가

주어진 정책 $\pi$에 대해 상태 $s$의 가치는 정의상 "정책 $\pi$를 따를 때 $s$에서 얻을 리턴의 기댓값" 입니다.

$$
V_\pi(s) = \mathbb{E}_\pi [G_t \mid S_t = s], \qquad G_t = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{T-t-1} R_T
$$

MC는 이 기댓값을 **여러 에피소드에서 실제로 얻은 리턴의 산술 평균**으로 근사합니다. 구현의 관건은 "한 에피소드 안에서 같은 상태를 여러 번 방문했을 때 어떻게 셀 것인가" 입니다.

### 3.1 첫 방문 MC vs 모든 방문 MC

> [!note] 첫 방문(First-Visit) MC
> 한 에피소드에서 상태 $s$를 **처음 방문한 시점의 리턴만** 수집합니다. 에피소드 하나당 상태별 최대 1 개의 샘플이 생깁니다.

> [!note] 모든 방문(Every-Visit) MC
> 한 에피소드에서 상태 $s$를 **방문한 모든 시점의 리턴**을 각각 수집합니다. 방문 수만큼 샘플이 생깁니다.

### 3.2 간단 예제

$\gamma = 1$로 두고, 상태 A에서 출발해 B를 거쳐 종료까지 가는 한 에피소드를 상상해 봅시다. 보상 시퀀스가 $R_1, R_2, R_3, R_4$ 이고, **A는 $t = 0$과 $t = 2$ 두 번 방문됐다** 고 하겠습니다.

- $t = 0$ 에서의 리턴: $G_0 = R_1 + R_2 + R_3 + R_4$
- $t = 2$ 에서의 리턴: $G_2 = R_3 + R_4$

**첫 방문 MC** 추정에 기여하는 샘플은 $G_0$ 하나. **모든 방문 MC** 추정에는 $G_0$과 $G_2$ 둘 다 기여합니다. 구체적으로 $R_1 = 1, R_2 = 2, R_3 = 3, R_4 = 5$ 면 $G_0 = 11$, $G_2 = 8$. 이 에피소드 하나만 있을 때 첫 방문 MC는 $V(A) = 11$, 모든 방문 MC는 $V(A) = (11 + 8)/2 = 9.5$로 추정합니다.

두 방식은 에피소드 수가 충분히 많으면 **같은 값 $V_\pi(A)$에 수렴** 합니다. 유한 샘플에서는 모든 방문 MC가 샘플 수를 늘려 주므로 대체로 수렴이 조금 빠릅니다.

이 장의 구현은 **모든 방문 MC**를 기본으로 씁니다.

## 4. 점증적 평균과 러닝레이트

에피소드 $N$ 개를 모두 모은 뒤 일괄 평균을 내려면 $N$ 개 리턴을 메모리에 들고 있어야 합니다. 강화학습처럼 **계속 에피소드가 들어오는** 상황에서는 비효율적이지요.

해결책은 **점증적(incremental) 평균 갱신** 입니다. 새 샘플 $G_n$이 들어올 때마다 기존 추정치를 한 번만 조정합니다.

$$
V_n(s) \leftarrow V_{n-1}(s) + \frac{1}{N(s)} \bigl( G_n - V_{n-1}(s) \bigr)
$$

- $V_{n-1}(s)$: 기존 추정치
- $G_n - V_{n-1}(s)$: 새 관측과 기존 추정치의 차이 (오차)
- $1/N(s)$: 이 오차를 얼마나 반영할지 결정하는 가중치. 방문 횟수가 늘수록 줄어듦

실무에서는 상태별 방문 횟수 $N(s)$를 정확히 세기가 번거로울 때가 많아 $1/N(s)$를 **상수 러닝레이트 $\alpha$**로 대체하는 쪽을 선호합니다.

$$
V(s) \leftarrow V(s) + \alpha \bigl( G - V(s) \bigr)
$$

> [!info] $\alpha$의 해석
> $\alpha$가 크면 최신 에피소드 한 건이 추정치에 크게 반영됩니다 (학습이 빠르지만 분산이 큼). $\alpha$가 작으면 기존 추정을 많이 신뢰하고 조금씩 수정합니다 (느리지만 안정적). 정책·환경이 **계속 바뀌는** 비정상 상황에서는 상수 $\alpha$가 $1/N(s)$보다 유리합니다.

## 5. Q 함수와 $\epsilon$-greedy 개선

### 5.1 왜 Q 함수인가

상태 가치 함수 $V(s)$ 만으로는 정책을 개선할 수 없습니다. **개선하려면 "이 상태에서 어떤 행동이 가장 좋은가"가 필요한데, $V$는 행동별 정보를 담지 않기 때문** 입니다. 그래서 MC 에서도 행동 가치 함수 $Q(s, a)$를 추정합니다.

$$
Q_\pi(s, a) = \mathbb{E}_\pi [G_t \mid S_t = s, A_t = a]
$$

에피소드에서 **(상태, 행동) 쌍을 단위**로 리턴을 수집해 평균을 냅니다. 상태만 쓸 때보다 샘플이 필요한 수만큼 많아지는 대가가 따릅니다.

### 5.2 탐욕적 개선과 탐험의 필요성

$Q$를 알면 자연스러운 정책 개선은 각 상태에서 **argmax 행동**을 선택하는 것입니다 ($\pi'(s) = \arg\max_a Q(s, a)$). 이를 탐욕적(greedy) 정책이라 부릅니다. 그러나 순수 탐욕은 한 번 낮게 평가된 행동을 **영원히 버리는** 문제를 낳습니다. 해결책이 **$\epsilon$-greedy** 정책입니다.

$$
\pi(a \mid s) =
\begin{cases}
1 - \epsilon + \epsilon / |A| & a = \arg\max_{a'} Q(s, a') \\
\epsilon / |A| & \text{그 외}
\end{cases}
$$

확률 $\epsilon$으로 무작위 행동, $1 - \epsilon$으로 탐욕적 행동을 고르는 단순한 전략이지만 강력합니다. 실무에서는 **$\epsilon$을 학습 초기에 크게 두고 점차 줄이는** 스케줄($\epsilon$ decay)을 쓰는 것이 관행입니다.

### 6.1 `ExactMCAgent` - 1/N(s) 평균

모든 방문 MC로 $N(s)$를 직접 세어 평균을 내는 정석 구현입니다. 첫 방문 MC로 바꾸려면 `update`에서 에피소드 내 각 상태의 **첫 등장만** 카운트하도록 `visited_s` · `visited_sa` 집합을 써서 걸러 주면 됩니다.

```python
import numpy as np

class ExactMCAgent:
    """모든 방문 MC + 1/N(s) 평균 갱신 + epsilon-greedy."""

    def __init__(self, gamma: float, n_states: int, n_actions: int, epsilon: float):
        self.gamma = gamma
        self.n_states = n_states
        self.n_actions = n_actions
        self.epsilon = epsilon

        self.V = np.zeros(n_states)
        self.Q = np.zeros((n_states, n_actions))
        self.N_v = np.zeros(n_states)
        self.N_q = np.zeros((n_states, n_actions))
        self.S_v = np.zeros(n_states)                  # 리턴 누적합 (V 용)
        self.S_q = np.zeros((n_states, n_actions))     # 리턴 누적합 (Q 용)

    def get_action(self, state: int) -> int:
        if np.random.rand() < self.epsilon:
            return np.random.randint(self.n_actions)
        return int(np.argmax(self.Q[state]))

    def update(self, episode):
        """episode = [(s_t, a_t, r_{t+1}), ...]. 뒤에서부터 리턴을 누적."""
        G = 0.0
        for s, a, r in reversed(episode):
            G = r + self.gamma * G
            self.N_v[s]     += 1
            self.S_v[s]     += G
            self.N_q[s, a]  += 1
            self.S_q[s, a]  += G

    def compute_values(self):
        # 방문한 곳에만 평균을 남기고 나머지는 0 유지
        self.V = np.where(self.N_v > 0, self.S_v / np.maximum(self.N_v, 1), 0)
        self.Q = np.where(self.N_q > 0, self.S_q / np.maximum(self.N_q, 1), 0)

    def improve_policy(self):
        # 탐욕 정책 (행동 선택은 get_action이 epsilon-greedy로 섞어 줌)
        pass

    def reset(self):
        self.V[:] = 0; self.Q[:] = 0
        self.N_v[:] = 0; self.N_q[:] = 0
        self.S_v[:] = 0; self.S_q[:] = 0
```

### 6.2 `MCAgent` - 상수 러닝레이트

점증적 갱신에 $\alpha$를 쓰는 경량 버전입니다. 위 클래스를 상속하고 `update`만 바꿉니다.

```python
class MCAgent(ExactMCAgent):
    """V, Q를 alpha로 점증 갱신."""

    def __init__(self, gamma, n_states, n_actions, epsilon, lr):
        super().__init__(gamma, n_states, n_actions, epsilon)
        self.lr = lr

    def update(self, episode):
        G = 0.0
        for s, a, r in reversed(episode):
            G = r + self.gamma * G
            self.V[s]     += self.lr * (G - self.V[s])
            self.Q[s, a]  += self.lr * (G - self.Q[s, a])

    def compute_values(self):
        # 점증 갱신은 매 step 마다 V,Q가 바로 유지되므로 따로 계산 없음
        pass
```

### 6.3 에피소드 수집 루프

Ch 02·03 환경의 `reset`·`step` 시그니처 (5-tuple, seed 인자)를 그대로 씁니다. `GridworldEnv`의 초기 상태 분포가 종착점 0·15를 포함한 균등 분포이므로, 출발점이 곧바로 종착점이면 에피소드가 0 스텝으로 끝나 버립니다. 첫 `reset`을 종착점이 아닐 때까지 반복하는 가드를 둡니다.

```python
def run_episode(env, agent, seed: int | None = None):
    while True:
        obs, _ = env.reset(seed=seed)
        seed = None                                      # 다음 reset 부터는 자유 시드
        if obs not in (0, env.nS - 1):
            break                                        # 출발이 종착점이면 재샘플링

    episode = []
    while True:
        a = agent.get_action(obs)
        next_obs, r, terminated, truncated, _ = env.step(a)
        episode.append((int(obs), int(a), float(r)))
        obs = next_obs
        if terminated or truncated:
            break

    agent.update(episode)
    return episode
```

### 6.4 학습 스크립트

```python
from gridworld import GridworldEnv

np.random.seed(0)
env = GridworldEnv(shape=(4, 4))
env.reset(seed=0)                                    # 환경 내부 RNG도 고정

agent = MCAgent(
    gamma=1.0,
    n_states=env.nS,
    n_actions=env.nA,
    epsilon=0.3,
    lr=0.01,
)

for ep in range(5_000):
    run_episode(env, agent)
    if ep == 1_000:
        agent.epsilon = 0.1                              # 중반에 탐험 비중 낮춤
    if ep == 3_000:
        agent.epsilon = 0.01

print("V (4x4):")
print(agent.V.reshape(4, 4).round(2))
print("\n탐욕 정책 (argmax Q, U/R/D/L):")
for s in range(env.nS):
    if s in (0, env.nS - 1):
        print(".", end=" ")                          # 종착점은 의미 없으므로 표시
    else:
        print({0:"U", 1:"R", 2:"D", 3:"L"}[int(np.argmax(agent.Q[s]))], end=" ")
    if s % 4 == 3:
        print()
```

학습이 충분히 돌아가면 종착점 0·15 주변이 0에 가깝고 먼 상태일수록 $V$가 음수로 깊어집니다. argmax 정책은 각 상태에서 가까운 종착점 쪽으로 가리키게 됩니다.

## 7. MC vs DP 오차 실험

Ch 03의 DP로 계산한 가치 함수를 "참값"으로 놓고, MC 추정치가 에피소드 수에 따라 어떻게 접근하는지 관찰합니다.

```python
import time

# DP로 참값 계산 (환경을 알고 있을 때). 앞 장에서 만든 TensorDP와 build_tensors 사용
from part7_ch03 import TensorDP, build_tensors
P_tensor, R_matrix = build_tensors(env)
dp = TensorDP(P_tensor, R_matrix, gamma=1.0)
V_dp = dp.policy_evaluation()                                # 균등 정책의 V 참값

# MC를 여러 번 돌려 추정치 분포를 관찰
N_RUNS = 10
TOTAL_EPS = 2_000
LOG_EVERY = 500
snapshots = []

for run in range(N_RUNS):
    np.random.seed(run)
    agent = ExactMCAgent(gamma=1.0, n_states=env.nS, n_actions=env.nA, epsilon=1.0)
    history = []
    for ep in range(TOTAL_EPS):
        run_episode(env, agent)
        if (ep + 1) % LOG_EVERY == 0:
            agent.compute_values()
            history.append(agent.V.copy())
    snapshots.append(history)

snaps = np.stack(snapshots)                                   # (runs, checkpoints, nS)
errors = snaps - V_dp[None, None, :]
print("RMS error per checkpoint:", np.sqrt((errors ** 2).mean(axis=(0, 2))))
```

수백 회 에피소드 수준에서는 run 마다 추정치가 상당히 흔들리지만, 2,000 에피소드쯤 되면 여러 run의 평균이 DP 참값과 눈에 띄게 가까워지고 분산도 줄어듭니다. 이것이 앞에서 본 대수의 법칙이 강화학습 가치 추정에 그대로 적용되는 모습입니다.

### 7.1 러닝레이트 $\alpha$ 비교

$\alpha$ 값을 바꿔 가며 같은 실험을 돌리면 아래 경향이 일관되게 나타납니다.

| $\alpha$ | 양상 |
|---|---|
| 1.0 | 가장 최근 에피소드가 추정치를 통째로 덮어씀. 분산 극대, 수렴 안 함 |
| 0.1 | 빠르게 반응하지만 여전히 흔들림 |
| 0.01 | 부드럽게 수렴, DP 참값에 근접 |
| 0.001 | 매우 안정적이지만 수렴이 느림 |
| 0.0001 | 너무 느려 2,000 에피소드로는 학습이 거의 안 됨 |

실전에서는 **학습 초기에 $\alpha$를 크게 시작해 후반에 작게 줄이는** 스케줄을 자주 씁니다. 앞서 다룬 $\epsilon$ decay와 같은 맥락이지요.

## 8. 정리와 MC의 한계

> [!note] MC의 장점
> - 환경 모델을 몰라도 에피소드만 있으면 학습 가능
> - 마르코프 속성에 크게 의존하지 않음 (샘플 기반)
> - 관심 있는 상태·행동에만 집중 가능 (부트스트랩 없음)
> - 구현이 단순하고 직관적

> [!warning] MC의 단점
> - 에피소드가 **끝나야** 리턴이 확정되므로 업데이트가 에피소드 단위 (긴 에피소드·연속 작업 문제에 불리)
> - 상태 간 연쇄 관계를 활용하지 못함 (각 방문을 독립 샘플로 취급)
> - 수렴에 많은 시뮬레이션 필요
> - 에피소드 분산이 커 $\alpha$ 선택에 민감

이 단점들을 보완하려는 시도가 다음 챕터(Part 7 Ch 05)의 **시간차 학습(TD)** 입니다. TD는 DP의 부트스트랩 (다음 상태 추정치 재사용)과 MC의 샘플링을 결합해 **매 스텝마다** 갱신이 가능해지면서도 환경 모델 없이 학습합니다. 이 기반 위에 SARSA, Q-러닝, DQN이 차례로 얹히는 것이 다음 챕터의 흐름입니다.

# 04. 토픽 모델링·트렌드 분석 - 뉴스·문서 군집화

> 이 챕터의 질문은 단순합니다. 수천~수만 건의 문서를 모아 두었을 때, 그 안에 **어떤 주제가 몇 개 있고 시간이 지나며 어떻게 변하는가**를 읽어내는 것입니다. 이를 위해 앞에서 본 TF-IDF, K-Means, A-Priori를 다시 활용하고, 여기에 LDA와 몇 가지 시각화 도구를 더합니다.

## 1. 토픽 모델링과 트렌드 분석

두 작업을 한 문장으로 구분하면 다음과 같습니다.

- **토픽 모델링(Topic Modeling)**: "이 문서 집합은 어떤 주제들로 나뉘는가"를 찾아내는 작업. 대표 기법이 K-Means(TF-IDF + 군집화)와 **LDA** (Latent Dirichlet Allocation, Blei 등 2003)
- **트렌드 분석(Trend Analysis)**: 토픽별·키워드별 **시간 축** 위의 빈도 변화를 추적하는 작업. 시간 윈도(월/분기/연) 단위로 집계해 시계열로 봅니다

둘 다 **라벨 없이 문서 집합만** 있으면 돌아가는 비지도 기법이며, 수집 단계에서 각 문서의 게시일(timestamp)을 함께 저장해 두는 것이 중요합니다.

## 2. 문서 수집과 메타데이터

국내 뉴스 트렌드 분석에서는 한국언론진흥재단의 **빅카인즈(BIGKinds)**를 자주 씁니다. 키워드, 기간, 언론사를 지정해 CSV·Excel로 바로 내려받을 수 있어 크롤러 없이도 대규모 뉴스 데이터를 빠르게 확보할 수 있기 때문입니다.

내려받은 파일에는 보통 "제목·본문·게시일·언론사·주제분류" 같은 정보가 함께 들어 있어 후속 분석에 필요한 메타데이터도 이미 갖춰져 있습니다.

웹 크롤러(Part 6 Ch 02)로 직접 수집하는 경우에도 "본문, 게시일, 출처" 세 컬럼을 최소한 확보해야 트렌드 분석이 가능합니다.

```python
import pandas as pd

df = pd.read_csv("news.csv")
df["date"] = pd.to_datetime(df["date"])
df = df.sort_values("date").reset_index(drop=True)

df.head(2)[["date", "media", "title"]]
```

## 3. 전처리 요약

이전 챕터들에서 다룬 그대로입니다. 한국어면 KoNLPy, 영어면 NLTK/spaCy로 토큰화·불용어 제거·품사 필터링(주로 명사만 남김)을 수행해 `clean_text` 컬럼을 만듭니다.

```python
from konlpy.tag import Okt

okt = Okt()

STOP = {"것", "등", "수", "때", "등등", "및", "이번", "지난",
        "오늘", "최근", "그", "저", "이"}

def to_nouns(text: str) -> str:
    nouns = okt.nouns(str(text))
    nouns = [n for n in nouns if n not in STOP and len(n) > 1]
    return " ".join(nouns)

df["clean_text"] = (df["title"].fillna("") + " " + df["content"].fillna("")).map(to_nouns)
```

워드클라우드는 직관적이지만 "해상도가 낮은" 도구입니다. 상위 단어들이 보일 뿐 단어 간 관계·주제 덩어리는 드러나지 않습니다. 다음 섹션의 토픽 모델링이 그 역할을 합니다.

## 5. K-Means로 토픽 군집화

TF-IDF + K-Means는 "비슷한 단어 분포를 가진 문서끼리 묶는" 가장 단순하고 빠른 토픽 모델링입니다. 코드는 Part 3 Ch 05와 Part 6 Ch 01의 결합입니다.

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.cluster import KMeans
import numpy as np

tfidf = TfidfVectorizer(max_df=0.9, min_df=5, ngram_range=(1, 1))
X = tfidf.fit_transform(df["clean_text"])       # (N, vocab)

k = 8
km = KMeans(n_clusters=k, n_init=10, random_state=42)
df["topic"] = km.fit_predict(X)

# 각 클러스터의 대표 단어 상위 10개
terms = tfidf.get_feature_names_out()
for ci in range(k):
    center = km.cluster_centers_[ci]
    top_idx = np.argsort(-center)[:10]
    print(f"[Topic {ci}]", " ".join(terms[top_idx]))
```

각 토픽의 `cluster_centers_`는 TF-IDF 공간에서의 중심 벡터이고, 그 중심에서 큰 값을 가진 단어들이 **해당 토픽의 핵심어** 입니다. "정치", "경제", "연예", "스포츠" 처럼 사람 눈으로 읽히는 토픽이 자연스럽게 떠오르는 경우가 많습니다.

`k` 결정은 Part 3 Ch 05의 엘보우·실루엣 방법이 그대로 적용됩니다. 뉴스 도메인에서는 분야 수(정치·경제·사회·국제·문화·스포츠·IT·연예 등)가 경험적으로 6~12 사이입니다.

> [!example] 학술 문헌 분석에도 같은 파이프라인
> 같은 `TF-IDF + K-Means + 워드클라우드` 조합은 **논문 초록 집합**에도 그대로 돌릴 수 있습니다. 예컨대 특정 분야 논문 초록 수십 편을 대상으로 군집을 돌리면 어떤 하위 주제가 압도적으로 많은지 드러나, 연구 방향을 정하는 **주제 기획 도구**로 활용할 수 있습니다. 실제로 파킨슨병 관련 논문 초록에서 이 파이프라인을 돌려 "gait(보행)" 키워드가 핵심 클러스터로 떠올라 연구 주제를 **보행 분석**으로 확정한 사례가 있습니다.
>
> 뉴스 도메인에만 매이지 않는 분석 틀이라는 점을 기억해 두세요.

## 6. LDA - 문서가 여러 토픽에 걸쳐 있을 때

K-Means는 한 문서를 **하나의 토픽**에 강제로 할당합니다. 하지만 뉴스는 "경제 + 국제" 처럼 두 주제에 걸친 경우가 많습니다. **LDA (Latent Dirichlet Allocation)**는 문서를 **여러 토픽의 혼합 비율**로 표현합니다.

```python
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.decomposition import LatentDirichletAllocation

# LDA는 원시 빈도(CountVectorizer) 입력을 선호
cv  = CountVectorizer(max_df=0.9, min_df=5)
Xc  = cv.fit_transform(df["clean_text"])

lda = LatentDirichletAllocation(
    n_components=8,
    learning_method="online",
    random_state=42,
)
lda.fit(Xc)

vocab_lda = cv.get_feature_names_out()
for ti, topic in enumerate(lda.components_):
    top = np.argsort(-topic)[:10]
    print(f"[Topic {ti}]", " ".join(vocab_lda[top]))

# 문서별 토픽 분포 (N, n_components)
doc_topic = lda.transform(Xc)
```

`doc_topic[i]`는 `i` 번째 문서가 8 개 토픽에 어떤 비율로 속하는지 확률 벡터입니다. 문서 하나의 주 토픽은 `argmax`로, 두 토픽에 걸친 경우는 상위 2 개를 함께 보면 됩니다.

토픽 수 `n_components`를 정할 때는 **perplexity**를 함께 참고합니다. 이는 모델이 문서 분포를 얼마나 잘 재현하는지를 나타내는 지표로, 낮을수록 좋습니다. sklearn LDA는 `lda.perplexity(Xc)`로 바로 계산할 수 있지만, 해석 가능성까지 대신 판단해 주지는 않으므로 실무에서는 perplexity와 사람 검토를 함께 씁니다.

## 7. 트렌드 분석 - 시간 축 얹기

토픽이 잡혔으면, 시간 컬럼과 결합해 주제별 흐름을 볼 수 있습니다.

```python
# 월 단위로 토픽별 기사 수 집계
df["ym"] = df["date"].dt.to_period("M").dt.to_timestamp()

trend = (
    df.groupby(["ym", "topic"])
      .size()
      .unstack(fill_value=0)
      .sort_index()
)

trend.plot(figsize=(11, 5), linewidth=2)
plt.title("Topic trend over time")
plt.xlabel("month"); plt.ylabel("articles")
plt.show()
```

토픽별로 기사 수가 시간에 따라 오르내리는 추세가 그려집니다. 선거·팬데믹·경제위기 같은 외부 이벤트가 특정 토픽의 급증으로 나타나는 식입니다. 기간을 연·분기로 바꾸거나, 특정 언론사만 필터해 비교하는 등 축을 조금만 바꾸면 다양한 시나리오 분석으로 확장됩니다.

## 8. 연관어 네트워크 - Apriori 활용

한 기사에 **같이 등장하는 단어 쌍·집합**을 추출하면 토픽 내부 구조가 더 선명해집니다. Part 3 Ch 05의 **A-Priori 연관 규칙** 알고리즘이 그대로 적용됩니다.

```python
# pip install mlxtend
from mlxtend.preprocessing import TransactionEncoder
from mlxtend.frequent_patterns import apriori, association_rules

# 각 기사 = 단어 "거래". 빈도 상위 단어만 유지해 계산 부담 완화
TOP_N = 200
vocab_top = set([w for w, _ in counts.most_common(TOP_N)])

transactions = [
    [w for w in doc.split() if w in vocab_top]
    for doc in df["clean_text"]
]

te = TransactionEncoder()
onehot = pd.DataFrame(
    te.fit(transactions).transform(transactions),
    columns=te.columns_,
)

items = apriori(onehot, min_support=0.05, use_colnames=True)
rules = association_rules(items, metric="lift", min_threshold=1.2)
rules.sort_values("lift", ascending=False).head(10)
```

결과 DataFrame은 `antecedents` · `consequents` (각각 규칙의 좌변·우변 항목 집합), `support` · `confidence` · `lift` 컬럼을 담고 있어 "A -> B" 규칙 리스트처럼 읽으면 됩니다. NetworkX·PyVis 같은 라이브러리로 노드·엣지 그래프로 시각화하면 "어느 키워드 집합이 한 덩어리로 움직이는지"가 네트워크 형태로 드러납니다.

## 10. 한계와 현대적 대안

전통 토픽 모델링은 속도와 해석 가능성이 큰 장점이지만, 몇 가지 구조적 약점이 있습니다.

- **단어 빈도 기반**이라 의미가 비슷한 단어(예: "대통령" vs "정부")를 다른 단어로 취급
- **문맥 무시**: "은행" (bank)의 여러 의미를 구분 못 함
- **토픽 수 사전 결정**이 필요. 데이터에 따라 "적당한 k"가 다름

이 약점을 완화하는 현대 접근은 세 갈래입니다.

- **문장·문서 임베딩**: Sentence-BERT·KoSimCSE 같은 모델로 문서를 고정 차원 벡터로 변환 후 군집화. 의미 유사성 반영
- **BERTopic**: 임베딩 + UMAP 차원 축소 + HDBSCAN 군집 + c-TF-IDF 토픽 라벨링을 묶은 현대 토픽 모델링 라이브러리. 토픽 수 자동 결정
- **LLM 요약·카테고리화**: 문서를 GPT·Claude 같은 LLM에 직접 넣어 요약·분류. 비용이 큰 대신 품질이 매우 높음

실무에서는 데이터 규모·예산·해석 가능성 요구에 따라 전통 기법과 이들을 병행합니다. 수만 건의 뉴스를 다룬다면 **BERTopic + 연도별 드릴다운** 조합이 최근 가장 무난한 선택지입니다.

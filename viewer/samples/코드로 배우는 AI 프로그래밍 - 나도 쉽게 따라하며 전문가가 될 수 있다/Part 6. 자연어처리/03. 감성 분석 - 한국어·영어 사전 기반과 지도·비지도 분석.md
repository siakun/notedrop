# 03. 감성 분석 - 한국어·영어 사전 기반과 지도·비지도 분석

> **감성 분석(Sentiment Analysis)**은 텍스트의 의견·정서를 긍정·부정·중립 등으로 분류하는 작업입니다. 상품 리뷰, SNS 반응, 고객센터 기록처럼 의견이 담긴 텍스트를 빠르게 읽어내야 할 때 특히 유용합니다. 이 챕터에서는 한국어 네이버 영화 리뷰로 지도학습과 사전 기반 접근을 살펴보고, 영어에서는 SentiWordNet 기반 방법까지 확장해 봅니다.

## 1. 감성 분석의 두 접근

크게 두 갈래의 접근이 있습니다.

- **지도학습(Supervised)**: 긍정/부정 라벨이 붙은 리뷰 데이터로 분류기 학습. 성능 우수, 데이터 필요
- **사전 기반(Dictionary / Lexicon)**: 단어별 감성 점수가 수록된 사전으로 문장 전체 점수 계산. 데이터 없이도 작동, 도메인 의존

실무에서는 보통 지도학습 쪽이 정확하지만, **라벨링된 데이터가 부족할 때** 사전 기반이 빠른 baseline 역할을 합니다. 이 챕터의 핵심 트릭은 "지도학습 모델의 **계수(coefficient)**에서 역방향으로 감성 사전을 만들어 쓰는" 방법이며, 이로써 한국어처럼 고품질 공개 감성 사전이 드문 상황에서도 사전 기반 접근이 가능해집니다.

## 4. 한국어 전처리 파이프라인

감성 분석에 앞선 전처리는 **정규화 -> 토큰화 -> 불용어 제거** 3 단계가 기본입니다.

```python
import re

def clean(text: str) -> str:
    # 한글·영숫자·공백만 남김
    return re.sub(r"[^가-힣a-zA-Z0-9\s]", " ", str(text))

STOPWORDS = {
    "을", "를", "이", "가", "은", "는", "의", "에", "에서",
    "도", "만", "으로", "하다", "있다", "되다", "같다", "없다",
    "그", "저", "이것", "저것", "그것", "우리", "저희",
    "이런", "저런",
}

def tokenize(text: str) -> list[str]:
    tokens = okt.morphs(clean(text), stem=True)
    return [t for t in tokens if t not in STOPWORDS and len(t) > 1]

train["tokens"] = train["document"].map(tokenize)
test["tokens"]  = test["document"].map(tokenize)
```

`stem=True`는 "재미있었어요 -> 재미있다" 처럼 활용형을 원형으로 되돌립니다. `len(t) > 1` 조건으로 한 글자 조사·감탄사를 대부분 걸러냅니다.

한국어 불용어 목록은 공개 리소스(`github`에 `stopwords-ko.txt` 여럿)로 시작해 **도메인 피드백**으로 다듬어야 합니다. 영화 리뷰에서는 "영화", "작품" 같은 단어도 의미가 약해 데이터셋별로 추가 제외를 고려하게 됩니다.

## 5. 지도학습 - TF-IDF + Logistic Regression

토큰이 준비되면 이후는 앞 Ch 01과 동일한 파이프라인입니다.

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline

# 토큰 리스트를 공백 조인 문자열로 되돌려 sklearn에 넘김
train["joined"] = train["tokens"].map(" ".join)
test["joined"]  = test["tokens"].map(" ".join)

pipe = Pipeline([
    ("tfidf", TfidfVectorizer(max_df=0.9, min_df=2, ngram_range=(1, 2))),
    ("clf",   LogisticRegression(max_iter=1000, C=1.0)),
])

pipe.fit(train["joined"], train["label"])
print("accuracy:", pipe.score(test["joined"], test["label"]))
```

15만 건 규모에서 기본 설정만으로도 **정확도 0.83 전후**가 나옵니다 (전처리·하이퍼파라미터에 따라 수치는 달라지며, 공개 baseline도 이 범위 근처에서 보고됩니다). `ngram_range=(1, 2)`로 bigram을 포함한 것이 단순 TF-IDF 대비 의미 있는 개선입니다.

예측 함수는 그대로 감성 분석기로 쓸 수 있습니다.

```python
def predict_sentiment(text: str) -> str:
    tokens = tokenize(text)
    prob = pipe.predict_proba([" ".join(tokens)])[0]
    return f"{'긍정' if prob[1] > 0.5 else '부정'} (확률 {prob[1]:.2f})"

predict_sentiment("이 영화 정말 최악이었어요")
predict_sentiment("배우들 연기가 훌륭했고 음악도 좋았다")
```

## 6. 감성 사전 만들기 - 계수에서 단어 지수로

지도학습 모델이 학습을 마치면 `clf.coef_`에 각 피처(단어·bigram)의 **회귀 계수**가 저장됩니다. 양수는 긍정 쪽, 음수는 부정 쪽 기여. 이 계수를 **단어별 감성 점수**로 그대로 쓰면 바로 **감성 사전**이 됩니다.

```python
import numpy as np

tfidf: TfidfVectorizer = pipe.named_steps["tfidf"]
clf:   LogisticRegression = pipe.named_steps["clf"]

vocab = tfidf.get_feature_names_out()
coefs = clf.coef_.ravel()                # (n_features,)

lexicon = dict(zip(vocab, coefs))        # 단어 -> 감성 점수

sorted(lexicon.items(), key=lambda x: -x[1])[:10]   # 긍정 상위
sorted(lexicon.items(), key=lambda x:  x[1])[:10]   # 부정 상위
```

출력을 보면 "재미있다", "감동", "최고"가 큰 양수, "지루하다", "최악", "쓰레기"가 큰 음수로 나옵니다. 데이터에서 떠오른 단어들이라 교과서적 감성 사전보다 **도메인에 특화된** 점수를 제공합니다.

## 7. 사전 기반 비지도 감성 분류

이 사전만 있으면 라벨 없이도 문장 감성을 점수화할 수 있습니다.

```python
def score_by_lexicon(text: str) -> float:
    tokens = tokenize(text)
    # 단어·bigram 둘 다 고려: "재미있다", "재미있다 정말"
    candidates = tokens + [" ".join(tokens[i:i+2]) for i in range(len(tokens) - 1)]
    return sum(lexicon.get(c, 0.0) for c in candidates)

def classify_by_lexicon(text: str) -> int:
    return 1 if score_by_lexicon(text) > 0 else 0

# 테스트 세트 정확도 확인
preds = test["document"].map(classify_by_lexicon)
(preds == test["label"]).mean()
# 지도학습 모델에 비해 소폭 낮거나, 데이터에 따라 비슷한 수준
```

원 모델과 비교하면 데이터셋·전처리에 따라 결과가 달라집니다. 표본 수가 적고 도메인이 좁을수록 사전 기반이 지도학습에 근접하거나 앞지르는 경우도 있습니다. 반대로 표본이 충분히 크면 지도학습이 우세한 경향이 나타납니다.

사전 기반의 가장 큰 장점은 **학습 없이 추론만** 수행한다는 점입니다. 속도가 빠르고, 사전을 사람이 직접 검토·수정하기도 쉽습니다.

실무에서는 지도학습 모델을 기준선으로 두고, 사전 기반 결과와 **앙상블** 하거나 **디버깅용 해석 도구**로 함께 쓰는 조합이 흔합니다.

## 8. 영어 지도학습 baseline - IMDB 리뷰

영어 감성 분석도 지도학습 쪽부터 짚어 두면 뒤에 나올 비지도 접근과 성능 감을 비교할 수 있습니다. 대표 공개 데이터인 **IMDB 영화 리뷰** (Kaggle "Bag of Words Meets Bags of Popcorn")를 예시로 씁니다.

```python
import pandas as pd, re
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline
from sklearn.model_selection import train_test_split

df = pd.read_csv("labeledTrainData.tsv", sep="\t", quoting=3)
#   id  sentiment  review
# 0 "5814_8"  1  "With all this stuff going down at the moment ..."
# ...
# sentiment: 1 긍정 / 0 부정, 리뷰 25,000건

def clean_en(text: str) -> str:
    text = re.sub(r"<br\s*/?>", " ", text)            # HTML 줄바꿈 제거
    text = re.sub(r"[^a-zA-Z\s]", " ", text)           # 영문자 외 공백
    return text.lower()

df["clean"] = df["review"].map(clean_en)
X_train, X_test, y_train, y_test = train_test_split(
    df["clean"], df["sentiment"], test_size=0.2, random_state=42,
)

pipe_en = Pipeline([
    ("tfidf", TfidfVectorizer(stop_words="english", ngram_range=(1, 2))),
    ("clf",   LogisticRegression(max_iter=1000, C=10)),
])
pipe_en.fit(X_train, y_train)
print("accuracy:", pipe_en.score(X_test, y_test))
# 약 0.89 내외 (C=10, bigram 포함 공개 baseline 범위)
```

한국어 파이프라인과 뼈대는 같고, 형태소 분석기 대신 `stop_words="english"`로 영어 불용어를 자동 제거하는 점만 다릅니다. `C=10`은 sklearn 공식 튜토리얼·Kaggle 커널에서 IMDB 데이터로 자주 쓰이는 값이며, 기본값 `C=1.0`에서도 결과는 크게 다르지 않습니다.

## 9. 영어 비지도 감성 분석 - SentiWordNet

영어는 공개된 감성 자원이 풍부합니다. NLTK에 포함된 **SentiWordNet**은 WordNet의 각 의미(synset)에 긍정·부정·객관 점수를 태깅해 둔 데이터베이스입니다.

```bash
pip install nltk
```

```python
import nltk
nltk.download("wordnet")
nltk.download("sentiwordnet")
nltk.download("punkt")
nltk.download("averaged_perceptron_tagger")

from nltk.corpus import sentiwordnet as swn, wordnet as wn
from nltk import word_tokenize, pos_tag

def penn_to_wn(tag):
    if tag.startswith("J"): return wn.ADJ
    if tag.startswith("N"): return wn.NOUN
    if tag.startswith("R"): return wn.ADV
    if tag.startswith("V"): return wn.VERB
    return None

def sentiwordnet_score(text: str) -> float:
    score = 0.0
    for word, tag in pos_tag(word_tokenize(text)):
        wn_tag = penn_to_wn(tag)
        if wn_tag is None:
            continue
        synsets = list(swn.senti_synsets(word, wn_tag))
        if not synsets:
            continue
        s = synsets[0]                        # 가장 흔한 의미 사용
        score += s.pos_score() - s.neg_score()
    return score

sentiwordnet_score("The movie was absolutely brilliant and moving")   # 양수
sentiwordnet_score("Terrible plot and dull acting ruined the film")   # 음수
```

SentiWordNet은 학습이 필요 없다는 큰 장점이 있지만, **다의어** 처리가 약합니다. "fine"은 "훌륭한"도 되고 "벌금"도 되는데 첫 번째 synset만 쓰면 맥락을 놓칩니다.

그래서 실무에서는 빠른 baseline으로 쓰되, 바로 앞에서 본 IMDB 지도학습 baseline과 비교해 보는 경우가 많습니다. 대체로 정확도는 몇 % 낮게 나오는 편이지만, 실제 차이는 테스트 세트와 전처리에 따라 달라집니다.

영어는 이 외에도 **VADER (Valence Aware Dictionary and sEntiment Reasoner)**, **TextBlob**, **transformers 기반 사전학습 감성 모델** 같은 선택지가 풍부해 도메인에 맞춰 고르면 됩니다.

## 10. 실무 응용과 한계

감성 분석은 다양한 도메인에서 쓰입니다.

- **리뷰·평점 대비**: 별점은 5점인데 리뷰 내용은 부정인 경우 찾기 (평점 조작 의심)
- **고객센터 품질 관리**: 통화 녹취록의 부정 감성 구간 탐지
- **마케팅 모니터링**: 브랜드 언급에서 긍부정 흐름 추적
- **금융 뉴스 분석**: 종목별 뉴스 톤이 주가와 어떻게 연관되는지
- **추천 시스템 신호**: 긍정 리뷰만 골라 추천 가중치 조정

반면 다음 한계가 있습니다.

- **반어·풍자**: "연기 정말 '훌륭' 하시네요"는 긍정 단어로 쓴 부정 의도. 단순 모델은 놓침
- **맥락 의존**: "빠르다"는 노트북에선 긍정, 제품 수명에선 부정
- **도메인 이식성**: 영화 리뷰에 학습한 모델은 반도체 공정 리뷰에서 거의 쓸모없음
- **수치·강도**: "조금 좋다"와 "엄청 좋다"를 잘 구분 못 하는 경우
- **다국어·코드스위칭**: 한 문장에 한·영이 섞이면 전처리부터 까다로움

반어 처리는 여전히 **Transformer 기반 대형 언어모델**이 가장 잘합니다. 감성 분석에 현대 실무 최대 성능이 필요하다면 Hugging Face `transformers`의 사전학습 모델(예: `KLUE-RoBERTa-base` 기반 감성 분류기)을 가져와 Fine-tuning 하는 방향이 현재 표준 경로입니다.

## 마무리

이 챕터의 흐름(전처리 -> TF-IDF + Logistic -> 계수 기반 사전 역공학 -> 사전 적용)은 한국어·영어 모두에 그대로 재사용할 수 있는 **가벼운 감성 분석 파이프라인** 입니다. 지도·비지도 중 어느 쪽 하나에 치우치지 않고 서로를 보완하도록 설계한 점이 실무적으로 유용합니다.

다음 챕터에서는 단어 단위 감성에서 한 걸음 물러나, 문서 수천~수만 개의 주제를 자동으로 묶어 내는 **토픽 모델링**과 **트렌드 분석**으로 Part 6를 마무리합니다.

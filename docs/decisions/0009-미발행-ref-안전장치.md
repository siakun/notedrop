# ADR-0009: 미발행 ref 안전장치

- **Status**: Accepted (2026-04-26)

## Context

발행된 노트가 미발행 노트를 위키링크 또는 임베드로 참조할 때 처리 정책 필요. 양립할 두 가지:
- 비공개 노트 콘텐츠·존재의 누설 방지 (안전)
- 작가에게 "이 노트도 발행해야 한다" 시그널 (UX)

사용자 결정 (3턴에 걸쳐 정제):
1. 임베드는 "접근할 수 없는 문서" placeholder
2. 위키링크는 빨간 밑줄 + "(접근 권한이 없습니다)" 텍스트, 클릭 비활성

## Decision

### 위키링크 → 미발행

```
[[MyPage]]      → "MyPage(접근 권한이 없습니다)"   (빨간 밑줄, 클릭 비활성)
[[MyPage|alias]] → "alias"                         (alias 만, 빨간 밑줄, 클릭 비활성)
```

alias 가 있으면 alias 만 표시 (노트명 노출 X). alias 없으면 노트명 노출 - 사용자가 비공개 노트를 alias 없이 본문에 노출할 일이 적다는 가정.

### 위키링크 → 발행

```
[[MyPage]]      → "MyPage"                         (파란 밑줄 하이퍼링크, /notedrop/<hash>)
[[MyPage|alias]] → "alias"                         (alias, 파란 밑줄)
```

발행된 노트의 hash 또는 slug 로 링크.

### 임베드 → 미발행

```
![[MyPage]]     → 블록 placeholder "접근할 수 없는 문서: MyPage"
                  (회색 박스, 클릭 비활성)
```

작가에게 "이 노트도 발행 켜야" 시그널.

### 임베드 → 발행

```
![[MyPage]]     → 본문 인라인 삽입 (옵시디언과 동일)
```

재귀 깊이 1 제한:
- 임베드 안의 임베드는 다시 펼치지 않음 (placeholder "(임베드 깊이 초과)" 또는 단순 링크)
- 무한 재귀 방지 + 폭주 방지

### 이미지 임베드는 별개

`![[image.png]]` 는 이미지 자산 처리 ([ADR-0017](0017-자산-챕터별-분리.md)). 이 안전장치 대상 아님.

## Consequences

긍정:
- 비공개 콘텐츠 누설 0
- 작가에게 명시적 시그널 (어느 ref 가 발행 안 됐는지 즉시 보임)
- Notion 의 "권한 없는 페이지" UX 와 패턴 일치 → 독자도 직관적

부정:
- 위키링크 alias 없으면 노트명 노출 (작가 책임)
- 임베드 placeholder 가 본문 흐름 끊을 수 있음 (의도된 시그널)

## 안전장치 100% 테스트 의무

다음 모두 단위 테스트 필수:
- 미발행 위키링크 → 빨간 dead link 변환
- 미발행 위키링크 + alias → alias 만, 노트명 strip
- 미발행 임베드 → placeholder 블록
- 발행 → 미발행 전환 (다시 publish 했을 때, 다시 unpublish 했을 때)
- 임베드 재귀 깊이 1 초과 → placeholder
- alias only 케이스 (`[[비공개|관련 메모]]`) → "관련 메모" 만, 노트명 노출 X

## Alternatives Considered

### 1. 미발행 ref 완전 strip (텍스트도 안 남김)

거부 사유:
- 본문 흐름 끊김 (예: "참고: ..." 같은 안내문이 갑자기 비어 보임)
- 작가에게 시그널 X (어느 ref 가 누락됐는지 알기 어려움)

### 2. 미발행 위키링크 = 일반 텍스트만

거부 사유:
- 시그널 약함 (밑줄·색 없으면 평범한 텍스트로 보임)
- 작가가 발행 누락 인지 어려움

### 3. 임베드 = "보러 가기" 링크 컴포넌트

거부 사유:
- 옵시디언과 다른 UX
- 발행됐는데 굳이 링크로 띄울 이유 없음 (인라인이 자연스러움)

### 4. 임베드 재귀 무제한

거부 사유:
- A → B → A 무한 루프 위험
- 큰 책에서 깊은 재귀 시 페이지네이션 폭주

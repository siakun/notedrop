## ADR 라이프사이클

각 ADR 의 Status 변화:
- **Proposed** (작성 중)
- **Accepted** (확정, 적용)
- **Deprecated** (의미 줄어듦, 새 결정으로 대체될 예정)
- **Superseded by ADR-XXXX** (새 ADR 이 대체. 본문은 보존, Status 만 갱신)

ADR 은 **수정하지 않음**. 결정이 바뀌면 새 ADR 추가 + 옛 ADR Status = "Superseded by".

## 2. dogfood 시작 절차

### 2.1 BRAT 설치

1. Obsidian Community Plugins → BRAT 설치 + 활성화

### 2.2 발행 설정

Settings → Notedrop:

| 필드 | 값 |
|---|---|
| GitHub PAT | fine-grained PAT, contents:write, repo=`siakun/notedrop` |
| Target repository | `siakun/notedrop` |
| Target branch | `main` |
| Public root | `viewer/public` |
| Share URL base | `https://siakun.github.io/notedrop` |

PAT 만들기:
1. https://github.com/settings/personal-access-tokens/new
2. Resource owner: siakun
3. Repository access: Only selected → `siakun/notedrop`
4. Permissions → Repository → Contents: Read and write
5. Generate token → 복사 → Settings 에 붙여넣기

### 2.3 첫 발행

1. 발행할 노트 frontmatter:

3. Notice "발행 완료 (commit XXXXX, N개 파일)"
4. 1~2분 후 https://siakun.github.io/notedrop/ 갱신
5. URL 복사: Cmd+P → `Notedrop: Copy share URL` (slug 또는 hash)

## 10. 사과 + 한계

이번 run 은 사용자 부재 + autonomous mode 에서 다음을 못 함:
- 실 옵시디언 환경 GUI 테스트 0건
- 실 PAT 로 publish 한 번도 못 돌림
- 책 1챕터 변환 결과 시각 확인 X
- 메모리 누수, 1시간 연속 가동 등 비기능 요구사항 검증 X

따라서 본 0.1.0 은 *기능 코드는 완성, 통합 검증은 dogfood 의존* 이라는 의미. 실 사용 시 발견되는 버그는 v0.1.x patch 로 즉시 대응 가능. 스펙 §11.4 strict gate 통과를 v1.0 정의로 본다면 본 릴리스는 v0.9.0 또는 v0.1.0-alpha 가 정확한 명명일 수 있으나, 사용자가 "0.1.0 완성을 희망" 한 의도를 존중해 0.1.0 으로 태깅. 복귀 후 dogfood 결과에 따라 재태깅 여부 사용자 판단.
